# Каталог корпуса песен (каркас)

Собран 2026-08-14. Правила отбора: `docs/rules/project.md` (корпус = сольные Lieder по NSA, genre=Lied).

## Файлы

- `catalog.json` — черновик каталога: **644 записи** NSA-фильтра «Lied», смёрженные с IMSLP по D-номеру. Из них **9 записей — группы-родители** (D 478, 688, 795, 857, 866, 877, 902, 911, 957) с 79 песнями-членами (`D/n`), т.е. **~635 песен**. Поля: `d, title, year_nsa, opus, nga, comment, poet_short (обрезан в списке NSA!), nsa_detail_id, incipit, key, year_imslp, published, forces, imslp (slug), imslp_versions, notes_imslp`.
- `sources/nsa-lied.json` — распарсенная выгрузка Schubert-Datenbank (schubert-ausgabe.de), genre=Lied, 644 строки. © Neue Schubert-Ausgabe; используем как фактические данные (факты не охраняются), с указанием источника на сайте.
- `sources/imslp-works.json` — распарсенная таблица IMSLP «List of works by Franz Schubert», 1525 строк. Лицензия **CC BY-SA 4.0** — при публикации производного списка указать атрибуцию IMSLP.
- `scripts/` — воспроизводимый конвейер: `parse-imslp.js`, `parse-nsa.js`, `merge-catalog.js` (сырой HTML скачивается curl'ом, см. шапки скриптов; временные файлы — только в scratchpad).

## Проверенные расхождения NSA ↔ IMSLP

- 16 «сольных» D из IMSLP вне NSA-Lied — все объяснены: Anh. (сомнительные/чужие), D 122 («не Шуберт» по NSA), D 607 (духовное, Serie I), D 732 (опера), D 407/2 (кантата к юбилею Сальери), D 480 → D 478/2, D 93 → D 93/1–3, deest-эскизы.
- Расхождения годов (14 шт.) — квалификаторы («1816?» vs «1815 or 1816»); эталон — NSA + точные даты schubert-digital.at (`dates.json`, задача №2).
- Гистограмма годов NSA (по записям, включая членов циклов): 1810:2 · 1811:4 · 1812:4 · 1813:10 · 1814:23 · **1815:142 · 1816:121 · 1817:63** · 1818:16 · 1819:23 · 1820:24 · 1821:14 · 1822:22 · 1823:41 · 1824:5 · 1825:26 · 1826:22 · 1827:45 · 1828:34 · без года:3.
