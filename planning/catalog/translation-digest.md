# Дистиллят правил перевода для агентов-переводчиков

Полный свод: `planning/winterreise-reference/CLAUDE.md`. При конфликте с грамматикой — приоритет ей.

## Пословность

- Каждое DE-слово — в подстрочнике, включая служебные и модальные частицы (`mögen`=«должно быть»).
- Одно RU = одно DE, где возможно. Объединять слова в сегмент — **только** когда буквальность ломает смысл/грамматику RU (идиомы, AcI, Verbklammer). Слово с самостоятельным смыслом — отдельный сегмент даже в рамке.
- Составное DE-слово — один DE-сегмент, RU разбивается дефисом (`Frauenbild→женщины образ.`, `Traum→сон-мечта`); части компаунда склоняются согласованно.
- **Порядок слов**: сохранять DE-порядок (в т.ч. поэт. инверсию), где грамматично по-русски. Перестраивать — только если RU **нечитаем**; «непривычно» не повод.

## Сегменты `{ru, de}`

- Порядок сегментов — по RU. `de` пустой — слово вошло в рамку/сосед. `ru` пустой — у артикля без пары; пустой `de` при непустом `ru` — грамматич. RU-добавка (союз, предлог, антецедент).
- Рамка (Verbklammer) — многоточие в `de` при разрыве словами (`pfiff'... aus`), рядом стоящие — без; порядок в рамке = порядок DE.
- Предлоги — отдельные сегменты; управляемые глаголом — в рамку с глаголом.

## Артикли, частицы, возвратные

- Артикль слева от сущ. — со **следующим** сегментом; не «некий/этот» по умолчанию (искл. — сам несёт смысл).
- doch/denn/nun/wohl/so/schon — по контексту, не шаблонно; неочевидный выбор сигнализировать.
- Связка sein → тире отдельным сегментом (искл.: модальный+sein-инф. — пара глаголов).
- «Свой» — только внутри одной RU-клаузы; при разбиении на клаузы — «его/её/их».
- Отрицание (kein/nichts/nimmer) — отриц. слово + «не» (пустой `de`) + глагол.

## Тире и знаки

- Пунктуация — только в `ru` (кроме апострофов элизии: zieh', hätt'). Не калькировать DE-пунктуацию.
- Тире — для связки sein и маркера эллиптированного глагола (не домысливать); двоеточие — при двух предикативных частях/AcI после глаголов восприятия.
- Добавленный «из воздуха» глагол (эллипсис) — обязательна lang-аннотация. Ёлочки «...», длинное тире, ё обязательна.

## Аннотации: `lang` vs `meaning`

- **lang** — грамматика (Verbklammer, порядок слов, падежи, род, отрицание, идиомы, составные слова).
- **meaning** — смысл (этимология, семантика эпохи, мотивы, многозначность, музык. события, лит. контекст).
- DE-цитаты в тексте аннотации — с переводом в скобках; ёлочки только для RU.
- `segment_range:[start,end]` — индексы включительно (0-based); разрыв — `[[s1,e1],[s2,e2]]`. `line_span`+`continuation_ranges` — многострочный охват, `[-1,-1]` — пропустить строку.
- Несколько аннотаций на сегменте возможны, видимая сноска — одна. Факты meaning-аннотации проверяются по источникам до записи.

## Орфография и повторы

- Историческая DE-орфография источника **не «чинится»**, кроме модернизации ß→ss, Th→T.
- Повтор DE-слова переводится **каждый раз заново** отдельным сегментом — можно раскрыть разными гранями смысла.
- Одно DE-слово через песню/цикл — один RU-эквивалент по умолчанию; отступление — с сигнализацией.

## Пример (`d118-gretchen-am-spinnrade.json`)

```json
{"segments":[{"ru":"Его","de":"Sein"},{"ru":"горделивая","de":"hoher"},{"ru":"поступь,","de":"Gang"}],
 "annotations":[
   {"type":"lang","segment_range":[1,1],"text":"Дословно hoher — «высокая»; «высокая поступь» по-русски не читается, поэтому «горделивая»."},
   {"type":"meaning","segment_range":[0,2],"text":"Перечень — приближение: походка, лицо, речь, рука, поцелуй."}
 ]}
```
