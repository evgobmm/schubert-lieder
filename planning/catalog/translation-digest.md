# Дистиллят правил перевода для агентов-переводчиков

Полный свод: `planning/winterreise-reference/CLAUDE.md`. При конфликте с грамматикой — приоритет ей.

## Пословность

- Каждое DE-слово — в подстрочнике, включая служебные и модальные частицы (`mögen`=«должно быть»).
- Одно RU = одно DE, где возможно. Объединять слова в сегмент — **только** когда буквальность ломает смысл/грамматику RU (идиомы, AcI, Verbklammer). Слово с самостоятельным смыслом — отдельный сегмент даже в рамке.
- Составное DE-слово — один DE-сегмент, RU разбивается дефисом (`Frauenbild→женщины образ.`, `Traum→сон-мечта`); части компаунда склоняются согласованно.
- **Порядок слов**: сохранять DE-порядок (в т.ч. поэт. инверсию), где грамматично по-русски. Перестраивать — только если RU **нечитаем**; «непривычно» не повод. **Гейт читаемости**: прочитай каждую RU-строку вслух — это русская фраза? «Дрожит мне горячее вниз по щеке» — НЕТ (брак); перестраивай и объясняй в lang-аннотации. Пословность не оправдывает кальку.

## Сегменты `{ru, de}`

- Порядок сегментов — по RU. `de` пустой — слово вошло в рамку/сосед. `ru` пустой — у артикля без пары; пустой `de` при непустом `ru` — грамматич. RU-добавка (союз, предлог, антецедент).
- Рамка (Verbklammer) — многоточие в `de` при разрыве словами (`pfiff'... aus`), рядом стоящие — без; порядок в рамке = порядок DE.
- **Позиция слитой рамочной формы (канон референса)**: вспомогательный глагол перфекта/пассива (haben/sein/werden) позицию НЕ задаёт — русская слитая форма встаёт на место СМЫСЛОВОЙ части (причастия/приставки), обычно в конец строки: «Gott hat sie so gemacht» → «Бог её так создал»; «An dich hab' ich gedacht» → «О тебе я думал». Модальные и полнозначные глаголы — на своей позиции («kann... nicht» → «не могу» на месте kann). Ставить глагол на позицию вспомогательного («Зажгло ты моё сердце…») — ошибка.
- Предлоги — отдельные сегменты; управляемые глаголом — в рамку с глаголом.

## Артикли, частицы, возвратные

- Артикль слева от сущ. — со **следующим** сегментом; не «некий/этот» по умолчанию (искл. — сам несёт смысл).
- doch/denn/nun/wohl/so/schon — по контексту, не шаблонно; неочевидный выбор сигнализировать.
- Связка sein → тире отдельным сегментом (искл.: модальный+sein-инф. — пара глаголов).
- «Свой» — только внутри одной RU-клаузы; при разбиении на клаузы — «его/её/их».
- Отрицание (kein/nichts/nimmer) — отриц. слово + «не» (пустой `de`) + глагол.

## Тире и знаки

- Пунктуация — только в `ru` (кроме апострофов элизии: zieh', hätt'). Не калькировать DE-пунктуацию.
- Тире — для связки sein и маркера эллиптированного глагола (не домысливать); двоеточие — при двух предикативных частях/AcI после глаголов восприятия.
- Добавленный «из воздуха» глагол (эллипсис) — обязательна lang-аннотация. Ёлочки «...», длинное тире, ё обязательна.

## Аннотации: `lang` vs `meaning`

- **lang** — грамматика (Verbklammer, порядок слов, падежи, род, отрицание, идиомы, составные слова).
- **meaning** — смысл (этимология, семантика эпохи, мотивы, многозначность, музык. события, лит. контекст).
- DE-цитаты в тексте аннотации — с переводом в скобках; ёлочки только для RU.
- `segment_range:[start,end]` — индексы включительно (0-based); разрыв — `[[s1,e1],[s2,e2]]`. `line_span`+`continuation_ranges` — многострочный охват, `[-1,-1]` — пропустить строку.
- **Одно слово — одна сноска**: диапазоны аннотаций в строке НЕ пересекаются; всё, что нужно сказать о слове, — в одной аннотации (можно с абзацем внутри). Две сноски на слове — дефект (указание пользователя 2026-08-18). Факты meaning-аннотации проверяются по источникам до записи.

## Орфография и повторы

- Историческая DE-орфография источника **не «чинится»**, кроме модернизации ß→ss, Th→T.
- Повтор DE-слова переводится **каждый раз заново** отдельным сегментом — можно раскрыть разными гранями смысла.
- Одно DE-слово через песню/цикл — один RU-эквивалент по умолчанию; отступление — с сигнализацией.

## Язык текстов (дистиллят style.md — обязателен с первого черновика)

- **Живая русская речь** — мерило, а не чек-лист: фраза должна звучать так, будто её написал русский редактор для бумажного издания; читать вслух. Переводной синтаксис запрещён как класс («оба слоя работают вместе», «форма желания, не факта», «отдельного слова не получает» — образцы брака).
- Слова в своих значениях и сочетаниях; глагол должен подходить; каждая отсылка («он же», «перечень») понятна на месте.
- Запрещены: «не просто X, а Y» и отрицательный параллелизм как украшение (контраст — только когда он и есть сообщение); «стоит отметить/важно понимать»; анонсы «рассмотрим»; связки «кроме того/более того/таким образом»; канцелярит («является», «данный», «в рамках»); раздувание («ключевой», «уникальный»); штампы-метафоры («симфония», «палитра»); тире-мания и двоеточие-развёртка как приём по умолчанию; украшательные триады; рубленые фразы-«удары» (максимум 1–2 заработанные на страницу); зачины-клоны.
- **Немецкое (и любое иноязычное) — всегда с русским переводом в скобках с «ёлочками»**: Sehnsucht («тоска»); переводы только в скобках. Иноязычные цитаты — живым русским, не калькой.
- **Не оставлять загадок**: договаривать всё, спойлеры разрешены; можно отсылать к другому разделу.
- Числа и даты страницы согласованы между собой; видимое противоречие снимается пояснением.

## Факты и порядок работы (дистиллят verification-protocol.md)

- **Сначала факт**: тексты собираются только из файла фактов песни (утверждение+URL+цитата+статус); «мостики» и сравнения — тоже утверждения. `uncertain` не публикуется, `secondary` — только с атрибуцией-оговоркой.
- Словарные решения — из словарного кэша `planning/dictionary/entries/`; непокрытые слова — сначала дорожка, потом перевод.
- Цитаты снимаются с сырого текста (raw/pdftotext/скан), не с пересказа WebFetch; OCR-цитаты в кавычках — только после сверки со сканом.
- Приёмка каждой песни: механический валидатор (`planning/scripts/check-corpus.js`) + редактор-язык + факт-гейт; цикл «правка → сверка» до чистого прохода; правки контролёров — тоже редактура.

## Пример (`d118-gretchen-am-spinnrade.json`, эталонная страница)

```json
{"segments":[{"ru":"Его","de":"Sein"},{"ru":"горделивая","de":"hoher"},{"ru":"поступь,","de":"Gang"}],
 "annotations":[
   {"type":"lang","segment_range":[1,1],"text":"Дословно hoher — «высокая». О человеке это слово означало «знатный, возвышенный», о походке — «величавая, полная достоинства»: перед Гретхен — гость из высшего мира. «Высокой» поступь по-русски не называют — в классике она гордая, величавая или важная; здесь — «горделивая»: тем же словом в этой строфе пользуется Пастернак («стан горделивый»)."}
 ]}
```
Полный эталон стиля и глубины — вся страница d118 (перевод, 27 аннотаций, 20 разделов «О песне»).
