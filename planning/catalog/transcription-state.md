## Смена конвейера (2026-08-14 ~19:20 UTC, после сгорания лимитов)

Старый конвейер (двойное зрение + арбитраж, модель сессии, xhigh) стоил ~120 тыс. токенов/песню — **запрещён**. Новый: `scripts/gen-transcribe-ocr.js` — бесплатный hOCR-слой MDZ (`https://api.digitale-sammlungen.de/ocr/<bsb>/<page>`) + 1 агент sonnet/low на сборку + механический guard (каждое слово результата содержится в OCR-склейке, порог 2%) + проверка связности sonnet/low. Ожидаемая цена ~6–10 тыс. токенов/песня (~15× дешевле). Зрение по картинкам — только вторая волна для suspect.

## Правила процесса (докручено по указанию пользователя)

- Результат партии коммитится и пушится **сразу**; не более 1–2 воркфлоу одновременно.
- Обрыв воркфлоу → `Workflow({scriptPath, resumeFromRunId})` — журналы в `~/.claude/projects/.../workflows/`.
- Спорные (suspect) — вторая волна после всех партий.
- Хвост после партий: ~11 полных песен без AGA (первые издания), фрагменты — по политике «точечно позже» (`docs/rules/project.md`).
