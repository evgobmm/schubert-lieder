# Ретроспектива первого дня (пилот «Гретхен»)

Разбор ошибок и проблем сессии «основной чат» с мерами. Меры со статусом «принято» уже действуют (записаны в правила); «новое» — принято этой ретроспективой.

## Содержательные ошибки

1. **Непроверенный факт внесён при редактуре** («прялки крутились в музыке и до Шуберта») — стилевая правка родила утверждение без источника; поймано пользователем.
   Меры (принято): конвейер «сначала факт» (`verification-protocol.md` §0) — тексты только из файла фактов; §3б — редактура не вносит фактов; §3в — аудит прослеживаемости после каждого изменения. Аудит 283 утверждений проведён.
2. **Искажения формулировок при пересказе источников** (14 случаев: «слил строки», «до XIX века», снятая оговорка рецензента, смешение атрибуций, превосходная степень).
   Меры (принято): тот же §0/§3в; в аудит включена проверка «мостиков» и сравнение с точной формулировкой источника.
3. **ИИ-язык в текстах** («это не X, а Y», двоеточия-развёртки, клоны зачинов, канцелярит).
   Меры (принято): `style.md` (22 запрета) + каталог 73 паттернов; писать сразу по правилам; стилевой проход свежим агентом — обязательный пункт публикации.
4. **Потери при редактуре** (просклонённая цитата, четыре смысловых оборота).
   Меры (принято): §3б «редактура без потерь» с независимой сверкой; финальная сквозная сверка снапшота — выполняется.
5. **Ошибочная дата в данных о записи** (Э. Шуман: 1945 из метаданных archive.org; на деле 1936 — доказано по матрицам).
   Мера (новое): в `youtube-performances.md` — даты и составы записей верифицировать по дискографиям (матрицы, CHARM, буклеты), а не по описаниям загрузок и метаданным архивов.
6. **Цитаты через пересказ WebFetch** (промежуточная модель может исказить).
   Мера (новое): в `verification-protocol.md` — цитаты снимать с сырого текста (curl, action=raw, pdftotext, скан), пересказ WebFetch — только как навигация; OCR — по §3а.
7. **Нестабильные источники** (kammermusikfuehrer то 404, то жив).
   Мера (принято де-факто, закреплено): дословная цитата всегда сохраняется в файле фактов в момент верификации — страница не зависит от живости ссылки; при нестабильности добавлять ссылку на веб-архив.

## Процессные и технические проблемы

8. **Обрыв сессии убил фоновые воркфлоу** (перезагрузка VS Code).
   Меры (принято де-факто, закреплено): длинные исследования — только через Workflow (журнал на диске, резюме из кэша через resumeFromRunId); результаты немедленно в `planning/research/` и коммит; после обрыва — ревизия фактического состояния по диску и git, не по памяти разговора.
9. **Мусор агентов в корне репозитория** (дампы страниц, JSON Discogs).
   Мера (принято): агентам — только scratchpad; требование включается в каждый промпт; обнаруженный мусор удалять.
10. **Гонка сборки с параллельной сессией** (разовая ошибка rollup из-за файлов, записываемых в момент сборки).
    Мера (новое): разовую ошибку сборки не диагностировать по одному прогону — повторить; перед push — `git pull --rebase`; сборку для деплоя делает CI, локальная — только проверка.
11. **Правка JSON инструментом Edit по старой копии** (несовпадение форматирования после jq).
    Мера (новое): данные песен править через jq (по пути в структуре) либо после свежего чтения файла; большие замены — сборкой нового объекта с валидацией до записи.
12. **Лимит подписки оборвал агентов посреди воркфлоу.**
    Мера (принято де-факто): резюме воркфлоу с кэшем завершённых агентов; при известном лимите — крупные волны агентов не запускать впритык.
13. **Недостаточная глубина первой версии** («О песне» пришлось расширять по требованию пользователя).
    Мера (принято): стандарт глубины — пять линз сразу, до публикации (`translation.md`).
14. **Разнобой оформления правил** (пометки «указание, дата» раздували файлы).
    Мера (принято): правила содержат только текущую редакцию, без протокола получения; дата — в шапке файла. Старые пометки вычищены.
