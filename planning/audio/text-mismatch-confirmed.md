# Расхождения текста сайта с тем, что поют — подтверждённые разбором

Случаи, где расхождение проверено по нескольким записям (Whisper + разбор), а не только автоматической сверкой (`text-audit.md`).
Правка текста — редакторское решение (конвейер «сначала факт», `docs/rules/verification-protocol.md`); после правки песня
пересобирается одиночной партией.

| D | строка на сайте | что поют | записи | примечание |
|---|---|---|---|---|
| 23 Klaglied | 1.6 «Klagton hör ich bebend nur,» / 1.7 «Klagton hör ich nur, Klage.» | «Hör ich bebend nur Klagton, hör ich nur Klagton» — «Klagton» в конце фразы, финального «Klage.» нет | Яновиц, Маклафлин, Мюллер-Брахман (3 из 3, поющих строфу) | ИСПРАВЛЕНО 2026-09-09 по указанию пользователя: строки приведены к спетому («Hör ich bebend nur Klagton,» / «Hör ich nur Klagton.»), сегмент «Klage» убран; песня пересобрана |
| 23 Klaglied | 3.1 «Wenn ich von fern ihn seh,» | Яновиц: «Wenn ich ihn von fern seh» (по Whisper, оба раза); пользователь слышит «Wenn ich seh ihn von fern» | Яновиц (единственная, кто поёт строфу 3) | порядок слов внутри строки; CTC на сопрано не различает |
| 955 Glaube, Hoffnung und Liebe | 1.1 «Glaube, hoffe, liebe!» / 1.2 «Hältst du treu an diesen Dreien,» | «…und glaube, es hilft, es heilt die göttliche Kraft» — иная редакция текста Куфнера | все записи | вся песня расходится с текстом; см. text-audit.md |
