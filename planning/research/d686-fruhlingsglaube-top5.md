## Итоговый топ-5 (порядок — строгая иерархия приоритетов)

1. **Thomas Quasthoff / Justus Zeyen** — «Widmung — Romantische Lieder» (DG 474 501-2 — номер подтверждён Discogs API release 9880429: barcode 0 28947 45012 2, matrix 00289 474 501-2 01; переизд. «A Romantic Songbook»), издание 2004 (MusicBrainz release 50bda699-8911-4c9e-816e-a4a83449a3d8, 2004-04-01; Discogs 9880429 — year 2004). **Год сессии дискографически НЕ документирован** — по правилу «иначе год издания» в плеер идёт **2004**. Ходившая по реестру дата «сессии ноябрь 2003, Bavaria Musikstudios, Мюнхен» восходит к досье D 799 (карточка агрегатора IDAGIO/Apple Classical, буклет не вскрыт); перепроверка 2026-08-17: IDAGIO (recordings/28563818) — 403, Apple Classical показывает иную и заведомо ложную дату «November 5, 2001» без места записи, Discogs и MusicBrainz сессионных данных не содержат. До находки первички (буклет DG 474 501-2 / каталог лейбла) дата 2003 непубликуема; в D 257/550/799/853 альбом стоит с годом 2003 — сквозную унификацию нужно выправить отдельным проходом. Frühlingsglaube — открывающий трек альбома (3:07). Ему 44–45 — середина пика (~1993–2007 по дайджесту). Единственная запись песни у певца №1 иерархии — по правилам всегда №1 при наличии достойной записи. Видео: oEOQ1buE3jc (Quasthoff Topic, oEmbed OK, 187 с = MB).
2. **Dietrich Fischer-Dieskau / Gerald Moore** — ранняя EMI/Electrola-версия; цифровой альбом Warner «Schubert: Lieder Vol. 2» (компиляция-ремастер 2011, ℗ 2012 EMI; серия рециталов EMI Vol. 1–4 с Муром, сессии 1955–1958, продюсер Christfried Bickenbach; том 4 документирован Греем: 23–25.05.1958). Принадлежность videoId именно этой версии доказана в этой сессии: yt-dlp отдаёт album=«Schubert: Lieder Vol. 2», а трек 8 компиляции в iTunes — Frühlingsglaube 197 с (= длительность загрузки). Точный год сессии не установлен (у Грея записи D 686 у Ф.-Д. нет вовсе; в MB её нет) — по правилу о неустановленном годе идёт диапазон **«1957–58?»**, уже принятый корпусом для этого же альбома (D 547). Ему 32–33 — абсолютный пик; выбрана вместо DG-свода 1966–72 (та же связка, 173 с) по состоянию голоса и правилу «при прочих равных — более ранняя» (прецеденты D 547, D 550, D 138). Косвенный маркер статуса: фан-загрузка именно этой версии (E_WMgEu63FA, 316 тыс.) — самая просматриваемая запись песни на YouTube. Видео: zUznPTIDbzo (F.-Dieskau Topic, 198 с).
3. **Fritz Wunderlich / Hubert Giesen** — DG 139 220 («Die schöne Müllerin» + Lieder), сессии 2–5 июля 1966, Мюнхен, Akademie der Wissenschaft (Грей, id 177555; у Грея опечатка «Hubert Green»). Последние студийные сессии певца — погиб 17.09.1966, в 36 лет; спада не было («только пик» — дайджест). Связка Вундерлих/Гизен — эталон тенорового Шуберта (дайджест); досье называет запись сильнейшим теноровым кандидатом корпуса. Среди «прочих звёзд прошлого» — сильнейший кейс по качеству (прецедент ранжирования — D 550). Год унифицирован с D 257/550/558/800 (сессии июля 1966). Видео: ZIJiprlicM4 (Wunderlich Topic, 194 с ≈ MB 197 с).
4. **Christa Ludwig / Geoffrey Parsons** — Columbia SAX 5272 / Angel S 36462, сессия 20 февраля 1962, Abbey Road Studio No. 1 (Грей, id 175960 — точная дата). Ей 33–34 — начало пика (~1957–1975), голос в лучшей форме; тот же круг сессий (28–30.11.1961 + 20.02.1962), что дал её 5-звёздную по klassik-prisma Gretchen. Ранняя версия предпочтена DG-ремейку с Гейджем (21–24.06.1973) — повтор программы, правило «при прочих равных — более ранняя». Видео: tUl_-0rS-rQ (Ludwig Topic, 221 с = единственная «длинная» версия с Parsons по MB; у певицы на Topic три разные фонограммы — 183/177 с — это ремейк с Гейджем, не брать).
5. **Florian Boesch / Malcolm Martineau** — «Schubert: Lieder Recital» (Onyx 4149), 2016. Ему 45 — пик (~2010 — наст. время); «рассказчик венской школы» (дайджест). Альбом уже проверен и используется корпусом (D 225, D 226, D 254, D 257, D 805 — год унифицирован: 2016). Занимает слот «не ранее 2015» — сильнейший верифицированный кандидат этого слота (у Sampson-2025 рецензий пока нет, у Konradi — «молодой пиар» без критического следа). Видео: fnUMbjosVWk (Boesch Topic, 170 с = MB).

## Ключевые решения и отклонённые кандидаты

- **Schwarzkopf, Hotter, Popp — песню не записывали** (отрицательные результаты досье: MusicBrainz, Грей, YouTube; у Попп — лишь любительская загрузка концерта Вена-1982 без установленного происхождения). Приоритет №3 для этой песни закрыт отрицательно — женский слот старой школы уходит Людвиг.
- **Elisabeth Schumann / Reeves (HMV, 19.11.1935, Abbey Road; Грей id 56373)** — именной приоритет, «стиль эталонный», край пика (47 лет). Уступила два свободных слота группы старых звёзд Вундерлиху (абсолютный пик, эталонная связка) и Людвиг (расцвет голоса, стереосессия с 5-звёздной родословной): звук 78 об. и возраст на границе пика — при отсутствии сравнительной критики по этой песне решают качество и состояние голоса. Первый резерв до-1990.
- **Peter Anders (Topic, две фонограммы: 176 и 188 с)** — именной приоритет, но записи нет ни у Грея, ни в MusicBrainz; пианист не установлен; «1947» — только из заголовка серого переиздания (History Records) — по правилам не источник. Качество не верифицировано — в топ не идёт без целевого доисследования; резерв.
- **Fischer-Dieskau, DG «Sämtliche Lieder» (сессии 1966–72, конвенция 1969; 173 с)** — уступил ранней EMI-версии по состоянию голоса; ID-резерв: fxF19B7Pg04 (Topic, 48 тыс. просмотров), дубль MNeJ-15Ui4w.
- **Ludwig / Gage (DG 2530 404, 21–24.06.1973)** — повтор программы 1962 г.; правило ранней версии.
- **Flagstad / Moore + альт Herbert Downes (HMV DB 21554, 15.07.1952; Грей id 57333)** — историческая редкость (облигатный альт), но манера монументальная, не камерная («Шуберт вторичен» — дайджест).
- **Björling / Schauwecker (Carnegie Hall, 24.09.1955 и 2.03.1958)** — бельканто-подход, не Lieder-специалист (в дайджесте отсутствует); две записи не разводятся по длительности без буклета.
- **Tauber (Parlophone, 28.09.1934) и Schlusnus (Polydor, 4.05.1938; ранняя 1928 с Руппом)** — достойный исторический второй ряд; проиграли конкуренцию за слоты до-1990; у Шлюснуса привязка Topic-загрузок к версии 1938 не доказана матрично.
- **Ameling / Demus (EMI Electrola, 10–13.01.1970)** — сильная документированная запись; уступила именным приоритетам и Вундерлиху; её версия 1987 г. (Tanglewood) отпадает по правилу ранней. **Baker / Parsons (℗ 1981)** — год сессии не установлен. **Grümmer (Шветцинген, 1958)** — пианист не установлен. **Prey / Hokanson (Philips, 27–30.10.1971)** — студийного трека на YouTube нет (только концерт с чтецом, 312 с — для плеера непригодно).
- **Современные, уступившие слоты 1990+**: Goerne / Metzmacher («Heliopolis», HM, сессии 2008–09), Gerhaher / Huber («Nachtviolen», Sony 2014 — по дайджесту прямое предупреждение о пиаре), Bostridge / Drake (EMI, зап. 1996), Lipovšek / Johnson (Hyperion Vol. 29, XII.1996 — научный эталон издания). Первый слот 1990+ занят именным приоритетом №1 (Квастхоф), второй по правилам отдан достойному кандидату 2015+ (Бёш).
- **Fleming / Eschenbach (Decca, 1996)** — резко замедленный темп (244 с), Lieder вторичны (дайджест). **Konradi (2018), Kleiter (2013)** — без критического следа; правило скепсиса к пиару. **Coote / Drake (Hyperion, зап. 2017)** — песня издана двумя треками по строфам, цельного видео нет — дисквалификация для плеера.
- **Sampson / Middleton («Schubert's Four Seasons», BIS, изд. 04.04.2025)** — новейший значительный релиз, но рецензий не собрано (WebSearch недоступен); слот 2015+ отдан проверенному Бёшу; резерв.

## Соответствие возрастной структуре

3 записи ранее 1990 («1957–58?», 1962, 1966) ✓; 2 записи 1990+ (2004, 2016) ✓; из них 1 запись 2015+ (2016) ✓. Возрастная структура выполнена без ущерба качеству; порядок — строгая иерархия: Квастхоф → Фишер-Дискау → (Шварцкопф нет) → звёзды прошлого по качеству (Вундерлих, Людвиг) → современный (Бёш).
