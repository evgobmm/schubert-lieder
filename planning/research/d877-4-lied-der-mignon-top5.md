# Lied der Mignon «Nur wer die Sehnsucht kennt» (D 877/4) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Досье: planning/youtube/data/d877-4-lied-der-mignon.dossier.json (редакция 2). Ярус — famous. Все 5 итоговых видео проверены через oEmbed (живы, встраиваемы, официальные Topic-каналы).

Особенность фонда: сравнительных обзоров по этой песне не существует — klassik-prisma страницы по D 877/4 не имеет (проверено по индексу Schubert.htm), слепых тестов нет. Ранжирование опирается на иерархию приоритетов, документированные факты о записях (год, состояние голоса, происхождение) и репутацию альбомов/исполнителей, а не на потрековую критику. Из приоритетных певцов песню записали только Криста Людвиг и Элизабет Шуман: Квастхоф, Фишер-Дискау, Шварцкопф, Хоттер, Андерс и Попп её не записывали (женская партия Миньоны; по каждому — отрицательный источник в досье, у Фишера-Дискау с ловушкой: Topic-трек pFrq3pvYa7I «No. 4» — ошибка метаданных, на деле дуэт D 877/1 с де лос Анхелес).

## Итоговый топ-5

1. **Christa Ludwig / Irwin Gage** — зап. 21–24.06.1973, Вена, Rosenhügel; LP «Schubert-Lieder», DG 2530 404 (℗ 1974); трек A6 (Грей через реестр; Discogs 3089946). Ей 45 — внутри пика (~1957–1975 по дайджесту). Приоритетный исполнитель (правило §Приоритетные, п. 4) с полностью документированным годом — единственный такой в пуле. Это поздний DG-ремейк её EMI-программ, но в отличие от Gretchen (где ремейк 1973 уступал ранней EMI-версии) более ранней её записи D 877/4 не существует — сравнивать не с чем. Видео: F_NdaYIpd9U (Ludwig Topic).
2. **Elisabeth Schumann / Gerald Moore** — год не установлен, публикуется с диапазоном «1936–46?» (по годам её работы с Муром на HMV; правило §«Хорошая запись приоритетного исполнителя не блокируется неустановленным годом»). Оригинал HMV, продюсер Walter Legge; переизд. «Icon: Elisabeth Schumann» (Warner Classics). Приоритетный исполнитель, эталон венского Lied-стиля межвоенных лет; единственный довоенно-исторический голос в пуле с официальной загрузкой. В базе Грея позиции нет, в Naxos 8.110731 трека нет — целевое доисследование даты результата не дало. Видео: pdPSzUx15uQ (E. Schumann Topic, кредиты Warner: Schumann/Moore/Legge).
3. **Irmgard Seefried / Erik Werba** — зап. 30.05 + 3, 7–8.06.1958; LP «Irmgard Seefried singt Lieder von Franz Schubert», DG 136 009 SLPEM, трек B1 группы «Lieder der Mignon» (Грей через реестр; Discogs 9264874). Ей 39 — середина формы (пик кон. 1940-х – нач. 1960-х). Признанная венская шубертианка своего поколения; сильнейший неприоритетный «старый» кандидат с твёрдой датой. Заметно более быстрая трактовка (160 с. против 190–215 у прочих). Против сходной по уровню Бейкер (1970) выбрана по правилу «сходные → более ранняя». Видео: iLD_epGlgBY (Seefried Topic).
4. **Christine Schäfer / Graham Johnson** — зап. февраль 1996; Hyperion Schubert Edition, Vol. 26 «An 1826 Schubertiad» (CDJ33026). Ей 31 — начало пика, свежий голос. Профильный том всего свода Hyperion для D 877: все четыре редакции даны полностью, три песни Миньоны — Шефер соло. Единственная в пуле награда, привязанная именно к диску с этой песней: Gramophone Editor's Choice + «Song Record of the Year» журнала Classic CD. Сильнейший современный кандидат по документированной, а не пиаровской репутации. Видео: q8xO02nDmEc (C. Schäfer Topic).
5. **Carolyn Sampson / Joseph Middleton** — зап. август 2017, ℗ 2018; «A Soprano's Schubertiade» (BIS). Ей 43, внутри пика. Слот «не ранее 2015»: единственный документированный кандидат 2015+ первого ряда (Jaroussky — контратенорная экзотика, Camarinha — вне устоявшегося фонда, обе без установленного года сессии). Тот же альбом, чья Gretchen прошла в топ-5 D 118 с независимыми похвалами MusicWeb и Limelight — репутация альбома установлена ранее, не пиар. Видео: SRgxz--MQrI (Sampson Topic).

Порядок: №1–2 — приоритетные исполнители группы 4 (внутри группы по качеству: Людвиг — документированный год внутри пика; у Э. Шуман состояние голоса зависит от неустановленной даты — при 1945–46 голос уже постаревший); №3 — лучшая из прочих старых; №4–5 — современные по качеству между собой.

## Ключевые отклонённые кандидаты

- **Janet Baker / Moore (1970, HMV SLS 812)** — классика жанра, ядро формы; уровень сопоставим с Зеефрид, уступила по правилу «сходные → более ранняя». Первый резерв старого слота.
- **Bernarda Fink / Huber (2008, HMC 901991)** — самая весомая современная репутация в пуле, но она заработана альбомной Gretchen (со-победитель слепого теста 2020), не этим треком; на Topic трек подписан ошибочным D-номером «D.64/4» (по длительности и альбому это D 877/4); уступила Шефер, чья награда привязана к диску именно с этой песней. Резерв современного слота.
- **Barbara Bonney / Parsons (1994, Teldec)** — сильный документированный кандидат 1990-х (в D 118 взяла современный слот с BBC 5/5), но здесь современных слотов два и оба заняты более сильными по этой песне (Шефер — профильный том с наградами; Сэмпсон — обязательный слот 2015+). Резерв.
- **Elly Ameling / Baldwin (1972, Philips 6500 515)** и **Arleen Augér / Olbertz (1976, Eterna)** — полностью документированы (крупная работа этой сессии досье), но старых слотов три и все заняты приоритетными певцами и Зеефрид.
- **Gundula Janowitz / Gage (1976–77, DG)** — серия с двумя Schallplattenpreis, но неясно, какая из двух сессий дала D 877/4, плюс два официальных ID одной записи; уступает занявшим слоты.
- **Rita Streich / Werba (1960, DG)**, **Judith Raskin / Schick (1966, Columbia)**, **Jan DeGaetani / Kalish (1974, Nonesuch)**, **Hendricks / Lupu (1985, EMI)**, **Lipovšek / Parsons (1988, Orfeo)** — достойный второй ряд старых/доклассических слотов; не дотягивают до занявших места по значительности или документированности.
- **Matthias Goerne / Schneider (2008, HM)** — единственный документированный мужской кандидат; мужской голос в партии Миньоны — интерпретаторски спорный выбор, при наличии сильных профильных сопрано/меццо не включён.
- **Dawn Upshaw / Goode (1994)**, **Röschmann / Martineau (2014)**, **Rubens / Gage (℗ 2000)**, **Meier / Oppitz (1998?)**, **Lott / Johnson (год не установлен)** — второй эшелон современных и/или неустановленные даты.
- **Dorliak / Рихтер (1956, Мелодия)** — поётся по-русски: для сайта с немецким подстрочником исключено, несмотря на Рихтера за роялем.
- **Studer / Gage (1992?, лайв)** и **Stader / Kapell (1953?)** — неофициальные загрузки с недокументированными датами (§Верификация, §Техническая гигиена).
- **M. Price** — Topic-трек от серого агрегатора Classical World Ltd., происхождение неизвестно (её Hyperion Vol. 15 песни не содержит) — к публикации не годен.
- **Maisky (виолончель)** и **Piau (квартетная аранжировка)** — не фортепианный вокальный оригинал; **Jaroussky (2024, контратенор)** — тембровая экзотика вне профиля пятёрки.

## Соответствие возрастной структуре
