# Die schöne Müllerin (D 795) — отбор топ-5 полных записей цикла

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md (цикльный метод, §«Масштабирование», п. 2). Исследование цикла — planning/youtube/data/cycle-muellerin.dossier.json (глубина famous: каждая запись-кандидат исследована отдельно — год по дискографии, состояние голоса, репутация, потрековая YouTube-доступность). Пятёрка едина для всех 20 песен цикла; per-song videoId берутся с официальных/Topic-каналов выбранных изданий. Гейт цикльного метода: запись публикуема, только если цикл доступен на YouTube потреково; проверено выборочно по 2–3 песни на запись (oEmbed + yt-dlp, включая финальные №№ 19–20).

## Итоговый топ-5

1. **Thomas Quasthoff / Justus Zeyen** — зап. 7/2005, Teldex Studio Berlin; DG 474 218-2 (Discogs 4640997, notes). Ему 46 — внутри пика (~1993–2007); последний из шести его шубертовских альбомов (классическую карьеру закрыл в янв. 2012). Приоритет №1 правил; запись достойная (студийный флагман DG в пике) → №1 в каждой песне цикла. Потреково: Thomas Quasthoff - Topic (проверены №№ 1, 7, 18, 20 — oEmbed 200 / yt-dlp). ВАЖНО при подборе videoId: на том же Topic-канале лежит параллельный лайв-комплект «(Live)» (Вербье-2023, с Emanuel Ax) — брать только треки без пометки «(Live)».
2. **Dietrich Fischer-Dieskau / Gerald Moore** — зап. 2–3.12.1961, Berlin-Zehlendorf; Electrola/EMI STE 91187/8, ныне Warner (реестр по дискографии Грея). Ему 36 — середина пика (~1951–1972), стерео; самая тиражируемая его EMI-версия цикла. **Замена внутри слота**: чисто по правилу «при прочих равных — более ранняя» первой была бы версия 1951 г. (HMV, сессии 3–5+7.10.1951, Abbey Road — Грей id 59873; ему 26, вокально самая свежая), но у неё НЕ найдено официальной потрековой загрузки — только «серые» Topic-агрегаторы (Heritage/MVE/BNF), чьи кредиты правилами запрещены как источник, а принадлежность дорожек сессиям 1951 не доказана. Гейт не пройден → слот занимает следующая по рангу версия того же певца: 1961 (пик голоса + официальный Warner-комплект). DG-версия (изд. 1972, 46 лет) уступает как более поздняя. Потреково: Dietrich Fischer-Dieskau - Topic / Warner (проверены №№ 1, 19 — oEmbed 200 / yt-dlp; титульный формат Warner «Op. 25, D. 795: No. …» отличает её от DG-комплекта).
3. **Gerhard Hüsch / Hanns Udo Müller** — зап. 31.01–22.03.1935, Abbey Road, студия № 3 (Грей: id 74340 — 31.01.1935, id 56255 — 02.02.1935, id 53828 — 22.03.1935); HMV DB 2429–2436; переизд. Angel «Great Recordings of the Century», Pearl, Pristine PACO007. Ему 34 — пик; тот же дуэт, что записал эталонную Winterreise 1933. Исторический эталон цикла: klassik-prisma 5 баллов, первая строка мужской таблицы; канонический статус подтверждён серией GRoC. Сильнейшая запись группы «звёзды прошлого» → №3. Поправка реестра: вместо «1934/35» по Грею все проверенные стороны — 1935; год плеера 1935. Потреково: Gerhard Hüsch - Topic (проверены №№ 1, 19 — oEmbed 200 / yt-dlp). Несколько параллельных Topic-комплектов разных переиздателей — при подборе videoId держать один ряд.
4. **Fritz Wunderlich / Hubert Giesen** — зап. 2–5.07.1966, Мюнхен (реестр + Грей; у Грея опечатка «Hubert Green»); DG 139 220. Ему 36 — только пик (погиб 17.09.1966; это последние студийные сессии). Эталон тенорового цикла, одна из самых почитаемых записей Lieder вообще. Второе место старой группы по качеству → №4. Потреково: Fritz Wunderlich - Topic / DG (проверены №№ 1, 7, 20 — oEmbed 200 / yt-dlp). На канале много параллельных комплектов (SWR-радио, ремастеры 2025) — брать альбомный ряд DG (формат «Schubert: Die schöne Müllerin, D. 795: No. …», как CN-OC9vx6tI).
5. **Samuel Hasselhorn / Ammiel Bushakevitz** — зап. 2023; harmonia mundi HMM 902720, т. 1 проекта «Schubert 200» (Discogs 36696394; изд. 22.09.2023). Ему 33 — ранний пик. Diapason d'or октября 2023 и Diapason d'or de l'année — объективные премии, не пресс-релиз (фильтр пиара пройден). Лучший кандидат слота «не ранее 2015» → №5. Потреково: Samuel Hasselhorn - Topic / harmonia mundi (проверены №№ 1, 19, 20 — oEmbed 200 / yt-dlp).

## Отклонённые кандидаты

- **Aksel Schiøtz / Moore (1945)** — ближайший конкурент старой группы (Грей id 57403: 1.11.1945, Abbey Road; 39 лет, последний год полной формы; классика тенорового цикла; потреково доступен — Schiøtz Topic/Danacord). Уступил по консенсусной репутации Хюшу (klassik-prisma 5, GRoC) и Вундерлиху (эталон-бестселлер): в пятёрке только два места старой группы после Ф.-Д. **Первый резерв старой группы.**
- **Ian Bostridge / Graham Johnson (1995, Hyperion т. 25)** — Gramophone Award 1996, голос свежий (31), лучшая из трёх его версий; потреково доступен. Не вошёл только из-за структуры состава: оба «современных» места заняты Квастхофом-2005 (приоритет №1) и слотом ≥2015 (Хассельхорн). **Первый резерв современного места.** Его же версии 2005 (Uchida) и 2020 (Giorgini) уступают по правилу ранней записи и состоянию голоса.
- **Julius Patzak / Raucheisen (радио 1940-х)** — «говорящее» пение для знатоков, но голос скромнее Хюша/Шиотца; год не установлен (допустим формат «194x?», однако мест в старой группе нет); часть Topic-комплектов «(Excerpts)».
- **Hans Duhan (1928)** — первая полная запись цикла в истории; ценность историческая, не художественная; потрековой доступности нет → непубликуем.
- **Peter Pears / Britten (изд. 1960)** — канон дуэта прежде всего Winterreise-1963; тембр на любителя; ниже Хюша/Вундерлиха/Шиотца.
- **Gérard Souzay / Baldwin (1964)**, **Hermann Prey / Hokanson (1973)**, **Peter Schreier / Olbertz (Eterna 1972; потрековость не подтверждена)** — второй ряд старой группы.
- **Peter Schreier / Schiff (сессия VIII.1989, изд. Decca 1991)** — интеллектуальная вершина Шрайера, но 54 года (поздний, суше), и сессия формально до 1990 — «современный» слот не закрывает. Резерв.

- **Jonas Kaufmann / Deutsch (2009)** — максимальный медийный охват при сдержанных оценках специалистов; правило скепсиса к пиару применено напрямую → вне пятёрки.
- **Andrè Schuen / Heide (зап. 5/2020)** и **Konstantin Krimmel / Heide (2023)** — альтернативы слоту ≥2015; у Хассельхорна объективная премия выше (Diapason d'or de l'année). Резервы слота ≥2015.

## Резервы (при выпадении видео)

1. Старая группа: Schiøtz/Moore 1945 → Pears/Britten 1960 → Souzay/Baldwin 1964 → Prey/Hokanson 1973.
2. Современное место (≥1990): Bostridge/Johnson 1995 → Güra/Schultsz 2000 → Goerne/Eschenbach 2008 (с исключением для gate.js по каналу пианиста).
3. Слот ≥2015: Schuen/Heide 2020 → Krimmel/Heide 2023 → Gerhaher/Huber 2016.
4. Слот Ф.-Д.: DG-версия (изд. 1972, Q9XxnkzYVw0 и ряд) — если выпадет Warner-комплект 1961.

## Соответствие правилам состава

3 записи ранее 1990 (1935, 1961, 1966) ✓; 2 записи 1990+ (2005, 2023) ✓; из них 1 запись 2015+ (2023) ✓. Порядок — строгая иерархия: Квастхоф (№1) → Фишер-Дискау (№2) → звёзды прошлого по качеству (Хюш → Вундерлих) → современные (Хассельхорн). Год плеера: у всех пяти — год сессий по дискографии (Discogs notes / Грей / реестр); сквозная унификация по альбомам соблюдена.

## Пер-песенная проверка: «Ungeduld» (D 795/7)

Дата: 2026-08-17. Основание — правило цикльного метода: песни цикла с самостоятельной концертной жизнью дополнительно проходят обычное пер-песенное исследование. Проверялись внецикльные записи именно этой песни (одиночные стороны 78 об., рециталы, сборники), а не цикльные комплекты.

Самостоятельная жизнь песни подтверждена документально: в дискографии Грея по запросу work=Ungeduld — 39 позиций, почти сплошь одиночные стороны, от Наваля (X.1909) и Хемпель (23.10.1922) до Шока (14–18.VI.1968); традиция преимущественно теноровая (Слезак, Земба́х, Гро, Й. Шмидт, Шиотц, Бут, Шок, Рети). Это единственный номер цикла, который в 78-эпоху жил отдельной пластиночной жизнью в таком объёме.

### Вытеснение цикльной позиции: Шварцкопф

- **Elisabeth Schwarzkopf / Gerald Moore, зап. 9–10 января 1954, EMI Abbey Road Studio I.** Источник даты — потрековые notes реставрации Naxos Historical 8.111287 (Discogs release 25991449: «Tracks 13–14 recorded 9th and 10th January, 1954 in EMI Abbey Road Studio I»; трек 14 — Ungeduld, трек 13 — Litanei D 343). Более ранний дубль той же связки Грей фиксирует как неизданный: id 25760 — 21.09.1952, Abbey Road St. 1, матрица CA 22322, «UNISSUED»; изданная фонограмма, следовательно, — переделка 1954 г. Ей 38 (р. 9.12.1915) — внутри пика 1948–1964; шубертовские Columbia-78 с Муром 1948–54 названы одной из опор её шубертовской репутации (planning/research/schubert-singers.md, реестр female-recitalists.md). Первая публикация — Columbia LP «A Lieder Recital» (33CX 1044), далее Warner-переиздания (Icon; бокс «The Complete Recitals 1952–1974»).
- По иерархии правил Шварцкопф — №3 (топ-1 среди женщин), качество как квалификационный фильтр пройдено → она входит в пятёрку **этой** песни и сдвигает старую группу на одну позицию. Женское исполнение «Ungeduld» — не курьёз, а часть традиции самой песни (Хемпель 1922, Джаннини 1929, Беттендорф 1937, Лемáн 1935 — все в списке Грея).
- **Побочный факт для сквозной унификации (за рамками этой песни):** Litanei D 343 — из той же сессии 9–10.01.1954. В `planning/research/d343-am-tage-aller-seelen-top5.md` и в `performances.json` она стоит как «1952–54?» по неустановленности года; находка закрывает этот вопрос — год 1954. Требуется отдельный проход по D 343.

### Кто уступает место

- **Gerhard Hüsch / H. U. Müller (сторона Ungeduld — 5 февраля 1935, Abbey Road St. 3, HMV DB 2431; Грей).** Цикльный эталон в целом сохраняется, но единственный оставшийся слот старой группы отдан Вундерлиху: (1) «Ungeduld» — экстравертный высоколежащий номер, самостоятельная дискографическая жизнь которого теноровая (см. выше), и запись Вундерлиха — референс именно этой традиции; (2) её отдельная концертная жизнь подтверждается тем, что DG раз за разом выносит номер в антологии («Fritz Wunderlich sings», «Ich liebe dich»); (3) Шварцкопф-1954 уже представляет в пятёрке исторический моно-слой. Хюш — **первый резерв** (wNSgGhvgny0, Gerhard Hüsch - Topic, oEmbed 200).

## D 795/2 «Wohin?» — пер-песенная проверка (2026-08-17)
