## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — свод DG «Sämtliche Lieder» (℗ 1969; сессии свода 1966–72, ему 41–44 — поздний пик, тон ещё полный). Высший доступный приоритет: Квастхоф песню не записывал (дискография закрыта в 2012 — проверено по MusicBrainz, Discogs и трек-листам), Шварцкопф записала, но её версии нет на YouTube. Ранняя EMI-версия 1962 г. (Electrola E/STE 91 204) официально не выложена — единственная похожая загрузка идёт от серого агрегатора без верифицированной атрибуции; берём DG-версию, официальную и самую слушаемую загрузку песни вообще (~47,5 тыс.). Год 1969 — сквозной год DG-свода по всему корпусу (унификация). Видео: ZUB-AfeFXEY (Fischer-Dieskau Topic, официальная Universal).
2. **Irmgard Seefried / Erik Werba** — DG 136 009, сессии 30.05 + 3, 7–8.06.1958 (по Грею); ей 39 — внутри пика. Сильнейшее внешнее свидетельство во всём пуле: редакция Diapason выбрала именно эту запись как эталонное прочтение D 777 для антологии «Les Indispensables de Diapason № 160: 22 Lieder» (2023) — единственный найденный «обзор с вердиктом» по песне; сама DG взяла её же в витринную антологию «Am Brunnen vor dem Tore». Внутри группы «старых мастеров» это ставит её выше по качеству. Видео: yE7e4TfWPXc (Seefried Topic, Universal, «The Art of Irmgard Seefried, Vol. 5»).
3. **Elisabeth Schumann / Gerald Moore** — HMV DB 3184, ок. 5–15 марта 1937 (датировка по матрицам 2EA 4849/4850); ей 48 — конец большого пика, голос ещё свеж, стиль эталонный. Именной приоритет правил; классика шубертовской дискографии 78-х, довоенный венский стиль — исторический слот пятёрки. Берём Warner-загрузку («Icon», кредит «Piano: Gerald Moore»); расхождение кредитов Naxos-загрузки (Reeves) отклонено — каталожная страница Naxos и Warner дают Мура. Видео: J-CO4dWV5pU (E. Schumann Topic, Warner).
4. **Bernarda Fink / Gerold Huber** — рецитал harmonia mundi, зап. 2007; ей 52, внутри пика. Сильнейший современный кандидат по внешнему признанию: тот же альбом дал со-победителя слепого теста 2020 по Gretchen (наряду со Шварцкопф/Фишером) — единственный современный диск пула с таким подтверждением; 5,9 тыс. просмотров — заметно для этой песни. Закрывает первый слот 1990+. Видео: rx7jYdf2uz0 (Fink Topic, harmonia mundi).
5. **Florian Boesch / Malcolm Martineau** — Onyx 4149 «Schubert: Lieder Recital», ℗ 2016; ему ~45, внутри пика. Единственный пригодный кандидат «не ранее 2015» (запись Кут/Дрейка 2017 дисквалифицирована: Hyperion издал песню двумя отдельными треками, целого ролика нет). Достойность не квотная натяжка: «рассказчик венской школы» (дайджест), альбом уже отобран проектом для D 805 и D 806. Видео: 4iGtxRJM-cg (Boesch Topic).

Порядок: № 1 — группа Фишера-Дискау; № 2–3 — «прочие звёзды прошлого» между собой по качеству (у Зеефрид — единственный внешний вердикт именно по этой песне); № 4–5 — современные между собой по качеству (у Финк внешнее признание сильнее).

## Ключевые решения и отклонённые кандидаты

- **Квастхоф** — песню не записывал (негатив верифицирован трижды: MusicBrainz, Discogs track-поиск, полный трек-лист «Widmung» 2004). **Хоттер, Андерс** — собственных записей не выявлено (полная выдача Грея + Discogs; их имена всплывают только в сборниках, где D 777 поёт Зеефрид).
- **Schwarzkopf / Moore (EMI 1955–64, изд. Testament SBT 1206, 2000)** — приоритет № 3 записал песню, но на YouTube её нет ни в каком виде (четыре целевых поиска, включая её Topic-канал). Первый кандидат на пересмотр пятёрки при появлении официальной загрузки.
- **Christa Ludwig** — именной приоритет, но лучшая версия (Parsons, сессии 28–30.11.1961, Abbey Road — по Грею) на YouTube отсутствует; доступен только DG-ремейк с Гейджем (℗ 1974) — на десять лет позже, второй взгляд без критического следа. Прецедент Попп: доступная запись слабее её же лучшей — в пятёрку не идёт, остаётся первым резервом старой группы.
- **Kathleen Ferrier / Britten (Decca, 4.02.1952)** — сильная альтернатива слотам 2–3: почитаемый дуэт, последний полный год её работы. Уступила Зеефрид (внешний вердикт Diapason) и Э. Шуман (именной приоритет); в Gretchen её же оценивали ниже старших мастеров (klassik-prisma 4/5, «сдержанные эмоции»). Резерв.
- **Kirsten Flagstad / McArthur (HMV, 28.06.1937)** — дата документирована матрицей, но дайджест прямо предупреждает: Шуберт у неё вторичен, манера монументальная, не камерная — для короткой, почти скерцозной песни это дисквалифицирующий минус.
- **Hermann Prey / Hokanson (1971 по Грею)** — достойная запись пика, но в старой группе слоты заняты более сильными кейсами; нерешённое расхождение лейбла/года (Philips у Грея / DG ℗ 1974) требовало бы доисследования. Близкий резерв.
- **Elly Ameling / Demus (℗ 1970)** — хороша, но без внешнего вердикта и с неснятым расхождением даты (~1965 против ℗ 1970).
- **Erna Berger / Raucheisen (1942–45)** — форма певицы в те годы не верифицирована (карточки в дайджесте нет); уступает верифицированным кейсам.
- **Bryn Terfel / Martineau (февр. 1994, DG)** — документированный год, бестселлер DG; уступил Финк (у той внешнее подтверждение слепым тестом) — первый резерв современного слота.
- **Barbara Hendricks / Lupu (℗ 1993)**, **Arleen Augér / Orkis (℗ 1991)** — достойные кандидаты 1990+, уступили Финк по силе внешнего признания.
- **Kathleen Battle / Levine (℗ 1988)** — устоявшейся Lieder-репутации нет, правило скепсиса к «звёздным» рециталам.
- **Matthias Goerne / Schneider (изд. 2014)** — в квоту 2015+ не попадает; в квоте 1990+ уступил Финк (правило скепсиса к прессе о современных).
- **Ian Bostridge / Andsnes (℗ 2008)** — дайджест предупреждает о манерности/сухости позднего периода; серия ценится за пианиста.
- **Alice Coote / Drake (зап. 2017, Hyperion 2022)** — ДИСКВАЛИФИКАЦИЯ по форме издания: D 777 разбита на два трека (52 + 63 с), целой песни одним роликом нет.
- **Peter Pears / Britten** — год сессии не установлен (℗ 1975 — только год фонограммы; возможно, ему было 60–65 — за пиком); без датировки не публикуется.
- **Недоступны на YouTube**: Schreier/Olbertz (Eterna 1974), Köth/Moore (1963), Mathis/Engel (1988), Popp (только лайв Covent Garden 1975, Gala — не выложен). **Vanni Marcoux (1928)** — поёт по-французски, вне пула по существу.

## Соответствие возрастной структуре

3 записи ранее 1990 (1969, 1958, 1937) ✓; 2 записи 1990+ (2007, 2016) ✓; из них 1 запись 2015+ (2016) ✓. Оба современных слота заняты кандидатами с независимой аргументацией (слепой тест у Финк; венская повествовательная репутация и корпусная преемственность у Бёша), не в ущерб качеству.
