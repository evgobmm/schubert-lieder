**факт-проверка** пяти записей применительно к «Täuschung» (№19 цикла): кто поёт/играет, точный год, издание, источник.

norpete.com, allmusic — упомянуты по ходу), Discogs API (`api.discogs.com`, без токена — работает из контейнера по правилу
`youtube-performances.md`/«Верификация данных»), прямое чтение архивной карточки на archive.org. Реестр альбомов проекта

## Итог по фактам

Все пять записей — подлинные, относятся к нужному исполнителю/инструменту/циклу и подтверждены хотя бы одним независимым
источником (Discogs API, archive.org, профильные обзоры); ни одна не подлежит замене. Единственная найденная неточность —
не в отборе, а в моём собственном первом (поисковом) проходе по Андерсу: месяц первой сессии — январь, не февраль; в файле
это исправлено по первоисточнику. Год сессии Квасthoff/Спенсер (1997 vs. год издания 1998) остался неподтверждён дословной
цитатой первоисточника в рамках сетевого бюджета — не противоречит найденному, но и не проверен строго; при появлении
времени стоит донайти буклет RCA.

**Наблюдение по порядку (не факт-ошибка, менять не предлагаю)**: правило «строгая иерархия приоритетов» (`youtube-performances.md`)
требует порядок Квасthoff → Фишер-Дискау → Шварцкопф → прочие звёзды прошлого → современные — то есть Маттеи (современный)
должен идти последним, после Андерса и Хоттера, а не вторым. В файле реестра порядок фиксирован для всех 24 песен цикла
разом (перенос из референса, единая структура «performers»), и его правка — решение по циклу целиком, а не по одной песне;
явно выходит за рамки этой задачи («поток Winterreise не пересматривает») и `performances.json` не тронут. Фиксирую для
сведения куратора цикла.
