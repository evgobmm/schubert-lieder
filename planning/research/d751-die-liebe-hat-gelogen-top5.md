# Die Liebe hat gelogen (D 751) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: `docs/rules/youtube-performances.md`. Ярус — famous (`planning/youtube/triage.json`). Досье: `planning/youtube/data/d751-die-liebe-hat-gelogen.dossier.json` (дискография Грея — 10 документированных сессий 1927–1973, Discogs API, Hyperion, Delphian, реестр альбомов, MusicBrainz-каркас). Все 5 итоговых видео и 3 резервных проверены через oEmbed в этой сессии (живы, официальные Topic-каналы). Сравнительного обзора записей песни (klassik-prisma, слепой тест) не существует — проверено в досье; ранжирование опирается на статус исполнителей, состояние голоса и документированность записей.

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — DG «Sämtliche Lieder» (21 CD), сессии 1966–72; в плеере 1969 — сквозная конвенция корпуса для этого свода (~150 уже опубликованных песен). Певцу 41–47 — исход пикового периода ~1951–1972 (singers-digest), голос полностью управляем. Базовый свод мужских песен Шуберта, «лучший охват среди всех»; приоритет №2 по правилам (Квастхоф песню не записывал — см. негативы). Видео: KCGkDRkVcCI (Fischer-Dieskau Topic, 140 с; самая просматриваемая из трёх Topic-загрузок одной записи).
2. **Elisabeth Schwarzkopf / Gerald Moore** — live, Зальцбургский фестиваль; Orfeo C 826 103 «Lieder von Schubert & Wolf» (серия Salzburger Festspieldokumente, 3 CD, 2010; цифровое переиздание ℗ 2019 «Schubert & Wolf: Lieder (Live)»). Точный вечер не установлен; в плеере «1957–63?» — определение проекта по этому же альбому (top5-файл D 776): бокс покрывает 1953–1963, зальцбургские Liederabend'ы с Муром — с 1957, вольфовский вечер 1953 аккомпанировал Фуртвенглер. Весь диапазон — внутри её пика (1948–1964). Топ-1 среди женщин по правилам (приоритет №3); её единственная запись песни. Видео: CGpOLNmOAQw (Schwarzkopf Topic, 181 с).
3. **Hans Hotter / Michael Raucheisen** — Берлин, 1944, радиозаписи Рейхсрундфунка; год по примечанию переиздания Grammofono 2000 AB 78690 «18 Lieder» (Discogs 27318492: «Recordings: 1944», трек 13 — D 751, 2:52). Певцу 34–35 — сердце пика ~1942–1955, до отяжеления голоса. Приоритетный исполнитель (п. 4 правил); военный корпус с Раухайзеном — основа его Шуберта тех лет; тёмный бас-баритон — редкая и веская краска для этой мрачной песни Платена. Год 1944 согласован с корпусом (D 842 — тот же корпус Раухайзена, 1944). Видео: dEn43f1--XM (Hotter Topic, 178 с).
4. **Matthias Goerne / Eric Schneider** — Goerne Schubert Edition, т. 8 «Wanderers Nachtlied» (harmonia mundi HMC 902109-10); D 751 — CD2, трек 17 (2:33 в буклете = 153 с загрузки, идентификация точная); сессии CD2 — VI.2011 и II.2012, Teldex (Discogs 20022025); в плеере 2014 — год издания тома, конвенция проекта для свода Гёрне (как в D 100, D 101, D 120, D 174, D 280, D 288). Певцу 44–45, внутри пика ~1997–2015; самый записываемый Schubert-баритон поколения, крупнейший сольный свод последних десятилетий. Сильнейший современный кандидат с видео. Видео: H38YQLE0-EU (Goerne Topic).
5. **Florian Boesch / Malcolm Martineau** — Schubert: Lieder Recital (ONYX 4149), издание 20.05.2016 (год сессии не установлен; 2016 — сквозной год альбома в корпусе: D 225, D 226, D 254, D 257, D 367, D 686, D 691, D 719, D 805). Певцу 45, внутри пика ~2010–наст.; «рассказчик венской школы» — декламационная повествовательность к лицу лаконичной жалобе Платена. Единственный публикуемый кандидат слота «не ранее 2015» (лучший по критике претендент Бёрнс — без видео, см. ниже). Видео: BG684pcnOO8 (Boesch Topic, 158 с).

## Ключевые решения и отклонённые кандидаты

- **Порядок** — строгая иерархия приоритетов: Квастхоф отсутствует (не записывал), поэтому №1 — Фишер-Дискау, №2 — Шварцкопф, №3 — Хоттер (звезда прошлого из именного списка), затем современные по качеству между собой: Гёрне выше Бёша (масштаб шубертовского корпуса и репутация свода против рецитала, в котором критика хвалила прежде всего аккомпаниатора).
- **Gérard Souzay / Dalton Baldwin (1961, Philips)** — сильнейший из невключённых: сердце зрелой формы (пик 1950-е — сер. 1960-х), двойное дискографическое подтверждение сессий 18–23.06.1961 (Грей + Discogs 21699958/12779819). Уступил место современным слотам состава (оба современных кандидата достойны); первый резерв.
- **Elly Ameling / Dalton Baldwin (1973, Philips 6500 704)** — пик самой записываемой шубертианки поколения, сессия документирована Греем (21–26.08.1973). Та же логика состава; резерв.
- **Jessye Norman / Geoffrey Parsons (1987, live Шубертиада Хоэнемс)** — голос в полной силе, но монументальная манера для интимной песни Платена — спорный выбор (скепсис зафиксирован в досье); ниже Сузе и Амелинг по соответствию жанру.
- **Harriet Burns / Ian Tindale (Delphian, зап. 8–10.02.2023)** — лучший по критике современный кандидат с прямой похвалой именно этой песни (Gramophone 4*: начало «like a Handelian queen», «dignity and grace»), но отдельной загрузки D 751 на YouTube нет ни у Delphian, ни на Topic — непубликуема. Кандидат №1 на пересмотр слота 2015+, если загрузка появится.
- **Barbara Hendricks / Radu Lupu (EMI, ℗ 1993)** — ценность прежде всего в пианисте; как запись слота «с 1990» уступает Гёрне; современный резерв.
- **Исторические 78-е**: Erb/Seidler-Winkler (1937) — документ довоенного стиля, но певцу 59, далеко за пиком; Ginster/Moore (1935) — на пике, но фигура второго ряда («слабейший охват фонда» в дайджесте); Völker (1941) — вне фонда проекта; McCormack (1927) — «резерв» фонда, немецкий стиль на любителя. Все уступают тройке старых мастеров по значительности.
- **Прочие**: Shirai (℗ 1997), Koningsberger/Johnson (1996, Hyperion т. 28 — ценность научная, певец не звезда), Partridge (1999, за пиком), Gedda и de los Ángeles (год/альбом не установлены — в пятёрку без атрибуции нельзя), Flagstad («Шуберт вторичен, манера монументальная» — дайджест), Elsner (том Naxos не идентифицирован). Krenn (1970) и Schock (1965) — без отдельного трека на YouTube; Hayes — обе сессии Columbia не изданы (UNISSUED у Грея).
- **Негативы приоритетов** (из досье, проверено по MusicBrainz-каркасу, yt-dlp и дискографиям): Квастхоф (дискография закрыта, ни один из 6 альбомов не может содержать песню Платена), Андерс, Э. Шуман, Людвиг, Попп записей D 751 не имеют.

## Соответствие правилам состава

3 записи ранее 1990 (1944; «1957–63?»; свод DG 1966–72 → 1969) ✓; 2 записи 1990+ (2014, 2016) ✓; из них 1 запись 2015+ (2016) ✓. Современные слоты заняты достойными кандидатами (крупнейший сольный свод поколения; рецитал уважаемого венского рассказчика), не в ущерб качеству: единственный современный кандидат с независимой похвалой именно этого трека (Бёрнс) непубликуем без видео.
