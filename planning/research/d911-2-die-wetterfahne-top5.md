## Порядок пятёрки — обязательное исправление

В `performances.json` сейчас порядок: **Quasthoff → Mattei → Fischer-Dieskau → Anders → Hotter.** Это нарушает строгую иерархию приоритетов правила (`docs/rules/youtube-performances.md`, «Приоритетные исполнители»): «1. Квасхоф — всегда №1 … 2. затем Фишер-Дискау … 4. затем прочие звёзды прошлого … 5. затем современные». Маттеи (совр. исполнитель, не входит в список приоритетных) стоит на позиции №2 — перед Фишер-Дискау, что правилом прямо запрещено («не хронология и не голый рейтинг критики»).

**Правильный порядок: Quasthoff → Fischer-Dieskau → Anders → Hotter → Mattei.** Взаимный порядок Anders/Hotter (оба — «прочие звёзды прошлого», между собой по качеству) сохранён таким, какой уже был в файле (Anders выше Hotter) — этот файл не переисследовал их сравнительное качество заново, только сдвинул обе записи выше записи Маттеи и зафиксировал, что Фишер-Дискау обязан идти следом за Квасхофом. Пофамильно состав пятёрки не меняется — меняются только порядок и один videoId (см. выше).
