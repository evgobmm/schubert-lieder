# An die Leier (D 737) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Ярус песни — famous (мужской репертуар; ~20 записей в MusicBrainz, 14 сессий в дискографии Майкла Грея). Досье: planning/youtube/data/d737-an-die-leier.dossier.json; все итоговые и резервные ролики проверены через oEmbed (живы, Topic-каналы).

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Jörg Demus** — зап. 24–25.11.1961, Berlin, Studio Lankwitz; DG SLPM 138 715, ℗1962 (дискография Грея, id=76885). Ему 36 — середина главного пика (~1951–1972), голос ещё свежий и полный. Приоритет № 2 проекта (Квастхоф песню не записывал — см. негативы); из двух его студийных версий по правилу «при прочих равных — более ранняя» выбрана версия с Демусом, а не свод с Муром (℗1969): голос в 1961 свежее, а критических данных, различающих версии, нет. Видео: IqAs2-Ezals (FD-Topic, официальный цифровой сборник «Schubert: Songs», UMG/DG).
2. **Heinrich Schlusnus / Franz Rupp** — зап. 1928, Berlin, Hochschule für Musik, Polydor 66776, матрица bm 1192 (Грей, id=63978; год — по буклету Nimbus NI 7883, трек озаглавлен «Recorded 1928»). Ему ≈40 — вокальный пик; эталон немецкого лирического баритона своего поколения, образцовое баритоновое «бельканто». Nimbus отобрал номер в свой шубертовский рецитал певца (Prima Voce, 1997). Пара Шлуснус-1928 / Бьёрлинг-1940 — записи сходного уровня без сравнительной критики (klassik-prisma страницы по D 737 не имеет), поэтому внутри группы «звёзды прошлого» действует правило «сходные по уровню — более ранняя»: Шлуснус выше. Плюс идиоматика: родной немецкий стиль в немецкой песне. Видео: ntjHmrZwB9o (Schlusnus-Topic, официальная загрузка Nimbus NI 7883).
3. **Jussi Björling / Harry Ebert** — зап. 30.01.1940, New York, Victor Studio No. 2, матрица CS 046744-1; Victor 12831 / HMV DB 5787 (Грей, id=77992; независимо — буклет Naxos Historical 8.110789S, Discogs 11230272). Ему 28 — абсолютный вокальный пик, полное «серебро» верхнего регистра. An die Leier — фирменный шубертовский номер Бьёрлинга: держал его в программе и через 18 лет (Карнеги-холл, 1958). Видео: Wi3SfnNDHPU (Björling-Topic; переиздание PD-агрегатора Vax Records — лейбловой загрузки версии 1940 г. нет, резерв — официальный Sony-лайв 1958, см. ниже).
4. **Thomas Hampson / Graham Johnson** — зап. 5–8.10.1991, Rosslyn Hill Unitarian Chapel, London; Hyperion Schubert Edition, т. 14 «Schubert & the Classics» (CDJ33014; буклет — Discogs 7179319, подтверждено hyperion-records.co.uk). Ему 36 — ранний пик (~1988–2005), голос свежий, без позднейшей манерности. Единственная запись песни с независимой критической поддержкой (Gramophone: «Johnson's piano at its probing best»; CDReview) и единственная, обеспеченная научным комментарием (аннотации Джонсона — единственный найденный содержательный разбор D 737). Сильнейший кандидат слота «не ранее 1990». Видео: 2aiOYfE1cVU (Hampson-Topic, ℗1992 Hyperion).
5. **Benjamin Appl / Graham Johnson** — концерт 27.03.2015, Wigmore Hall (Discogs 20004631: «Recorded live on 27 March 2015»; релиз WHLive0082 — 29.04.2016). Певцу 32–33 — начало зрелого периода; лёгкий, гибкий баритон, последний частный ученик Фишера-Дискау; за роялем — самый знающий шубертовский концертмейстер. Единственный официальный кандидат «не ранее 2015» (Wigmore-версия Бостриджа ℗2018 — певцу ~53, голос суше, дата концерта не установлена); включение не в ущерб качеству: живой вечер достойного уровня, без критических возражений в найденных источниках. Видео: ddT76LnCMIE (Appl-Topic, ℗2016 The Wigmore Hall Trust).

## Ключевые решения и отклонённые кандидаты

- **Квастхоф — записи нет** (проверены все 6 его шубертовских альбомов + трек-лист «Widmung» 2004 по Discogs 9880429; MusicBrainz и YouTube пусты). Из приоритетных певцов песню записал только Фишер-Дискау; Шварцкопф, Хоттер, Андерс, Э. Шуман, Людвиг, Попп — следов нет ни в MusicBrainz, ни у Грея, ни на YouTube (репертуарно объяснимо: анакреонтический «мужской» текст).
- **Fischer-Dieskau / Moore (свод DG, ℗1969)** — вторая версия того же певца; уступает по правилу «более ранняя при прочих равных» (в 1969 голос плотнее, «инструментальнее»). Первый резерв.
- **Björling / Schauwecker, Карнеги-холл 02.03.1958** — официальный Sony-источник, но певцу 47, голос за пиком, линия тяжелее студийной 1940 г.; по правилу «сходные — более ранняя» и по вокалу проигрывает версии 1940. Резерв на случай проблем с PD-загрузкой 1940 г.
- **Terfel / Martineau (DG, зап. II.1994)** — сильный молодой голос, бестселлер DG, но германский стиль небезупречен, а критическая поддержка альбома относится к Erlkönig, не к этому номеру; уступил Хэмпсону (прямая критика диска + научный статус). Резерв современного слота.
- **Goerne / Metzmacher (HM, зап. 2008–09)** — крупный свод, но отдельной критики по номеру нет, Метцмахер за роялем — своеобразие, не гарантия; скепсис к пиару современных. Не прошёл.
- **Bostridge / Drake (EMI 2001)** — самое медленное прочтение пула (4:50 против 3:45–4:20 у старых мастеров), риск статичности. Не прошёл; Wigmore-версия 2018 отклонена и по состоянию голоса.
- **Prey / Engel (DG ℗1974)** — достойная запись внутри пика, но группа «до 1990» уже занята тремя более сильными; версия 1971 с Хоканссоном (Philips, Грей id=176411) на YouTube отсутствует.
- **Haefliger / Dähler (Claves 1986, хаммерклавир 1820)** — периодная перспектива, но певцу 67, «голос уже сухой» (реестр: «вокально компромисс»). Не прошёл.
- **Souzay / Baldwin** — источник записи не установлен (нет ни у Грея по D 737, ни в MusicBrainz; только фан-загрузка); публиковать нельзя.
- **Greindl / Klust (1949, 1957)** — дискографически документированы, но на YouTube не выложены; **Borg / Raucheisen (1953)** и **Farrell (℗1960)** — маргинальны для фонда; **Bartoli / Schiff (Decca ℗1993)** — почти наверняка итальянский текст («Lo vuo' cantar di Cadmo»), для немецкоязычного плеера непригодна.

## Соответствие правилам состава

3 записи ранее 1990 (1928, 1940, 1961) ✓; 2 записи 1990+ (1991, 2015) ✓; из них 1 запись 2015+ (2015) ✓. Оба современных слота заняты без ущерба качеству: Хэмпсон — с независимой критикой, Аппль — единственный достойный официальный кандидат 2015+.
