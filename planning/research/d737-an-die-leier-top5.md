# An die Leier (D 737) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Ярус: famous (мужской репертуар; ~20 записей в MusicBrainz, 14 сессий в дискографии Майкла Грея). Основа — досье `planning/youtube/data/d737-an-die-leier.dossier.json`; все 5 итоговых видео проверены через oEmbed (живы, встраиваемы, Topic-каналы).

Особенность фонда: сравнительной критики по песне почти нет (страницы klassik-prisma по D 737 не существует, слепых тестов не найдено; единственный содержательный разбор — аннотации Грэма Джонсона к тому 14 Hyperion). Поэтому ранжирование опирается на дискографически документированное состояние голоса, репутацию исполнителей и правила проекта, а не на рейтинги по конкретному номеру.

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Jörg Demus** — зап. 24–25.11.1961, Berlin, Studio Lankwitz; DG SLPM 138 715 (℗1962). Дата — дискография Грея (modalcontent.php?id=76885). Певцу 36 — середина главного пика (~1951–1972), голос ещё полный, до сухости середины 1970-х далеко. Приоритет № 2 проекта (Квастхоф песню не записывал — см. негативы); из двух его студийных версий по правилу «при прочих равных — более ранняя» выбрана версия с Демусом, а не свод с Муром (℗1969, конец пика, тон плотнее). Видео: IqAs2-Ezals (FD Topic, официальный цифровой сборник UMG «Schubert: Songs»).
2. **Jussi Björling / Harry Ebert** — зап. 30.01.1940, New York, Victor Studio No. 2; Victor 12831 / HMV DB 5787, матрица CS 046744-1 (Грей, id=77992; независимо — буклет Naxos Historical 8.110789S). Певцу 28 — абсолютный вокальный пик. An die Leier — фирменный шубертовский номер Бьёрлинга (держал в программе и через 18 лет, Карнеги-холл 1958); Naxos отобрал запись в специальный том «Lieder och sånger». Внутри группы старых мастеров поставлен выше Шлуснуса: за записью — уникальная именная ассоциация певца с этой песней, а не только общая репутация. Видео: Wi3SfnNDHPU (Björling Topic; переиздание PD-агрегатора Vax Records — единственная доступная загрузка версии 1940 г.; официальный Sony-лайв 1958 г. — в резерве).
3. **Heinrich Schlusnus / Franz Rupp** — зап. 1928 (год — по буклету переиздания Nimbus Prima Voce NI 7883, 1997; сессия — Polydor 66776, Berlin, Hochschule für Musik, матрица bm 1192, Грей id=63978). Певцу ≈40 — вокальный пик; эталон немецкого лирического баритона своего поколения, образцовая кантилена. Самая ранняя запись пятёрки — исторический слот. Из двух его версий (1928 Rupp / 1938 Peschko) на YouTube опознана только 1928-я — она же более ранняя. Видео: ntjHmrZwB9o (Schlusnus Topic, официальная загрузка Nimbus; не сборник M.A.T. с перепутанными кредитами).
4. **Thomas Hampson / Graham Johnson** — зап. 5–8.10.1991, Rosslyn Hill Unitarian Chapel, London; Hyperion Schubert Edition, т. 14 «Schubert & the Classics» (CDJ33014, изд. 1992). Певцу 36 — ранний пик (~1988–2005), голос свежий, без поздней манерности. Сильнейший документированный современный кандидат: том научного свода Джонсона с реальной (не пиарной) критикой — Gramophone («Johnson's piano at its probing best»), CDReview; единственная запись песни, обеспеченная научным комментарием. Видео: 2aiOYfE1cVU (Hampson Topic, ℗1992 Hyperion).
5. **Benjamin Appl / Graham Johnson** — концерт Wigmore Hall 27.03.2015; «Schubert — Wigmore Hall Live», ℗2016 The Wigmore Hall Trust. Дата сессии документирована: Discogs release 20004631 (WHLive0082, barcode 5065000924836), notes: «Recorded live on 27 March 2015» — прежнее противоречие реестра «дата концерта vs дата издания» снято (29.04.2016 — только дата цифрового релиза); по правилу проекта публикуем год сессии 2015. Певцу 32–33 (р. 1982) — начало зрелого периода; лёгкий, гибкий баритон, последний частный ученик Фишера-Дискау; за роялем — самый знающий шубертовский концертмейстер. Единственный официальный кандидат «не ранее 2015»; пиар-фактор высок, но живой Wigmore-концерт с Джонсоном — содержательный аргумент, не маркетинговый. Видео: ddT76LnCMIE (Appl Topic).

## Ключевые решения и отклонённые кандидаты

- **Год Appl/Johnson — 2015, не 2016.** Верификация вскрыла дату сессии: Discogs release 20004631 (Wigmore Hall Live WHLive0082, barcode 5065000924836 — тот же альбом, что официальная загрузка ℗2016 The Wigmore Hall Trust), notes: «Recorded live on 27 March 2015». Противоречие реестра «29.04.2016 — концерт или издание?» снято: 29.04.2016 — дата релиза, концерт — 27.03.2015. По правилу «год записи (сессии), если документирован» в поле year идёт 2015; условие «1 запись не ранее 2015» выполняется по-прежнему.
- **Квастхоф — песни нет** (проверены все 6 его шубертовских альбомов + трек-лист «Widmung» 2004 по Discogs 9880429). Из приоритетных певцов запись есть только у Фишера-Дискау: Шварцкопф, Хоттер, Андерс, Э. Шуман, Людвиг, Попп — следов нет ни в MusicBrainz, ни у Грея, ни на YouTube (репертуарно объяснимо: «мужской» анакреонтический текст).
- **Fischer-Dieskau / Moore (свод, ℗1969)** — та же ниша, что № 1; правило «более ранняя при прочих равных» отдаёт место версии с Демусом 1961 г. Резервом не ставим — при смерти видео № 1 замена очевидна (rHFWlNUW5Uw).
- **Björling / Schauwecker, Карнеги-холл 02.03.1958** (RCA/Sony, официальная загрузка) — голос за пиком (47 лет, за два года до смерти), линия тяжелее студийной 1940 г.; уступает по вокалу, выигрывает лишь чистотой источника. Резерв № 1 на случай смерти загрузки 1940 г.
- **Prey / Engel (DG, ℗1974)** — достойная запись внутри пика, но четвёртым «до-1990» слотом жертвуем в пользу возрастной структуры (2 записи 1990+); уступает тройке старых мастеров по значительности. Резерв.
- **Terfel / Martineau (DG, 1994)** — бестселлер DG, голос молодой и крупный, но германский стиль не безупречен, а критика альбома относится к Erlkönig, не к этому номеру; уступил Хэмпсону (научный свод + документированная пресса). Резерв современного слота.
- **Goerne / Metzmacher (HM, 2008–2009)** — крупный свод, но за роялем дирижёр, не концертмейстер; отдельной критики нет; слот 1990+ занят более сильным Хэмпсоном.
- **Bostridge / Drake (EMI, 2001)** — самое медленное прочтение пула (4:50 против 3:45–4:20 у старых мастеров), риск статичности; его же Wigmore-версия ℗2018 — певцу ~53, голос суше. Оба варианта уступают.
- **Haefliger / Dähler (Claves, 1986, хаммерклавир Brodmann 1820)** — периодный интерес, но 67 лет, «голос уже сухой»; вокально компромисс.
- **Borg / Raucheisen (1953), Farrell (℗1960), Bartoli / Schiff (℗1993 — почти наверняка итальянский текст «Lo vuo' cantar di Cadmo»)** — маргинальные кандидаты, в пятёрку не претендуют.
- **Souzay / Baldwin** — только фан-загрузка без установленного издания (у Грея и в MusicBrainz по D 737 Сузе отсутствует); публиковать нельзя. **Greindl / Klust (1949, 1957)** — дискографически значимые записи без единой загрузки на YouTube; отпадают технически.

## Соответствие возрастной структуре

3 записи ранее 1990 (1928, 1940, 1961) ✓; 2 записи 1990+ (1991, 2015) ✓; из них 1 запись 2015+ (2015, концерт 27.03.2015) ✓. Порядок — строгая иерархия приоритетов: Фишер-Дискау (приоритет № 2) → старые мастера по качеству (Бьёрлинг, Шлуснус) → современные по качеству (Хэмпсон, Аппль).
