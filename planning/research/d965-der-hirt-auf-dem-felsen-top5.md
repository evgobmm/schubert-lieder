# Der Hirt auf dem Felsen (D 965) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: `docs/rules/youtube-performances.md`. Ярус песни — famous; досье: `planning/youtube/data/d965-der-hirt-auf-dem-felsen.dossier.json`. Опорный сравнительный источник — единственный найденный полноценный Vergleich именно по D 965: klassik-prisma (Bernd Stremmel), 30 записей с оценками по 5-балльной шкале; даты сессий — по дискографии Майкла Грея (classical-discography.org) и документации изданий. Все 5 итоговых видео проверены через oEmbed 2026-08-17 (живы, встраиваемы).

Особенность песни: написана для сопрано (Анна Мильдер-Хауптман), с облигатным кларнетом. **Никто из первой тройки приоритетов проекта (Квастхоф, Фишер-Дискау, Шварцкопф) её не записывал** — проверено по MusicBrainz (53 записи произведения), обзору klassik-prisma (30 записей) и Грею (34 позиции); свод Фишера-Дискау сознательно исключал «женские» песни. Также не записывали Хоттер, Андерс и Попп (помету «Hirt — версии?» в дайджесте певцов следует снять). Из именных приоритетов песню записали только Криста Людвиг и Элизабет Шуман. Топ-5 поэтому строится из группы «прочие звёзды прошлого» и современных; по правилу name при облигатном инструменте — «Фамилия певицы — Фамилия пианиста», кларнетист документируется здесь.

## Итоговый топ-5

1. **Maria Stader — Karl Engel** (кларнет — Rudolf Gall) — LP «Liederabend Maria Stader», DG LPEM 19136, выпущен в июле 1958 (Discogs 10504998); сессия — 1957 по klassik-prisma, документально не подтверждена (у Грея записи нет), поэтому в плеере — «1957–58?». Штадер 46 — вокальный пик. **Высшая оценка klassik-prisma — 5 баллов** («souverän»; французский тип кларнета), одна из всего двух «пятёрок» среди сопрано за всю историю обзора. Официальной загрузки нет — только фан-перенос LP; качество исполнения перевешивает техгигиену (конфликт зафиксирован в досье). Видео: zFPkA9KhV3Q (Operaspia, фан; 668 с ≈ 10'58 у klassik-prisma).
2. **Christa Ludwig — Geoffrey Parsons** (кларнет — Gervase de Peyer) — Columbia SAX5274; сессии 5–7 ноября 1965 (и 8 июля 1966), EMI Studio No. 1, Abbey Road — документировано Греем (id 156037). Людвиг 37 — середина абсолютного пика; именной приоритет проекта; редчайший случай меццо в этой песне. klassik-prisma 4–5 («драматическая оперная сцена, выходит за рамки простой песни»; отмечены отдельные Tonverfärbungen) — на полступени ниже «пятёрок», отсюда второе место внутри группы старых мастеров. Видео: fBVTo9ucY1E (Christa Ludwig - Topic, Warner).
3. **Arleen Augér — Graham Johnson** (кларнет — Thea King) — Hyperion Schubert Edition, т. 9 «Schubert & the Theatre» (CDJ33009); запись октябрь 1989, Rosslyn Hill Chapel, Лондон (документация Hyperion). Аугер 50, пик до самой ранней смерти (1993). **5 баллов klassik-prisma** («колокольно-ясное сопрано, исполнено с мерой; интровертная средняя часть»); часть научного эталонного свода Джонсона; дайджест называет этот том её ключевой шубертовской позицией. Из двух «пятёрок»-сопрано более ранняя (Штадер) стоит выше по правилу о сходном уровне. Видео: 7N0Ta17S8_Y (Arleen Augér - Topic, UMG).
4. **Daniel Behle — Sveinung Bjelland** (кларнет — Andy Miles) — рецитал Capriccio, 2010 (klassik-prisma). Тенор — редкость в этой песне. **5 баллов klassik-prisma — единственная современная запись высшей группы**: «стройный, всегда уверенно ведомый голос… очень убедительны диалоги тенора и кларнета, в целом очень дифференцированно» (оговорка: голосу недостаёт металла). Возглавляет современную группу по качеству. Видео: ILBWNSXu7vk (Daniel Behle - Topic).
5. **Soile Isokoski — Marita Viitasalo** (кларнет — Anna-Maija Korsimaa) — «Brahms: Clarinet Sonatas / Schubert: Der Hirt auf dem Felsen», Finlandia, ℗1993. Изокоски 36, начало пика. klassik-prisma 4–5 — **самая высокая оценка среди современных сопрано**: «выразительный голос с телом, очень близко к Мюллеру/Шуберту». Закрывает второй слот «не ранее 1990». Видео: 0dnjmNnvOOE (Soile Isokoski - Topic).

Порядок — по строгой иерархии: групп 1–3 (Квастхоф/Фишер-Дискау/Шварцкопф) в фонде песни нет; группа 4 (звёзды прошлого, между собой по качеству): Штадер (5) → Людвиг (4–5; именной приоритет не даёт преимущества внутри группы — правило «между собой по качеству»); группа 5 (послевоенно-современная когорта, по качеству): Аугер (5, 1989) → Беле (5, 2010; при равной оценке — более ранняя, то есть Аугер выше) → Изокоски (4–5).

## Ключевые решения и отклонённые кандидаты

- **Elisabeth Schumann / Reeves / Kell (HMV, 1937 по klassik-prisma; ℗1938 Warner)** — именной приоритет, но версия **сокращённая** («gekürzt», 8'43 против 11–12 минут полных; подтверждено длительностью Topic-трека 532 с), klassik-prisma 4. По прецеденту Попп/Gretchen качество — квалификационный фильтр и для приоритетных: купированная версия песни непригодна как «главное» представление песни на странице. Отклонена; историческая ценность отмечается в резерве.
- **Erna Berger / Raucheisen (~1943–44, радиофонд)** — 5 баллов klassik-prisma, но: год не установлен (у Грея записи нет), кларнетист не установлен, единственная загрузка — фан-канал. Уступила слот Изокоски по правилу состава (достойная запись 1990+ есть — состав, не в ущерб качеству: Изокоски сама в ярусе 4–5). Первый резерв.
- **Erna Berger / Scherzer / Geuser (Electrola, 1.07.1954, Грей id 54523/24)** — 4–5, есть Topic-загрузки, но у Бергер 4–5 разных версий песни (риск путаницы изданий), и по оценке она не выше уже взятых старых мастеров.
- **Erika Köth / Weissenborn / Leister (Eurodisc, 28.10.1962, Грей id 174294)** — 4–5 («вступление — уже маленькая сцена»), но только фан-загрузка и ярус ниже «пятёрок»; вытеснена конкуренцией внутри до-1990.
- **Suzanne Danco / Agosti / de Peyer (Decca, 23–24.01.1956, Грей id 3304)** — 4–5, официальный Topic; проиграла Штадер/Людвиг по совокупности оценок и статуса. Резерв до-1990 с официальной загрузкой.
- **Benita Valente / Rudolf Serkin (Marlboro, август 1960, Грей id 1914)** — 4–5; главный интерес — Серкин за роялем; сама певица в 26 лет в начале пути.
- **Rita Streich / Werba (DG, 3–4.04.1959, Грей id 1915)** — 4 («Werba в средней части нестабилен»); ниже яруса.
- **Janowitz (1977)** — 4, «по этой песне ниже собственного уровня» (klassik-prisma); **Price/Sawallisch (1981)** — 4 («большой голос, но не очень гибкий»); **Battle/Levine (1987)** — 4 с прямой критикой манерности — пример «громкое имя ≠ качество»; **Hendricks/Lupu/Meyer (1992)** — 4, критика полости голоса при выдающемся составе; **Bonney/Parsons/Kam (1994)** — 4 («столько ли нужно вибрато?»); **Ameling (℗1972 и др.)** — 4–5, но три разных версии с непривязанными к изданиям загрузками; **Donath/Klöcker (℗1982)** — 4–5 и «beste Klarinette», но лейбл Acanta на YouTube не представлен (только фан) и ярус ниже взятых.
- **Слот «не ранее 2015» оставлен пустым**: Richter/Huber/Schorn (Pentatone, май 2018), Said/Martineau/Meyer (Warner, 2024), Sampson/Middleton/Collins (BIS, 2025), Mühlemann (Sony, ℗2019) — ни одна не имеет независимой сравнительной оценки (обзор klassik-prisma обрывается на 2010); по правилу скепсиса к пиару современных включать их вместо записей с документированным качеством нельзя. Слот 2015+ — «только при наличии достойной», в ущерб качеству не заполняется.
