# Im Frühling (D 882) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: `docs/rules/youtube-performances.md`. Ярус: famous. Досье: `planning/youtube/data/d882-im-fruhling.dossier.json` (даты сессий — по дискографии Майкла Грея, classical-discography.org; реестр альбомов; MusicBrainz-каркас). Все 5 итоговых видео проверены oEmbed 2026-08-17 — живы, официальные каналы (4 Topic + 1 Topic harmonia mundi-серии).

Особенность фонда: klassik-prisma песню не рассматривает (проверено по индексу сайта) — привычного 5-звёздного ориентира нет; WebSearch в обеих сессиях недоступен. Ранжирование опирается на документированные даты сессий, состояние голоса по дайджесту певцов и устоявшуюся репутацию альбомов из реестра проекта.

## Итоговый топ-5

1. **Thomas Quasthoff / Justus Zeyen** — DG «Widmung – Romantische Lieder / A Romantic Songbook» (DG 474 501-2, изд. 01.04.2004; MusicBrainz release 50bda699…, Discogs 9880429). Год сессии дискографически не документирован — по правилу «иначе год издания» в плеер идёт **2004** (вердикт перепроверки в `d686-fruhlingsglaube-top5.md`, 2026-08-17: «ноябрь 2003» восходит к невскрытой карточке агрегатора и непубликуем; в D 257/550/799/853 стоит 2003 — сквозную унификацию выправлять отдельным проходом). Ему ~45 — внутри пика (~1993–2007), запись студийная, DG. Высший приоритет правил — всегда №1 при достойной записи; запись достойная, единственная у певца. Видео: `E7tjdawU4Dc` (Quasthoff Topic, ℗ 2004 DG).
2. **Dietrich Fischer-Dieskau / Gerald Moore** — студийная EMI/Electrola, Topic-альбом Warner «Schubert: Lieder Vol. 2»; лейбловая строка официальной поставки Warner: «℗ 1958, 2011 Parlophone», продюсер Christfried Bickenbach (Electrola). Сессия дискографически не датирована (у Грея этой позиции нет — проверено повторно в этой сессии; MusicBrainz знает трек только по боксу «The Great EMI Recordings», 2010) → по правилу о приоритетных певцах публикуется с диапазоном **«1957–58?»**: ℗ оригинальной фонограммы 1958 даёт верхнюю границу, заголовок фан-загрузки (incontrario motu) утверждает 1957. Ему ~32 — самая середина пика (~1951–1972), голос свежий и гибкий. Из трёх его версий выбрана ранняя: свод DG 1966–72 — поздний пик, live с Рихтером 1977 — «тон суше» (за пиком); правило «при прочих равных — более ранняя». Видео: `96J30-mUiIE` (Fischer-Dieskau Topic, Warner).
3. **Elisabeth Schwarzkopf / Edwin Fischer** — зап. 7 октября 1952, Abbey Road Studio 1A; Columbia 33CX 1040 (Грей: дата, место, состав; совпадает с карточкой реестра — сессии 4–7.10.1952, переизд. Naxos Historical 8.111287, реставрация Obert-Thorn). Ей 37 — середина пика (1948–1964). Диск с Эдвином Фишером — эталон рецитального Шуберта по дайджесту проекта; тот же круг сессий дал со-победителя слепого теста 2020 по Gretchen. Топ-1 среди женщин по правилам. Концертная альтернатива «Турин 1954» дискографически не подтверждена; при равенстве уровня правило выбирает студийную более раннюю. Видео: `bL9iUv2Iqfc` (Schwarzkopf Topic).
4. **Hans Hotter / Gerald Moore** — зап. 2 октября 1949, No. 1 Studio, Abbey Road; 78-я Columbia LX1305, матрица 10623. Самая надёжно датированная историческая позиция пула: двойное подтверждение (Грей + буклет переиздания EMI References CDH 5 65196 2 через карточку реестра). Ему 40 — внутри пика (~1942–1955), тёмный, ещё гибкий бас-баритон; слой Hotter/Moore 1949–57 — опорный для песенного Хоттера (реестр). Приоритетное имя группы 4. Загрузка 249 с соответствует матрице 1949 года (поздний слой 1957-го — иные длительности, не смешан). Видео: `oSHWEL4DPK0` (Hotter Topic).
5. **Samuel Hasselhorn / Ammiel Bushakevitz** — «Hoffnung» (harmonia mundi, изд. 17.04.2026) — том проекта «Schubert 200» с песнями 1826 года; принадлежность трека альбому **верифицирована в этой сессии** по MusicBrainz (release fe38510b…, 20 треков D 862–906, вкл. «Im Frühling, D. 882: No.1», 280 с — название и длительность точно совпадают с Topic-загрузкой). Гипотеза досье «Licht und Schatten» опровергнута: его трек-лист (MB f87a3c47…) — 18 номеров D 366–860, D 882 нет. Год сессии не документирован → год издания **2026**. Ему ~35 — молодая зрелость. Достоинство документировано не пиаром, а наградами двух предыдущих томов серии (Müllerin 2023 — Diapason d'or года; «Licht und Schatten» — Preis der deutschen Schallplattenkritik). Единственный верифицированный достойный кандидат слота «не ранее 2015». Видео: `FjKDZFo0J40` (Hasselhorn Topic, harmonia mundi).

## Ключевые решения и отклонённые кандидаты

- **Bernarda Fink / Huber (2007, harmonia mundi HMC 901991)** — сильнейшая документированная репутация среди современных (5 звёзд klassik-prisma по D 828 с того же альбома; со-победа дуэта в слепом тесте 2020 по Gretchen). Уступила только составу: оба современных слота структуры заняты приоритетом №1 (Квастхоф) и достойным кандидатом 2015+ (Хассельхорн). **Резерв №1 современного слота** — прецедент Gretchen (там Финк так же уступила Сампсон 2015+).
- **Christa Ludwig / Moore (17–18.11.1957, Angel 35461)** — приоритетное имя группы 4, дата точная (Грей), ей 29 — самое начало пика. Уступила Хоттеру слот старых мастеров: у Хоттера запись в середине пика с двойным дискографическим подтверждением и опорным статусом слоя Hotter/Moore; сравнительных оценок, различающих их треки, нет. **Резерв №2**.
- **Peter Anders / Raucheisen (радиофонд RRG, 1943–47?)** — приоритетное имя, пик, но точная дата не установлена (у Грея только Eterna-издание 1959 — заведомо не сессия: Андерс умер в 1954). При заполненных слотах старых мастеров публикация с диапазоном не потребовалась; кандидат на переоценку при доисследовании Raucheisen-Edition.
- **Fischer-Dieskau, другие версии**: свод DG 1966–72 (`TgEH-J3Whmk` и дубли) — поздний пик, отклонён в пользу ранней EMI; live с Рихтером 1977 (DG 2530 988, Грей) — знаменитый дуэт, но голос за пиком («с сер. 1970-х тон суше»); версия с Хёллем — не идентифицирована и заведомо позднейшая.
- **Florian Boesch / Martineau (Onyx 4149, 2016)** — достойный современный, альбом в реестре проекта, но прямых рецензий именно на этот диск нет (восторги прессы — про другой его альбом), год сессии не установлен; уступил Хассельхорну слот 2015+ (у того — наградная репутация серии). **Резерв №3 (слот 2015+)**.
- **Schwarzkopf «Турин 1954»** — только заголовок фан-загрузки, дискографически не подтверждена; студийная 1952 раньше и документирована.
- **Schlusnus / Peschko (24.05.1940, Polydor 67740)** и **Pears / Britten (29.09.1950, HMV DB21423)** — точно датированные исторические позиции (Грей), но оба вне списка приоритетных имён и без критического следа по этому номеру; уступили приоритетным Хоттеру/Шварцкопф.
- **Janowitz / Gage (1976–77, DG)** — сильнейшая женщина «второго ряда» (альбом дал 5-звёздную Gretchen), но слоты до-1990 заняты приоритетными именами.
- **Schreier / Olbertz (1971, Eterna)** и **Prey / Hokanson (1971, Philips)** — даты документированы Греем, но официальных загрузок нет (у Шрайера — только фан-канал, у Прея не найдено вовсе).
- **Seefried, della Casa, Ameling, Lott (Hyperion), Isokoski, Hendricks/Lupu, Goerne/Deutsch, Gerhaher (Wigmore), Sampson, Schuen** — у всех не установлены год/альбом/мастер (детали в досье); публикация без документации запрещена, приоритетными именами не являются.
- **Fleming / Eschenbach (1996)** — дайджест прямо отмечает вторичность Lieder для певицы — против включения при наличии специалистов.
- **Отрицательные результаты** (досье): Э. Шуман и Попп песню не записывали; Квастхоф записал её только на «A Romantic Songbook».
