# D 5 «Hagars Klage» — топ-3

Первая сохранившаяся песня Шуберта (30.03.1811, текст К. А. Шюккинга) — 17-минутная баллада для женского голоса; в свод Фишера-Дискау (DG, только мужские песни) не входит, у Квастхофа и Шварцкопф записи нет. Фонд: один рецитал звезды прошлого + два полных издания.

Возрастная структура: 2 записи не ранее 1990 (1996, 2009); достойных кандидатов не ранее 2015 нет — их место заняла лучшая старая запись. Порядок: Яновиц — звезда прошлого (группа 4), далее современные по качеству (Hyperion выше Naxos: специализированный том, отобранный под драматическую балладу).

Отклонены: «HappyKeroMusic» 60ac0QNdf08 (видео с нотами, исполнители не идентифицированы); загрузки канала «Виктория Заболоцкая» (любительская студийная серия, дискографии нет); Claudio Colombo (аранжировки для кларнета и ф-но, не песня).
