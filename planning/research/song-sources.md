# Источники для полного корпуса песен: тексты + даты + группировка

Дата: 2026-08-14. Метод: 7 параллельных веб-агентов + перекрёстная проверка (воркфлоу `schubert-source-research`); каждый факт ниже проверен реальной загрузкой страниц, если не отмечено иное. Дополняет и частично **исправляет** `schubert-corpus.md` (см. «Что изменилось»).

## Главный ответ

**Единого авторитетного источника «тексты + даты написания» не существует.** Причина структурная: источники с точными датами (schubertsong.uk, schubert-digital.at, каталог Дойча 1978) публикуют стихотворения или инципиты — но не текст как поётся; единственный источник текстов действительно «как поётся», с повторами (OpenScore Lieder, CC0), не содержит дат и покрывает ~14% корпуса.

**Критично для нас:** пилотная «Гретхен» использует текст именно как поётся — с повторами («Ich finde, ich finde», строфа 11 «O könnt' ich ihn küssen…» с повтором, кода 12). Значит, ни один «поэмный» источник сам по себе не даёт наш формат: слой повторов всегда добирается из нот.

## Что изменилось против `schubert-corpus.md`

1. **Каркас каталога теперь строить не по Википедии, а по IMSLP-списку работ** (её «таблицы» оказались маркированными списками без поэтов и с испорченным текстом; IMSLP — одна чистая таблица CC BY-SA с фильтром `v pf`), с выверкой по **NSA Schubert-Datenbank** (авторитетное определение корпуса: genre=Lied, 626–650 строк).
2. Найден **schubert-digital.at** — самые точные даты (до дня, по версиям), основан на Дойче-1978. Источник дат для карточек песен.
3. Скан Дойча-1978 на archive.org — **не** public domain (ошибка метки IA): пользоваться только как справкой, не как данными.
4. OpenScore Lieder — не просто ноты: **готовые текстовые файлы «как поётся» с повторами, CC0** — это ровно наш формат (совпадает с пилотом).

## Рекомендуемая связка (минимум источников)

1. **Каркас** (D, название, инципит, опус, состав, год, год публикации): IMSLP works list (CC BY-SA) × NSA Schubert-Datenbank (объём корпуса).
2. **Даты**: schubert-digital.at (день/месяц, по версиям), спорное сверять с Дойчем-1978 (справочно).
3. **Тексты**: OpenScore (CC0) как база «как поётся» для 88 песен (все три цикла!); для остальных ~540 — слой Растля (LiederNet per-setting тексты со сносками отличий / schubertsong.uk) **с разрешения** + повторы редакционно по PD-сканам AGA (IMSLP). Сами стихотворения XIX века — PD везде.
4. **Одно письмо решает многое**: тексты Растля лежат в основе и LiederNet, и schubertsong.uk — запрос Растлю/Врену/Эзуст может открыть весь критический текстовый слой сразу.

## Группировка (проверенные цифры)

- **По годам — не годится как навигация**: 1815 — 144 песни, 1816 — 103, 1817 — 61, но 1824 — 7, 1810 — 1 (разброс 20:1; подсчёт по 19 годовым спискам Википедии, NSA серия IV). Год — как факт на карточке и лента «чудо-год 1815», не как рубрикатор.
- **По поэтам — работает**: 155–156 поэтов; ~15–20 покрывают больше половины корпуса (Гёте 61 текст / 70+ песен, Майрхофер 46–47, Мюллер 45, Шиллер 38, Маттиссон 32, Хёльти 27, Козегартен 21, далее 10–15 у десятка имён). Коммерческий прецедент — Naxos Deutsche Schubert-Lied-Edition, 35 томов: крупные поэты отдельно, хвост в ~8 именованных групп («Друзья», «Австрийские современники», «Поэты чувствительности», «Романтики», «Европейские поэты»…).
- **Циклы/сборники** — первосортные входы: три больших цикла + именованные группы (Арфист D 478, Wilhelm Meister D 877, 4 Refrainlieder D 866, 4 канцоны D 688, песни Эллен из «Девы озера» op. 52, оссиановские песни…).
- Прецеденты сайтов: schubertlied.de и Oxford Song — плоский сортируемый алфавитный индекс; Naxos и schubertsong.uk — поэтные группы; Hyperion (40 CD) — хронология.
- **Рекомендация**: первичная навигация — **поэты** (+ циклы закреплены отдельно), вторичная — **плоский индекс** с сортировкой по алфавиту/D/году и поиском. D-номер — канонический ID (уже принято).
