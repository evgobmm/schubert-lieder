# D 671 «Trost» (Майрхофер) — топ-4

Фонд записей крайне узкий: песня существует почти только внутри полных сводов и специальных майрхоферовских программ. Пять достойных кандидатов не набирается — по правилу берётся меньше.

Порядок — по иерархии: Квастхоф (нет) → Фишер-Дискау → Шварцкопф (нет) → современные по качеству.
