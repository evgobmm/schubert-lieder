# Tränenregen (D 795/10) — отбор топ-5 исполнений

Дата: 2026-09-06. Правила: `docs/rules/youtube-performances.md`. Песня — № 10 цикла «Die schöne Müllerin» (D 795), цикльный метод (раздел «Масштабирование», п. 2): базовая пятёрка наследуется из полного исследования цикла — `planning/research/cycle-muellerin-top5.md` (дата 2026-08-17; там же — досье по каждой из пяти записей: год по дискографии Майкла Грея/Discogs, состояние голоса, репутация, потрековая доступность на YouTube). Пятёрка в `performances.json` (поле `"795/10"`) совпадает с цикльной базой; задача этого файла — независимая проверка всех пяти записей именно для этой песни (правильность видео, происхождение конкретной загрузки, свежие цитаты-подтверждения) и проверка, не заслуживает ли «Tränenregen» отдельного пер-песенного пересмотра.

Источники, проверенные заново для этого файла: YouTube oEmbed для всех пяти videoId из `performances.json`; полные страницы watch-видео (поле `shortDescription`, где auto-generated Topic-загрузки прямо называют издателя-поставщика, лейбл, альбом и дату «Released on») — это надёжнее oEmbed, который отдаёт только название/канал; Discogs API (`api.discogs.com`, curl без токена) для сессионных дат и цитат по альбомам; веб-поиск на предмет самостоятельной концертной жизни песни у приоритетных исполнителей без полного цикла.

## Проверка на самостоятельную концертную жизнь песни

По методу цикла отдельные номера с задокументированной самостоятельной («шлягерной») дискографической жизнью получают дополнительный пер-песенный пересмотр (прецеденты — «Ungeduld», D 795/7: 39 сольных сторон у Грея, Шварцкопф вытеснила Хюша; «Das Wandern», D 795/1; «Wohin?», D 795/2). Для «Tränenregen» такой традиции найти не удалось:

- Веб-поиск («"Tränenregen" Schwarzkopf OR "Elisabeth Schumann" OR Hotter Schubert recording single side») не дал документированных отдельных студийных записей этой песни у приоритетных исполнителей без полного цикла. Автоматическая сводка поисковика первоначально утверждала, что «Elisabeth Schwarzkopf performing "Tränenregen"» упоминается в найденных материалах — при прямой проверке текста той же статьи (PS Audio, «The Beauty of Song Part 2») это утверждение не подтвердилось: статья посвящена «An die Musik» и Малеру, «Tränenregen» там не упоминается вообще. Это ложный след поисковой сводки, не факт; для отчётности он честно зафиксирован здесь и отклонён.
- Цикльное досье (`cycle-muellerin.dossier.json`) уже фиксирует отрицательные результаты по полным циклам для Шварцкопф, Хоттера, Людвиг, Попп; у Э. Шуман — только «Wohin?» отдельно; у Андерса потрековая доступность на YouTube ограничена «Wohin?» — «Tränenregen» среди задокументированных отдельных записей этих исполнителей нет.
- Скрипт сбора кандидатов (`planning/youtube/data/d795-10-tranenregen.{yt,candidates}.json`) нашёл на официальных Topic-каналах помимо основной пятёрки записи Brigitte Fassbaender (EMI 1974), Hermann Prey (Philips 1973 либо более ранние Columbia-78), Olaf Bär, Christian Gerhaher (Arte Nova 2003) и Andrè Schuen (DG 2021/22) — все они уже фигурируют как второй ряд / резервы старой и современной групп в `cycle-muellerin-top5.md` («Отклонённые кандидаты», «Резервы») и не вытесняют места по иерархии приоритетов (три места до 1990 заняты Ф.-Д., Хюшем и Вундерлихом более высокого консенсусного ранга; современное место занято Хассельхорном с объективной премией). Ни одна из этих записей не даёт оснований для пер-песенного пересмотра именно «Tränenregen».
- В отличие от «Das Wandern», «Wohin?» и «Ungeduld» — «Tränenregen» рядовой номер середины цикла без задокументированной сольной пластиночной традиции 78-эпохи.

**Вывод**: оснований вытеснять цикльную позицию нет — состав пятёрки (певцы/год/издание) сохраняется без изменений; меняется только конкретный videoId у позиции №2 (см. выше).
