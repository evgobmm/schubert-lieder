## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — DG «Sämtliche Lieder» (том «Lieder, Volume 2», DG 2720 022, изд. 1970). Сессии свода — 1966–1972, Ufa-Ton-Studio Berlin; том с D 870 издан в 1970, значит сессия не позднее 1970 — в плеере диапазон **«1966–70?»** (точная дата по буклету не установлена; правило о приоритетных исполнителях с неустановленным годом). Певцу 41–45 — внутри вокального пика (~1951–1972 по дайджесту). Эталонное полное издание мужских песен Шуберта; Квастхоф песню не записывал, поэтому топ открывает приоритет №2. Из трёх студийных версий ФиДи выбрана ранняя с Муром: версия с Бренделем (Philips, изд. 1983) — за пределами пика («с сер. 1970-х тон суше»), версия с Бриттеном — без установленной даты и без официальной загрузки. Видео: Yoc_J7Z_1D0 (Fischer-Dieskau Topic, 130 с — совпадает с MusicBrainz 2717fb5a).
2. **Lucia Popp / Irwin Gage** — зап. 1–6.11.1983, Abbey Road (примечание прессинга, Discogs 6176352); EMI/HMV «Schubert Lieder» (1C 067 27 0067 1, изд. 1984). Ей 44 — самый центр зрелой формы (пик ~1970–1988, позднего спада практически нет); это её главный сольный шубертовский диск по дайджесту. Единственная запись песни у именных приоритетов-женщин (Шварцкопф её не записывала). В отличие от прецедента Gretchen (задокументированные низкие оценки), негативной критики этого трека нет — приоритет действует. Внутри группы приоритетов №4 (Хоттер и Попп — один пункт списка, между собой по качеству) поставлена выше Хоттера: студийная цифровая запись с точно документированной сессией в самом центре пика певицы против недатированного концертного радиоэфира, значительная часть возможного диапазона которого приходится на годы после пика Хоттера (подробнее в п. 3). Видео: 4bQdSEVDCT0 (Popp Topic, 151 с = MusicBrainz 0fb7827c).
3. **Hans Hotter / Hans Altmann** — концертная запись из архива Баварского радио (Preiser PR 3145 «Dichterliebe / Ausgewählte Lieder», трек 21; Discogs 13964615: «Aus dem Archiv des Bayrischen Rundfunks. Live Recording»). Год записи не установлен (у Грея сессий Hotter/Altmann нет); целевое доисследование сузило диапазон: пианист Ханс Альтман умер в 1961 (Hans Altmann (Musiker), 1904–1961 — de.wikipedia, страница разрешения неоднозначности), BR под этим именем существует с 1949 — в плеере **«1949–61?»**. Бо́льшая часть диапазона накрывает пик Хоттера (~1942–1955). Единственная запись песни у этого именного приоритета; включена по правилу «хорошая запись приоритетного исполнителя не блокируется неустановленным годом». Внутри группы №4 уступает Попп по качеству записи: недатированный live-эфир из архива BR (концертный радиозвук) против её студийной сессии Abbey Road, и почти половина возможного диапазона (1956–61) лежит за пределами пика Хоттера — состояние голоса на момент записи, в отличие от документированного центра пика у Попп, не гарантировано. Видео: wffV7pZh180 (Hans Altmann - Topic — так лейбл атрибутировал релиз; живость проверена).
4. **Florian Boesch / Roger Vignoles** — зап. ноябрь 2012, All Saints' Church, East Finchley (страница Hyperion CDA68010); «Schubert: Der Wanderer & other songs» (изд. 2014). Ему 41 — пик (~2010–). Сильнейший современный кандидат: независимая пресса конкретно об альбоме — Gramophone («богаче тембр, чем у Герхаэра… больший дар тихого пения»), The Guardian, IRR («двое из лучших исполнителей Lieder нашего времени»), Sunday Times; песня-«странник» — смысловая ось программы. Видео: MXoPM99_dRg (Vignoles Topic, 144 с = MusicBrainz 4a2faa6a).
5. **Samuel Hasselhorn / Ammiel Bushakevitz** — «Hoffnung 1826» (harmonia mundi HMM 902779, серия «Schubert 200», изд. 2026; Discogs 37546023). Певцу ~36 — в форме. Слот «не ранее 2015»: серия издаёт песни ровно через 200 лет после сочинения (D 870 — 1826), а её предыдущие выпуски отмечены независимыми наградами (Müllerin 2023 — Diapason d'or года; «Licht und Schatten» 2024 — Preis der deutschen Schallplattenkritik) — это не пиар-репутация, а призовой послужной список серии. Видео: KHzkeT2E01s (Hasselhorn Topic, 143 с = MusicBrainz cdf46268).

## Ключевые решения и отклонённые кандидаты

- **Квастхоф и Шварцкопф песню не записывали** (проверено по MusicBrainz-списку работы, тресклистам и Грею; негативы досье) — верх иерархии вакантен, топ открывает Фишер-Дискау. Также не записывали её Андерс, Э. Шуман и К. Людвиг.
- **Fischer-Dieskau / Brendel (Philips, изд. 1983)** — отклонена в пользу ранней: певцу ~58, за пределами пика; правило «при прочих равных — более ранняя» здесь усилено разницей состояния голоса. **Fischer-Dieskau / Britten (Decca)** — дата сессии не установлена, только фан-загрузка; кандидат на доисследование, не для публикации.
- **Heinrich Schlusnus / Franz Rupp (Polydor, 1931; Грей id 256640)** — сильнейший из невключённых старых мастеров: сердцевина формы эталонного межвоенного баритона. Уступил третьему довоенно-архивному слоту только из-за именного приоритета Хоттера; первый резерв.
- **Gérard Souzay / Jacqueline Bonneau (Decca, 24.10.1947; Грей id 33570)** — ранний Сузе (29 лет, чуть до пика); поздней студийной версии у него нет (тресклист «Der Musensohn» 1967 песни не содержит). Достойный, но в пятёрку не поместился при трёх занятых до-1990 слотах.
- **Peter Schreier / András Schiff (Decca, август 1989)** — зрелая вершина тенорового Шуберта, самый край пика; конкуренция до-1990 слотов слишком плотная. Резерв.
- **Hermann Prey (Philips, 27–30.10.1971)** — пик певца, но неразрешённое противоречие по пианисту (Грей: Hokanson; MusicBrainz: Engel) и расходящиеся длительности дублей; до сверки по буклету не публикуется.
- **Margaret Price / Johnson (Hyperion т. 15, X.1991)** — граница пика, добротная пресса, но общего характера (о голосе, не о треке); самый быстрый темп пула (120 с против медианных ~140) — спорная трактовка. Уступила Бёшу; резерв современного слота.
- **Christian Gerhaher / Huber (Sony, изд. 2014)** — дайджест прямо предписывает фильтровать прессу о нём по правилу о пиаре; независимых сравнительных оценок трека нет, а цитата Gramophone в пользу Бёша сравнивает их напрямую.
- **Andrè Schuen (Avi, зап. 2016)** — самый медленный дубль пула (172 с), устоявшихся оценок нет; **Benjamin Appl (Sony, 2017)** — медийно активный проект без устоявшейся критической репутации. Оба уступили Хассельхорну в слоте 2015+.
- **Ian Bostridge / Drake (Wigmore live)** — год не установлен, дайджест о позднем Бостридже скептичен; при датированных сильных кандидатах не нужен.
- **Karl Erb / Seidler-Winkler** — без даты и заведомо вне вокального пика (58–74 года) — документ стиля, не топ-5. **Fassbaender (1989/91), von Otter (1996), Hendricks (1985, аномальные 106 с), Kasarova, Jackson (Hyperion т. 26), Prégardien (обе версии — даты сессий не установлены)** — достойный второй ряд, уступили по совокупности формы, критического следа и датировки.
- **Вне игры**: Schöffler/Lush (Decca 1946 — на YouTube не найден), Traubel (Columbia 1947 — не издана), Olaf Bär (исходный альбом не установлен).
