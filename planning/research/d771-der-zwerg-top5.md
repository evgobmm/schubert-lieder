Источник кандидатов: `planning/youtube/data/d771-der-zwerg.dossier.json` (досье 2026-08-17; сессия досье шла без WebSearch — свободный веб-поиск был исчерпан, поэтому даты и происхождение записей опираются на MusicBrainz, Discogs API, страницы Hyperion/audite, реестр альбомов проекта и метаданные официальных Topic-загрузок; прямых рецензий на D 771 по большинству записей добыть не удалось — это отражено ниже честно). Особенность фонда: у D 771 практически нет записей старых мастеров до ~1950 — Шварцкопф, Хоттер, Андерс, Э. Шуман и Попп песню не записывали (MusicBrainz — 0 результатов по каждому, целевые yt-dlp-поиски пусты). Дискография песни фактически начинается с Фишера-Дискау; «старую» часть пятёрки образуют записи 1958–1984 годов.

## Итоговый топ-5

1. **Thomas Quasthoff / Charles Spencer** — сессии 25–26 и 28–29 мая 1993, Historischer Reitstadel, Ноймаркт; RCA Victor Red Seal «Schubert: Goethe-Lieder» (изд. 1995; ℗ 1993 BMG). Певцу 33–34 — самое начало пика (~1993–2007), голос свежий и ровный. Первый из шести шубертовских альбомов Квастхофа, вошёл в бокс «The Complete RCA Recordings»; несмотря на название диска, Der Zwerg (текст Коллина) в программе есть — подтверждено MusicBrainz и Topic-метаданными. По иерархии приоритетов Квастхоф — всегда №1. Студийная версия предпочтена его же лайву из Вербье с Кисиным (год концерта не установлен). Видео: WeKeLRGR0Yc (Quasthoff Topic).
2. **Dietrich Fischer-Dieskau / Gerald Moore** — EMI/Electrola «Schubert: Lieder Vol. 2», ℗ 1958 (год сессии не выверен, вероятно 1957–58; в плеере — год издания 1958 по правилу «иначе год издания»). Певцу 32–33 — сердцевина пика (~1951–1972). EMI-серия с Муром второй половины 1950-х считается вершиной раннего Фишера-Дискау (по Erlkönig klassik-prisma ставит EMI-1958 высший балл — выше его же DG-свода). Из четырёх его версий выбрана самая ранняя студийная: правило «при прочих равных — более ранняя», студия предпочтительнее зальцбургского лайва 1957 по звуку, DG-1969 — тот же дуэт на десятилетие позже. Видео: JbKdazcFvLs (Fischer-Dieskau Topic, Warner).
3. **Christa Ludwig / Irwin Gage** — DG «Schubert: Lieder», ℗ 1975 (год сессии не документирован; дайджест даёт «~1973» без источника — в плеере 1975 до находки буклета). Певице ~47 — конец пика (~1957–1975), меццо ещё полнозвучное, богатый низ для мрачной баллады фактурно выигрышен. Единственная запись песни среди приоритетных певиц правил (Шварцкопф, Э. Шуман, Попп её не пели) — именной приоритет группы «звёзды прошлого». Видео: VThok0wekj8 (Ludwig Topic).
4. **Jessye Norman / Phillip Moll** — сессия апрель 1984; Philips «Schubert: Lieder» (℗ 1985). Певице ~39 — центр пика (~1975–1995). Альбом уже опорный в проекте (D 118, D 852); по Erlkönig klassik-prisma даёт ему 5 баллов — единственную пятёрку среди женщин, и для «Карлика» с его оперным размахом крупный тёмный голос Норман — естественное преимущество. Версия 1984 предпочтена её же ранней (Philips ℗ 1972, с Гейджем): зрелая запись центрального пика против 27-летней «до пика» — это не «прочие равные», выбор по состоянию голоса и статусу альбома. Видео: kbwNRxEf7XM (Norman Topic; дубль той же фонограммы на компиляции — Kno0IAQrt5E).
5. **Florian Boesch / Malcolm Martineau** — Onyx «Schubert: Lieder Recital» (ONYX 4149), 2016 (год сессии не установлен). Певцу ~45 — зрелый пик; тёмный бас-баритон венской рассказчицкой школы — из современных кандидатов наиболее близкий песне типаж (Der Zwerg — повествовательная баллада). Альбом уже используется проектом (D 805, D 806); пресса о Бёше в Шуберте устойчиво положительна (восторги Gramophone/Guardian о его Hyperion-диске 2012 — см. реестр), прямых рецензий на D 771 нет. Закрывает слот «не ранее 2015». Видео: i9lMhlKVny0 (Boesch Topic).

## Ключевые решения и отклонённые кандидаты

- **Quasthoff / Kissin (Verbier, live; ℗ 2023)** — резерв Квастхофа: редкая связка с Кисиным, но год концерта не установлен (верхняя граница — январь 2012, уход из классического пения), запись слабо верифицирована; студия 1993 сильнее по документированности и состоянию голоса.
- **Fischer-Dieskau, прочие версии**: Зальцбург-1957 live с Муром (Orfeo, диск «1957, 1. Liederabend») — тот же пик, но студия EMI предпочтительнее по звуку; DG-1969 (свод с Муром) — тон плотнее и тяжелее раннего EMI; ранняя запись с Клаусом Биллингом (рубеж 1940–50-х) — именно её Diapason выбрал в антологию «22 Lieder» (сильный сигнал!), но год не установлен и официальной загрузки на YouTube нет — кандидат на будущую переоценку при появлении официального релиза.
- **Ian Bostridge / Drake (EMI, сессии 1996)** — самый сильный внешний сигнал среди современных: именно его Der Zwerg отобрана представителем песни в антологию EMI/Warner «Schubert: Lieder on Record 1898–2012». Не вошёл из-за возрастной структуры: два слота 1990+ заняты Квастхофом (иерархический приоритет №1) и достойным кандидатом 2015+ (Бёш); лёгкий светлый тенор для этой мрачной баллады — типаж спорнее Бёша. Первый резерв.
- **Christian Gerhaher / Huber (Sony, 2013)** — главный конкурент Бёша среди современных; самый быстрый тайминг пула (4:54) — подчёркнуто речевая трактовка; пресса о нём фильтруется по правилу пиар-скепсиса, независимых сравнений по D 771 нет. Слот 2015+ он не закрывает (2013). Резерв.
- **Norman 1972 (Philips, с Гейджем)** — отклонена в пользу 1984: см. п. 4.
- **Hasselhorn 2021, Krimmel 2019 («Saga»), Coote 2022, Said 2024** — достойный второй ряд слота 2015+: у Хассельхорна награды соседних дисков серии, у Криммеля Der Zwerg — программный центр балладного дебюта, но оба — молодые голоса против зрелого пика Бёша; Ку́т — авторитетная связка с Дрейком без внешних сигналов именно по D 771; Саид — лирико-колоратурное сопрано, нетипичный для «Карлика» голос при премиальной маркетинговой кампании Warner.
- **Ann Murray / Johnson (Hyperion Vol. 3, зап. XI.1988)** — «научный эталон» издания с настоящими рецензиями диска (Gramophone: «faultlessly recorded»), но в старой группе уступает Людвиг и Норман по масштабу голосов и статусу; светлое меццо для баллады менее выигрышно.
- **Trost / Eisenlohr (Naxos, 2008)** — справочная «полная» версия, художественно уступает рециталам.
- **Приоритетные певцы без записи D 771**: Schwarzkopf, Hotter, Anders, E. Schumann, Popp (проверено: MusicBrainz — 0, целевые поиски пусты).
