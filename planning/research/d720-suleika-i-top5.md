# Suleika I (D 720) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Ярус песни — famous. Досье кандидатов: planning/youtube/data/d720-suleika-i.dossier.json (23 кандидата, все данные — по дискографиям: Грей/реестр проекта, Discogs API, MusicBrainz). Все 5 итоговых видео и 3 резервных проверены через oEmbed (живы, официальные Topic-каналы).

**Особенность фонда**: песня целиком женского репертуара (стихи Марианны фон Виллемер от лица Сулейки). Мужских записей не существует в значимом фонде (MusicBrainz — 29 записей, все женские голоса; проверено и поиском YouTube), поэтому приоритеты №1, 2 и мужская часть №4 (Квастхоф, Фишер-Дискау, Хоттер, Андерс) неприменимы. Из приоритетных певиц записала только Шварцкопф; Людвиг, Попп и Э. Шуман записей D 720 не оставили (отрицательный результат MusicBrainz + YouTube). Сравнительной страницы klassik-prisma по D 720 нет; критический след записей тоньше, чем у Gretchen, — ранжирование опирается на дискографический статус изданий, состояние голоса и устоявшуюся репутацию исполнительниц.

## Итоговый топ-5

1. **Elisabeth Schwarzkopf / Geoffrey Parsons** — «An Elisabeth Schwarzkopf Song Book, Vol. 3» (HMV ASD 2634): ℗ 1971, конверт напечатан XI.1970; сессионная дата не документирована → в плеере год издания 1971. Источник: Discogs 8527832 (трек-лист: A1 = Suleika I, A2 = Suleika II; кредит Parsons). Приоритет №3 правил (топ-1 среди женщин). Ей ~55: поздний период с Parsons — голос легче и суше пика 1948–64, но интерпретаторски высший класс (прецедент той же поры: Gretchen-1973 — 5 звёзд klassik-prisma); самая протяжённая трактовка пула (6:05) — фирменная поздняя детализация слова. Диск входит в Warner-бокс «The Complete Recitals 1952–1974». Видео: uqFK9B_icCo (Schwarzkopf Topic; дубль Sakq_8sVWvQ того же трека отсеян).
2. **Kathleen Ferrier / Bruno Walter** — Эдинбургский фестиваль, live BBC, 1949 (Decca 6BB 197-8 «BBC Broadcasts from the Edinburgh Festival 1949»; переизд. Ferrier Edition Vol. 9, Centenary Edition). Источник: Discogs 10191684. Ей 37 — пик формы (умерла в 41, спада не было); за роялем великий дирижёр — ключевая позиция её шубертовского наследия (дайджест). Историческая веха фонда песни, сохранённая самим Decca в полном собрании записей певицы. Звук — концертное моно 1949 г., что для слота «звёзд прошлого» норма (ср. Э. Шуман-1936 в Gretchen). Видео: cRliVVZ-Hjc (Ferrier Topic, Vol. 9 — наибольшие просмотры из четырёх официальных загрузок одного исполнения).
3. **Janet Baker / Gerald Moore** — HMV SLS 812 «Schubert: Lieder» (2 LP), сессии 29.08 + 12–13.09 + 16–20.12.1970, Abbey Road Studio 1 (Грей через реестр проекта). Ей 37 — пик (~1965–1982); Мур за роялем. Альбом — сквозной эталон женского шубертовского пения 1970-х, уже верифицирован в реестре по D 118, D 828, D 839, D 257. Длительность ролика совпадает с MusicBrainz (333 с). Видео: Ql-roruCGbQ (Baker Topic).
4. **Anne Sofie von Otter / Bengt Forsberg** — DG «Schubert: Lieder», запись июнь 1996, Concertgebouw Nijmegen, издание 1997 (реестр проекта). Ей 41 — пик (~1988–2010); ведущая шубертианка своего поколения среди меццо; альбом уже в реестре по D 799, D 839, D 257. Лучший кандидат слота 1990+ по совокупному весу исполнительницы и альбома (сравнение с Лотт и Апшоу — ниже). Видео: ZMGVg0-CiFQ (von Otter Topic).
5. **Carolyn Sampson / Joseph Middleton** — BIS «A Soprano's Schubertiade», запись 2017, издание 2018 (реестр + Discogs 14565880). Пик формы (~2010–наст.). Единственный полноценный студийный кандидат «не ранее 2015» (наряду с Konradi-2020); тот же альбом уже прошёл отбор в топ-5 Gretchen (MusicWeb: «одно из лучших изданий года») — статус диска наследуется. Видео: RGxIgSm34RE (Sampson Topic).

Порядок — по строгой иерархии приоритетов: Шварцкопф (группа 3) → звёзды прошлого по качеству (Феррье выше Бейкер: историческое значение записи с Бруно Вальтером на пике певицы против «просто» эталонного студийного альбома) → современные по качеству (фон Оттер выше Сэмпсон по статусу в жанре).

## Ключевые решения и отклонённые кандидаты

- **Janowitz / Gage (DG, сессии 1976–77)** — сильнейшая альтернатива третьему довоенно-старому слоту: серия дважды удостоена Deutscher Schallplattenpreis, пик «инструментального» тона. Уступила Бейкер по совокупности: Мур за роялем, более ранняя запись при сходном уровне (правило ранней), альбом-эталон с более широким критическим следом в реестре. Первый резерв.
- **Ameling / Baldwin (Philips 9500 169, сессии 15–19.08.1975)** — альбом «Songs for Gretchen, Ellen & Suleika» назван в том числе по этой песне; пик зрелой манеры. Отсеяна из пятёрки конкуренцией трёх более весомых довоенных/студийных позиций (Феррье, Бейкер, Шварцкопф) — три пре-1990 слота заняты. Резерв. Её же ранняя версия с Демусом (EMI Electrola, сессии 10–13.01.1970) — свежее голосом, но менее значимое издание; при выборе между версиями Амелинг тематический Philips-диск перевешивает, а в пятёрку не проходят обе.
- **Felicity Lott / Johnson (Hyperion т. 19, зап. VII.1992)** — научный свод Джонсона, восторженная рецензия о самом диске; уступила фон Оттер по калибру исполнительницы. Резерв слота 1990+.
- **Upshaw / Goode (Nonesuch 1994)** — Diapason d'Or 09/1994 (по Discogs-сборнику; требует подтверждения трек-листом при публикации цитаты), Гуд за роялем; уступила фон Оттер (статус в Шуберте) и Лотт (научный свод) в конкуренции за один слот.
- **Norman / Moll (Philips, зап. IV.1984)** — Erlkönig с того же диска — 5 баллов klassik-prisma, но монументальная манера для «песни ветра и движения» — предмет спора критики; уступила более лёгким и подвижным голосам.
- **Hendricks / Lupu (EMI, зап. XI.1985)** — главный аргумент — Лупу; сама трактовка без критического следа, уступает по весу Бейкер/Яновиц.
- **Augér / Olbertz (Eterna, зап. X.1976)** и **Augér / Orkis (Virgin, ℗ 1991, хаммерклавир)** — добротные, но без особого статуса; вторая — поздний период (за два года до смерти), по правилу ранней уступает первой, первая — конкурентам 1970-х.
- **Battle / Levine (DG 1988)** — манера «оперно-декоративная», скепсис досье; отсеяна.
- **Zomer / Schoonderwoerd (Alpha 2003)** — сильнейший периодный кандидат (альбом — «периодный эталон» по дайджесту), но слот 1990–2014 один, и он отдан фон Оттер.
- **Konradi / Heide (Avi 2020)** — свежая запись, пресса не устоялась; уступила Сэмпсон (слот 2015+).
- **Marian Anderson (Constitution Hall, 1964)** — прощальный концерт в 66–67 лет, далеко за пиком; студийная версия (RCA ARL1-3022, ℗ 1978) официально на YouTube не найдена. Отсеяна по состоянию голоса.
- **Seefried, M. Price, Watts, Persson, Tilling, Ziesak** — либо год/альбом не установлены (Зеефрид, Прайс — «не публиковать без идентификации»), либо второстепенный статус без критического следа.

## Соответствие правилам состава

3 записи ранее 1990 (1949, 1970, 1971) ✓; 2 записи 1990+ (1996, 2018/зап. 2017) ✓; из них 1 запись 2015+ (2017) ✓. Современные слоты заняты достойными кандидатами (фон Оттер — первый ряд жанра; Сэмпсон — диск с независимым признанием), не в ущерб качеству.
