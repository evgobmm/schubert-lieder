# Nähe des Geliebten (D 162) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Досье кандидатов: planning/youtube/data/d162-nahe-des-geliebten.dossier.json (даты — по дискографии Майкла Грея, Discogs-релизам и буклетам переизданий; метаданные YouTube для датировки не использовались). Все итоговые видео проверены через oEmbed 2026-08-17 (живы, официальные Topic-каналы).

Особенность фонда: сравнительного обзора по D 162 нет (индекс klassik-prisma проверен — песни там нет), поэтому привычного 5-звёздного ориентира нет; ранжирование опирается на иерархию приоритетов, документированное состояние голоса и репутацию альбомов.

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — зап. 23–24.05.1958, Берлин-Целендорф, Evangelisches Gemeindehaus; Electrola E90921 «Schubert: Lieder Vol. 4» (дата — дискография Грея, id 199091). Ему 33 — сердцевина пика (~1951–1972); голос свежий, до сухости позднего периода. Квастхоф песню не записывал (проверено), поэтому Фишер-Дискау — вершина иерархии. Из трёх его версий выбрана эта: студийная, с Муром, в лучшей форме; фан-загрузка именно этой записи — самая просматриваемая среди всех роликов песни. Видео: sOSF0_PPInQ (FiDi Topic, альбом «Schubert: Lieder Vol. 4»).
2. **Elisabeth Schwarzkopf / Edwin Fischer** — зап. 5.10.1952, Abbey Road Studio 1A; Columbia 33CX 1040 (Грей, id 58270; буклет Naxos Historical 8.111287 — сессии 4–7.10.1952). Ей 36 — вокальный пик (1948–1964). Эталонный рецитал с великим пианистом; тот же альбом дал со-победителя слепого теста 2020 по Gretchen. Приоритет №3 (топ-1 среди женщин). Студийная версия предпочтена зальцбургскому лайву с неустановленным годом. Видео: Oa_Z9EzRLWo (Schwarzkopf Topic, Warner «Song Recital»).
3. **Elisabeth Schumann / Gerald Moore** — зап. ок. 5–15 марта 1937 (датировка по соседним матрицам Грея вокруг 2EA 4849/4850); HMV DB 3184, переизд. Naxos Historical 8.110731, Warner «Icon». Ей 48 — уже за пиком (1920-е — сер. 1930-х), но до заметно постаревших записей 1945–49; стиль эталонный, подача лёгкая, «песенная» (2:40 — самая быстрая из старых версий). Именной приоритет (п. 4 списка); самая ранняя доступная на YouTube запись песни — исторический слот. Видео: 85UiHs5hysw (E. Schumann Topic, Warner «Icon», ℗1937).
4. **Christoph Prégardien / Andreas Staier** (хаммерклавир) — зап. 10–13.10.1994, WDR Köln; DHM 05472 77342 2 «Songs to Poems by Goethe» (примечание релиза Discogs 9124690; инструмент — копия Johann Fritz ок. 1815 работы C. Clarke). Ему 38 — начало пика (~1990–2012); по дайджесту — один из ведущих Lieder-теноров поколения. Сильнейший современный мужской кандидат: цельная гётевская программа, периодная звуковая эстетика. Видео: Qvb7Vhd_HGo (Prégardien Topic).
5. **Barbara Bonney / Geoffrey Parsons** — зап. апрель 1994, Teldec Studio Berlin; Teldec 4509-90873-2 (примечание релиза Discogs 16032161). Ей 38 — пик (1990-е — нач. 2000-х). Проверенная в проекте связка Бонни/Парсонс (в Gretchen их трек получил BBC Music Magazine 5/5); самая просматриваемая официальная загрузка песни (26,6 тыс.). Видео: Uc5ldfXaQhI (Bonney Topic).

## Ключевые решения и отклонённые кандидаты

- **Квастхоф — записи нет**: полный треклист его единственного гётевского альбома (RCA 1993, Spencer) проверен — D 162 отсутствует; поиск Discogs по треку — 0 релизов. Поэтому №1 — Фишер-Дискау.
- **Выбор версии Фишер-Дискау**: (а) WDR-радиозапись 1954 с Вайссенборном (Audite 95.583) формально раньше, но правило «сходные → более ранняя» неприменимо — это радиодокумент с другим пианистом, заметно медленнее (3:46), без критического следа; студийная EMI-версия 1958 с Муром — канонический дуэт в лучшей звукозаписи (прецедент Шварцкопф-1948/1952 в Gretchen). Резерв. (б) DG-свод 1966–1972 (трек ℗1970) — базовая точка отсчёта, но певцу 41–47, тон суше; по правилу «при прочих равных — более ранняя» уступает 1958-й.
- **Schwarzkopf, зальцбургский лайв** («Schubert & Wolf: Lieder (Live)», предположительно Orfeo C826103D) — год не установлен дискографически, пианист не подтверждён; при наличии студийной 1952 не нужен.
- **Matthias Goerne / Haefliger (1996, Decca)** — достойный современный баритон (29 лет, голос свежий), но ранний диск вне его свода harmonia mundi, критики на трек нет; на два слота 1990+ уступил Прегардьену (специалист-Lieder-тенор в дедицированной гётевской программе) и Бонни (проверенная критикой связка). Первый резерв современного слота.
- **Brigitte Fassbaender / Werba (1974, EMI)** — сильнейший «старый» женский кандидат после Шварцкопф (34 года, перед пиком); в пятёрку не попал: три довоенно-послевоенных слота заняты именными приоритетами (Фишер-Дискау, Шварцкопф, Э. Шуман), а расширять старую группу за счёт современных слотов правила не велят. Резерв.
- **Janet Baker / G. Johnson (1987, Hyperion т. 1)** — единственный кандидат с настоящей прессой (Penguin Guide «glorious voice», The Guardian, The Times), но запись сделана в 53 года, на исходе пика (по дайджесту ~1965–1982); трактовка самая быстрая в пуле (2:22). Уступила именным приоритетам в старой группе. Резерв.
- **Kathleen Battle / Levine (1988, DG)** — расцвет голоса, и DG-переиздание 2009 названо именем песни, но певицы нет в дайджесте фонда, прессы на диск не найдено — по правилу скепсиса к пиару не завышена.
- **Rita Streich / Werba (1960, DG)** и **Elly Ameling / Baldwin (1972, Philips)** — добротные записи расцвета, но не именные приоритеты и без критического следа на трек; старые слоты заняты более сильными кандидатами.
- **Söderström / Badura-Skoda (℗1991)** — певице ~63, год не подтверждён дискографически; **C. Schäfer / Gage (℗1997)** — год не подтверждён, рецитал не значится в дайджесте; **Ziesak / Eisenlohr (2003, Naxos DSLE)** — «эталон издания», художественно не превосходит старых мастеров.
- **Markus Schäfer / Meniker (℗2021)** — единственный кандидат 2015+: певца нет в дайджесте, ему ~60 (поздний период), критики нет, дата сессии не установлена. По правилу «слот 2015+ — только при наличии достойного, никогда в ущерб качеству» слот оставлен пустым.
- **Без YouTube** (в плеер поставить нечего): Karl Erb (Odéon 1912 — самая ранняя документированная запись песни), Erika Köth / Moore (Eurodisc 1963), Peter Schreier / Olbertz (Eterna, XII.1970 — дискографически ценный гётевский цикл), Peter Pears / Britten (BBC, дата не установлена).
- **Записи не нашлось** (проверено по Грею, Discogs по треку, YouTube): Хоттер, Андерс (военная запись 15.10.1944 Андерсу не атрибутирована), Людвиг, Попп; совпадения в Discogs — ложные (сборники, где песню поёт Шварцкопф).

## Соответствие правилам состава

3 записи ранее 1990 (1937, 1952, 1958) ✓; 2 записи 1990+ (1994, 1994) ✓; слот 2015+ пуст — единственный кандидат (M. Schäfer, ℗2021) не проходит квалификационный фильтр качества; по правилам его место занимает лучшая доступная запись (Бонни, 1994). Порядок — строгая иерархия: Фишер-Дискау → Шварцкопф → прочие старые мастера (Э. Шуман) → современные по качеству (Прегардьен, Бонни).
