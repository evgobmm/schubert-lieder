# D 943 «Auf dem Strom» — топ-5

Состав: голос (тенор/сопрано), валторна, фортепиано (Рельштаб, 1828). Квастхофа, Фишера-Дискау, Шварцкопф нет; из приоритетных найден Петер Андерс. Порядок — иерархия: Андерс (приоритетный певец) → прочие мастера прошлого (Валенте — Серкин) → современные по качеству.

**Формат name для песни с облигатным инструментом.** Правило «непианистическое сопровождение → „Фамилия — Ensemble“» (`docs/rules/youtube-performances.md`) относится к записям, где пианиста нет вовсе (ансамбль, оркестр, арфа). В D 943 фортепиано остаётся аккомпанирующим инструментом, а валторна — облигатный голос поверх рояля, поэтому сохраняется обычный формат «Певец — Пианист»; валторнист документируется здесь, в обосновании (по каждой записи ниже). Тот же принцип — для D 965 «Der Hirt auf dem Felsen» (кларнет). Это не исключение из правила, а граница его применения; зафиксировано явно после QA-вопроса волны.
