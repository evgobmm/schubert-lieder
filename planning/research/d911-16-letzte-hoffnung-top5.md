## Проверка по записям

### 1. Thomas Quasthoff (бас-баритон) — Charles Spencer (фортепиано), 1997

- Полный цикл Winterreise, RCA. Discogs-мастер прямо озаглавлен «Thomas Quasthoff, Charles Spencer (2) — Winterreise, D. 911» — https://www.discogs.com/master/1245591-Schubert-Thomas-Quasthoff-Charles-Spencer-Winterreise
- MusicBrainz числит релиз под тем же составом: «Winterreise» by Thomas Quasthoff, Charles Spencer — https://musicbrainz.org/release/f10034f7-5ebc-4122-a74d-35749ef90ca6 (страница отдала только антибот-заглушку «Verifying your browser…», точную дату сессии подтвердить не удалось).
- Издание — RCA (по позднейшим переизданиям — Sony Classical); CD вышел в 1998, есть указание и на кассетный релиз 1997 года (Köln) — из чего год записи 1997 правдоподобен, но независимого дискографического подтверждения точной даты сессии (буклет/матрица) в рамках бюджета найти не удалось.
- Вывод: исполнитель и произведение подтверждены; год **правдоподобен, но не подтверждён первично** — источник для точной даты сессии остаётся задачей для отдельного доисследования (правило допускает публикацию приоритетного исполнителя без установленного года, со знаком «?», но здесь трогать `performances.json` не входит в задачу).

### 2. Peter Mattei (баритон) — Lars David Nilsson (фортепиано), 2018

- Подтверждено дискографически: BIS-2444, запись — ноябрь 2018, Studio Acusticum, Питео (Швеция). HRAudio.net: «Label: BIS (BIS-2444)», «Recording Year: November 2018» — https://www.hraudio.net/showmusic.php?title=13897
- Издание сопровождало концертный тур по Скандинавии и телеверсию для шведского SVT.
- Вывод: год, исполнители, издание — **подтверждены**.
- Проблема — не с содержанием, а с **порядком**: по правилу «строгая иерархия приоритетов» (Квасthof → Фишер-Дискау → Шварцкопф → прочие звёзды прошлого → современные) запись Маттеи (современная, группа 5) должна стоять **последней**, а не второй. Сейчас в `performances.json` она идёт сразу за Квасthofом, перед Фишером-Дискау, Андерсом и Хоттером (все — старые мастера, группы 2 и 4) — это нарушение правила порядка. Замены содержания не требует, требуется **перестановка**: Quasthoff → Fischer-Dieskau → Anders/Hotter (между собой — по качеству) → Mattei.

### 3. Dietrich Fischer-Dieskau (баритон) — Gerald Moore (фортепиано), 1962

- Фишер-Дискау записывал Winterreise с Муром трижды (1955 моно, 1962 стерео, 1971 стерео) — по данным справочной статьи AllMusic об альбоме «Die schöne Müllerin; Winterreise [1961/1962 Recordings]» и заголовку загрузки на YouTube «Dietrich Fischer Dieskau; "WINTERREISE"; (Gerald Moore '62)» — https://www.youtube.com/watch?v=hbNJsuNdfeM ; заголовок Discogs-релиза 2×LP «"Die Winterreise", Op. 89 / "An Die Ferne Geliebte", Op. 98 … 1962» — https://www.discogs.com/release/12890437-Schubert-Beethoven-Dietrich-Fischer-Dieskau-And-Gerald-Moore-Die-Winterreise-Op-89-An-Die-Ferne-Geli
- Прямые страницы Discogs (master и релиз-карточки с точными датами сессии/лейблом) отдавали HTTP 403 в рамках доступного бюджета обращений — независимая перепроверка точной даты (буклет DG, матричные номера) не выполнена; сведение трёх источников (AllMusic, Discogs-заголовок, авторитетная YouTube-загрузка) даёт год **1962 согласованно**, лейбл — Deutsche Grammophon (не EMI, как ошибочно выдала одна автоматическая сводка поиска — этот вариант отброшен как недостоверный).
- Ему в 1962 году 37 лет — середина пика (по дайджесту певцов проекта диапазон пика Ф.-Д. известен как один из самых длинных в дискографии барона). Стереозапись 1962 года — наиболее известная и часто переиздаваемая из трёх версий дуэта Ф.-Д./Мур.
- Вывод: исполнители, произведение и год — **подтверждены** (согласованно по трём независимым источникам), издание DG.

### 4. Peter Anders (тенор) — Michael Raucheisen (фортепиано), 1945

- Точные даты сессий: Berlin, Haus des Rundfunks, 23 января и 2, 13 марта 1945 года. Заголовок архива: «Franz Schubert, WINTERREISE — Peter Anders, Michael Raucheisen (23 gennaio e 2, 13 marzo 1945)» — https://archive.org/details/PeterAndersWinterreiseD911Schubert1945_201802

### 5. Hans Hotter (бас-баритон) — Michael Raucheisen (фортепиано), 1942

- Запись сделана в ноябре 1942 года для Deutsche Grammophon, впервые издана на 78 об/мин в 1943 году; это первая из как минимум четырёх версий Winterreise в дискографии Хоттера. Discogs-заголовок переиздания: «Hans Hotter, Michael Raucheisen, Franz Schubert — Hans Hotter Sings Schubert Winterreise The 1942 DG Recordings» — https://www.discogs.com/release/13638959-Hans-Hotter-Michael-Raucheisen-Franz-Schubert-Hans-Hotter-Sings-Schubert-Winterreise-The-1942-DG-Rec
- Критическая репутация — высокая: Джозеф Хоровиц в The New York Times (12.12.1999) назвал её «The most powerful Winterreise I know» (цитата — по сводке поиска, прямую страницу NYT/ClassicsToday получить не удалось — classicstoday.com отдал заглушку без текста, отдельный NYT-архив не запрашивался в рамках бюджета).
- Хоттеру в 1942 году 33 года — по характеристике той же сводки уже сложившийся мастер слова и рассказчик.
- Вывод: исполнители, год, издание (DG) — **подтверждены** двумя независимыми упоминаниями (Discogs-заголовок и справочная сводка); прямая цитата рецензии Хоровица не перепроверена по первоисточнику (бюджет обращений исчерпан) — приведена как разумно достоверная, но не как дословно сверенная цитата.

## Проблемы и рекомендации

1. **Порядок нарушает правило иерархии приоритетов.** Сейчас: Quasthoff → Mattei → Fischer-Dieskau → Anders → Hotter. По правилу (Квасthof №1 → Фишер-Дискау №2 → Шварцкопф №3, если есть → прочие звёзды прошлого → современные) корректный порядок: **Quasthoff → Fischer-Dieskau → (Anders, Hotter — между собой по качеству) → Mattei**. Замены исполнителя/записи не требуется — только перестановка. `performances.json` не тронут по прямому запрету задачи; правка делегируется потоку/пользователю.
2. **Год Quasthoff — Spencer (1997)** правдоподобен (кассетный релиз 1997/CD 1998), но не подтверждён первичным дискографическим источником (буклет, матрица) — точные Discogs/MusicBrainz страницы недоступны из контейнера (403 / антибот). Рекомендация: при следующей волне с доступом — точечная доверификация; замены не требует.
3. **Возрастная структура**: из пяти записей только одна (Mattei, 2018) — после 1990 года; правило считает это допустимым, если больше достойных современных кандидатов не найдено, но в рамках данной задачи (только проверка утверждённой пятёрки, без нового поиска кандидатов) этот вопрос не пересматривался.

## Заключение

Ни одна из пяти записей не подлежит замене: во всех пяти подтверждены исполнитель, партнёр за роялем, произведение (полный цикл Winterreise, включающий Letzte Hoffnung) и издание; год подтверждён для четырёх из пяти записей независимыми источниками, для записи Quasthoff/Spencer — правдоподобен, но не подтверждён первично. Найдена одна содержательная проблема — **нарушение порядка** записи Mattei относительно иерархии приоритетов; рекомендованная перестановка описана выше.
