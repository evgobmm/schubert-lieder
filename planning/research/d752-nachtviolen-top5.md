# Nachtviolen (D 752) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Досье: planning/youtube/data/d752-nachtviolen.dossier.json (22 позиции с проверенным YouTube; MusicBrainz — 30 записей произведения). Ярус — «famous» по фонду записей, но без внешнего сравнительного ориентира: klassik-prisma песню не разбирает (проверено, Vergleich по D 752 не существует), слепых тестов нет. Поэтому ранжирование опирается на иерархию приоритетов, документированные даты, состояние голоса и репутацию альбомов — не на пиар. Все 5 итоговых видео проверены yt-check (живы, официальные Topic-каналы).

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — EMI-рецитал с Муром, Лондон; год дискографически НЕ установлен, публикуется как «1955?» (описание фан-загрузки: сессии 12–13.05.1955; реестр проекта датирует серию EMI-рециталов 1955–1965; в дискографии Майкла Грея записи Ф.-Д. этой песни нет вовсе — 157 его шубертовских позиций проверены). Переиздание — Warner «The Great EMI Recordings» (2010). Ему ≈30 — вокальный пик: голос легче и свободнее, чем в DG-своде; тот же период, что классические Müllerin-1951 и Winterreise-1955. Из минимум пяти его прочтений песни правила выбирают раннее при сходном уровне; запись приоритетного певца не блокируется неустановленным годом (правило + прецеденты «1961?» у Прая, «1957–67?» у Шварцкопф в корпусе). Видео: WzV9RVDSC-4 (Warner Topic, 183 с — совпадает с MB-записью 182 с).
2. **Elisabeth Schwarzkopf / Edwin Fischer** — зап. 5.10.1952, EMI Studio No. 1A, Abbey Road; Columbia 33CX 1040 (дискография Майкла Грея, id 58914 — одна из двух записей песни с датой по первичному источнику). Ей 36 — сердцевина пика 1948–1964. Эталонный рецитал с великим солистом-пианистом (по дайджесту — «эталон» её дискографии; та же сессия уже в топах D 118, D 162, D 828). Приоритет №3 (топ-1 среди женщин). Видео: oJdRvySeGiM (Warner Topic).
3. **Elisabeth Schumann / Leo Rosenek** — год дискографически НЕ установлен, публикуется как «1938?» (метаданные Warner-Topic дают 1938, но источником не признаются; целевое доисследование дало отрицательные результаты: у Грея среди 32 её шубертовских позиций Nachtviolen нет, в Naxos 8.110731 песня отсутствует; издания — EMI «Der Hirt auf dem Felsen & 48 Lieder», Warner «Icon»). Если 1938 — ей 50: конец пика, но стиль — признанный эталон шубертовского «лёгкого сопрано»; именной приоритет (п. 4 правил), исторический слот пятёрки, как её Gretchen-1936 в D 118. Видео: rSAvVqF4vBs (Warner Topic).
4. **Christian Gerhaher / Gerold Huber** — альбом «Nachtviolen» (Sony Classical/BR-Klassik 88883712172, изд. февраль 2014; сессии не документированы; год 2014 — сквозная конвенция альбома в корпусе, ср. D 196). Песня — заглавная для диска, т.е. заявлена певцом как ключевая; Gramophone Award 2015 — независимая (не пиаровая) награда. Сильнейший современный кандидат. Видео: uuW0u9faXTg (Sony Topic).
5. **Florian Boesch / Malcolm Martineau** — «Schubert Lieder Recital» (Onyx ONYX4149, изд. 20.05.2016). Ему ≈45 — внутри пика; «рассказчик венской школы»; альбом уже проверен проектом и служит топам четырёх песен пилота (D 225, D 226, D 254, D 257). Закрывает слот «не ранее 2015». Видео: 6vuvMc1vf7M (Onyx Topic).

## Ключевые решения и отклонённые кандидаты

- **Квастхоф песню не записывал** (дискография закрыта в 2012, ровно 6 шубертовских альбомов — майрхоферовской лирики нет; поиск подтверждает). Также не записывали: Хоттер, Андерс, Людвиг, Попп (проверено по MusicBrainz-списку произведения и поиском), Прай, Вундерлих, Фассбендер, Шрайер, Дж. Бейкер.
- **Выбор версии Фишера-Дискау** — у него минимум пять прочтений. EMI «1955?» предпочтена DG-своду 1969 (обе внутри пика, ранняя вокально свежее — правило «при прочих равных — более раннюю»); зальцбургские лайвы (Orfeo, в издании две разные записи, годы вечеров не установлены) и «Homage to Gerald Moore» (RFH 1967, гала-контекст) — ниже студийных; лайв с Рихтером — уникум ансамбля, но год не установлен и отдельного официального трека нет (только фан-загрузка целого вечера — для плеера непригодна); запись с Демусом (Orfeo 2000) на YouTube отсутствует.
- **Elly Ameling / Baldwin (10–14.09.1976, Concertgebouw; Грей id 198305, Philips 9500 350)** — вторая запись с первичной датой, пик певицы; уступила третий «старый» слот именному приоритету Э. Шуман (п. 4 правил называет Шуман поимённо; Амелинг — «остальные по ситуации»). Первый резерв старого слота.
- **Bernarda Fink / Huber (сессии IX.2007, Teldex; HMC 901991)** — сильнейшая современная женская позиция по внешним оценкам (тот же альбом: Gretchen — со-победитель слепого теста 2020, D 828 — единственная современная с 5 звёздами klassik-prisma). Уступила Бёшу только по правилу состава (слот «не ранее 2015»): по самой D 752 внешних оценок нет ни у неё, ни у Бёша, явного перевеса качества нет — структура решает состав. Первый резерв современного слота.
- **Rita Streich / Werba (DG 1960)** и **Gérard Souzay / Baldwin («Récital Schubert no. 2», год 1958 не подтверждён)** — достойные звёзды прошлого, но три «старых» слота заняты более высокими приоритетами (Ф.-Д., Шварцкопф, Э. Шуман); расширять старую часть за счёт современной мешало бы составу.
- **Peter Pears / Britten (Aldeburgh)** — великий дуэт, но ни одна из двух записей не датирована даже приблизительно, и Пирс — не именной приоритет; без даты концерта позиция не конкурентна.
- **Felicity Lott / Johnson (Hyperion т. 19, июль 1992)** — научный свод с прессой уровня «perfect» (In Tune), но самая медленная трактовка пула (210 с) и певица вне круга приоритетов; современные слоты ушли более сильным кандидатам (Герхаэр — награда, Бёш — структура).
- **Christoph Prégardien / Staier («Lieder after Mayrhofer», ℗ 2001)** — контекстно самый «профильный» альбом (весь — Майрхофер, историческое фортепиано); проиграл Герхаэру (независимая награда, заглавная песня) и Бёшу (слот 2015+). Достоин переоценки при ротации.
- **Bostridge (Wigmore 2015)** — поздний период («интеллектуально, но суше»); **Sampson («Schubert's Four Seasons», BIS 2025)** — независимых оценок нет, пиар-фактор высок; **Keenlyside (EMI 1994?)** — 203 с, очень медленно, год не подтверждён; **Dessay (Sony 2017)** — официального трека нет (только фан-лайв); **Watts, Raskin, Russell** — периферия пула; **Walker, Argenta, Lorenz, FD/Demus** — нет отдельных треков на YouTube.

## Примечания по датам

- Даты по первичной дискографии есть только у Шварцкопф (5.10.1952, Грей id 58914) и Амелинг (10–14.09.1976, Грей id 198305).
- «1955?» (Ф.-Д./EMI): гипотеза «12–13.05.1955» — из описания фан-загрузки incontrario motu (Xrz7Jpd1YG8), подтверждена только совпадением длительностей (182–183 с) с официальным Warner-треком и MB-записью; серия EMI-рециталов в реестре проекта датирована 1955–1965. Кандидат на уточнение по буклету «The Great EMI Recordings» (2010).
- «1938?» (Э. Шуман): только release_year метаданных Warner-Topic; отрицательные результаты по Грею и Naxos 8.110731 задокументированы в досье. Кандидат на уточнение по буклету EMI CDH 7 64074 2 / Warner «Icon».
- Год Герхаэра — 2014 (издание; ℗ 2013, сессии не документированы) — сквозная конвенция альбома «Nachtviolen» в корпусе (так уже у D 196); год Бёша — 2016 (издание 20.05.2016, как у D 225/226/254/257).
