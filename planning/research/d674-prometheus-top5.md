## Итоговый топ-5

1. **Thomas Quasthoff / Charles Spencer** — зап. 25–26 и 28–29 мая 1993, Historischer Reitstadel, Ноймаркт; RCA Red Seal «Goethe-Lieder» (℗ 1995, BMG; переизд. в «The Complete RCA Recordings», 2018). Дата сессии установлена в этой сессии по notes Discogs-релиза 8778752 (транскрипция буклета) — снят знак вопроса досье («1993–95?»); год 1993 совпадает с уже опубликованным в корпусе для того же альбома (Erlkönig D 328). Ему 33–34 — начало пика (~1993–2007 по дайджесту), бас-баритон в полном ресурсе. Певец №1 по иерархии проекта; его Lieder-искусство ценится «for its detail, directness and his vocal range and colour» (Wikipedia). Из двух его версий выбрана фортепианная (вторая — оркестровка Регера с Аббадо, 2002 — в резерве: песня в оригинале фортепианная). Видео: dUIygMjsg2M (Quasthoff Topic).
2. **Dietrich Fischer-Dieskau / Jörg Demus** — зап. 13–14 сентября 1959, Studio Lankwitz, Берлин; DG «Ein Schubert-Goethe-Liederabend» (SLPM 138 117, изд. 1960; реестр альбомов проекта + MusicBrainz 1959-09). Ему 34 — самая свежая крупная студийная фаза, звонкий верх, внутри пика ~1951–1972. Из шести его версий (1954 Klust, 1957 Зальцбург live, 1959 Demus, 1969 Moore, 1972 Britten, 1979 Demus) правило «при прочих равных — более ранняя внутри пика» и документированность выбирают 1959: целиком гётевская программа, классика раннего стерео; версия 1969 (DG-свод) — равноценный резерв, 1972 с Бриттеном есть только на фан-канале. Видео: Rhx0HIGYspY (Fischer-Dieskau Topic; 334 s = MB-хронометраж записи 1959).
3. **Kurt Moll / Cord Garben** — Orfeo «Lieder für Baß» (LP S 021821 A, ℗ 1982; CD C 021 821 A подтверждает «℗ © 1982 Orfeo» — Discogs 29163157; дата сессии не печатается, ставим документированный год издания 1982, как уже принято в корпусе для этого альбома: D 44, D 805). Ему ≈44 — расцвет; редчайший случай настоящего чёрного баса в этом репертуаре. Прямая критическая санкция именно этого рецитала: «His recording for the Orfeo label of Schubert's philosophical Lieder für Bass set a new standard for these songs» (Wikipedia, ст. Kurt Moll) — Prometheus входит в программу. Сильнейший «старый мастер» пула после Фишера-Дискау. Видео: CgH9yaky0H0 (Kurt Moll Topic).
4. **Hermann Prey / Karl Engel** — зап. март 1974 (MusicBrainz), сессии Philips-эпохи (переизд. «Hermann Prey: A Life in Song», 2011; трек также в антологии EMI/Warner «Lieder on Record»). Ему 45 — внутри пика ~1960–1980; тёплый, ровный баритон — контрастное «титаническое» прочтение рядом с декламацией Фишера-Дискау и басовым гранитом Молла. Центральный баритон-шубертианец поколения после Фишера-Дискау, основатель Шубертиады в Хоэнемсе. Ранняя версия 1974 предпочтена поздней 1982 с Deutsch (голос тяжелее — правило возраста). Год 1974 совпадает с корпусным для того же пласта записей (D 77, D 259). Видео: qHzGrJHbPCQ (Prey Topic; 349 s = MB-хронометраж).
5. **Konstantin Krimmel / Doriana Tchakarova** — зап. март 2019 (MusicBrainz); Alpha Classics ALPHA 549 «Saga» (баллады Шуберта, Лёве, Йенсена, Шумана; релиз 2019-09-20). Ему 26 — начало пика; свежий тёмный баритон, балладный концепт-альбом — жанрово точное попадание для декламационной оды. Слот «2015+». Статус певца подтверждён вне пиара релиза: Opus Klassik «Sänger des Jahres» 2024 за шубертовскую Müllerin (de.wikipedia.org, ст. Konstantin Krimmel). Прямых рецензий на трек добыть не удалось (Presto/Outhere — 403; бюджет WebSearch исчерпан) — честный пробел, отмечен ниже. Видео: whxqZT3TvvA (Krimmel Topic; 342 s ≈ MB 341 s).

## Ключевые решения и отклонённые кандидаты

- **Приоритетные певцы, не записавшие песню**: Шварцкопф, Хоттер (его YouTube-«Prometheus» — Вольф, не Шуберт), Андерс, Э. Шуман, Людвиг, Попп — отсутствие проверено по MusicBrainz (26 записей произведения) и YouTube-поиску (досье, priority_singers_checked). Песня — мужская декламационная ода; женских записей уровня пятёрки нет (Margaret Ritchie 1949 — курьёз).
- **Quasthoff / COE / Abbado (2002, DG, орк. Регера)** — Grammy-альбом 2004, но не фортепианная версия; при одной записи певца в пятёрке выбрана оригинальная фортепианная (RCA 1993). Резерв.
- **Fischer-Dieskau 1969 (Moore, DG-свод)** — равноценная альтернатива слоту 2 внутри пика; уступила 1959 по правилу «более ранняя». Первый резерв слота.
- **Fischer-Dieskau 1972 (Britten, Олдборо)** — знаменитый дуэт, самый популярный «старый» ролик песни (>20 тыс.), но только фан-канал (риск удаления) и конец пика; отклонён.
- **Simon Keenlyside / Johnson (январь 1999, Hyperion т. 34)** — сильнейший отклонённый: реальная пресса тома (Gramophone «a feast of finely wrought, intelligent interpretations», BBC Music «a must for any serious Schubert collector»), расцвет (39). Не вошёл только из-за возрастной структуры: третий слот 1990+ вытеснил бы третьего «старого мастера» (правило «минимум 3 очень хорошие записи ранее 1990»), а по качеству Молл и Прай — выше яруса. Главный резерв современного слота.
- **Matthias Goerne / A. Haefliger (май 1996, Decca)** — ранний свежий Гёрне; уступил Квастхофу (иерархия) и Кинлисайду (документированная пресса). Резерв.
- **Siegfried Lorenz / Shetler (1974, Eterna)** — добротный систематический свод, но не художественная вершина рядом с Моллом/Праем.
- **Kim Borg / Werba (DG, 1960-е?)** — исторический бас, год сессии не установлен; без даты и критического следа в пятёрку не проходит.
- **Robert Holl / Lutz (Preiser, релиз 2021)**, **Franz-Josef Selig**, **Bo Skovhus** — год/альбом не установлены (пробелы досье); Холл — потенциально сильный бас-кандидат на переоценку после доисследования.
- **Florian Boesch / Martineau (2014, Onyx)** — самая быстрая версия пула (296 s); пресса не проверена; уступил по совокупности.
- **Ulf Bästlein (Naxos, 1999)** — справочное значение полноты издания. **Edelmann (2015)** — периферийный, найденный ролик оркестровый. **Appl** — фортепианной студийной записи нет (только оркестровки Регера). **Pape**, **Rosen** — год/происхождение не установлены.
