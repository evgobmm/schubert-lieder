# Die Rose (D 745) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Досье: planning/youtube/data/d745-die-rose.dossier.json (14 значительных записей исследованы; ярус «famous»). Все 5 итоговых видео проверены через oEmbed (живы, официальные Topic-каналы).

Особенность фонда: песня — де-факто женский рецитальный номер (единственная мужская запись фонда — Гёрне). **Все мужчины-приоритеты и Шварцкопф песню не записывали** (MusicBrainz + yt-dlp, см. досье): пункты 1–3 иерархии приоритетов пусты, пятёрка начинается с §4. Сравнительных обзоров именно D 745 не существует (klassik-prisma страницы по песне нет); единственный найденный «сравнительный вердикт» — отбор записи Попп в историческую антологию EMI «Schubert — Lieder on Record 1898–2012». Песня существует в двух редакциях (D 745a / D 745b) — пятёрка представляет обе.

## Итоговый топ-5

1. **Lucia Popp / Irwin Gage** — студийный рецитал EMI, сессии 1–6.11.1983, Abbey Road, прод. John Mordler. Ей 44 — внутри пика (~1970–1988; позднего спада у Попп практически нет). Сильнейший объективный маркер фонда: именно эта запись отобрана в антологию EMI Classics «Schubert — Lieder on Record 1898–2012» (MusicBrainz; Discogs 23802614) — де-факто признание референсной для песни; функционально это единственный «сравнительный вердикт» по D 745. Именной приоритет §4; внутри группы старых мастеров ранжирование по качеству ставит её выше Людвиг (у той — риск «слишком крупного» голоса для миниатюры, см. ниже). Прецедент Попп/Gretchen (отсев при слабой записи) здесь не работает в минус: там критика была против её записи, здесь — антология за. Студийная версия предпочтена её же зальцбургскому лайву того же года (общее правило: документированная студия при отсутствии свидетельств превосходства лайва). Видео: 0DO-kK4OLFg (Lucia Popp - Topic, 193 с ↔ MB 192,7 с).
2. **Christa Ludwig / Irwin Gage** — зап. 21–24.06.1973, Вена, Tonstudio Rosenhügel (Грей); LP DG 2530 404, ℗ 1974, прод. Cord Garben. Ей 45 — верхняя граница пика (~1957–1975): голос полный и ровный, темнее ранних EMI-лет. Именной приоритет §4. Поёт ПЕРВУЮ редакцию (D 745a). Осторожность из досье (по D 828 того же круга критика упрекала «слишком крупный» голос — риск той же претензии к миниатюре) понижает её ниже Попп внутри группы, но не отсеивает: прямых негативных свидетельств именно о её D 745 нет, а статус и состояние голоса — высшего яруса. Видео: pZqoP77wJKg (Christa Ludwig - Topic).
3. **Gundula Janowitz / Irwin Gage** — сессии 1976–77, Studio Lankwitz, Берлин (корпусный год свода — 1977); 4-LP свод DG 2713 012/2530 858, прод. Cord Garben. Ей 40 — сердцевина пика (~1965–1980): инструментальная ровность, «серебряный» тон. Серия дважды удостоена Deutscher Schallplattenpreis. Не именной приоритет, но звезда прошлого того же яруса (в Gretchen-исследовании её версия — 8/10, 5-звёздный ярус); замыкает группу §4 после двух именных приоритетов. Поёт ВТОРУЮ редакцию (D 745b). Видео: KEE2SbLNHkE (Gundula Janowitz - Topic).
4. **Felicity Lott / Graham Johnson** — зап. июль 1992, Rosslyn Hill Unitarian Chapel, Лондон; Hyperion Schubert Edition т. 19 «Songs about flowers & nature» (CDJ33019, изд. XI.1993). Ей 45 — рецитальная зрелость. Сильнейший документированный кандидат 1990-х: том тематически ЦЕНТРАЛЬНЫЙ для песни (целиком о цветах и природе), пресса тома — «Rarely can one find a recording where every single aspect — repertoire, performance and production — is perfect. This is» (In Tune), «art vocal propre, parfait», «prononciation impeccable» (Répertoire). Поёт вторую редакцию. Против Шефер/Johnson (т. 27, 1995): уровень сходный, пресса т. 19 сильнее, и по правилу «сходные → более ранняя» выбрана Лотт-1992. Видео: NJDF0t1moR8 (Graham Johnson - Topic — официальная загрузка UMG Hyperion-свода).
5. **Carolyn Sampson / Joseph Middleton** — зап. 25–28.02.2024 (буклет BIS, Discogs 34201693; релиз 2025); «Schubert's Four Seasons» (BIS-2703). Ей 50 — зрелый пик (~2010–наст.); третий шубертовский диск устойчивого дуэта с Мидлтоном, аннотация Susan Youens. Единственный кандидат яруса «не ранее 2015» с официальной загрузкой; дуэт подтвердил уровень в корпусе проекта (Gretchen-топ5: слот 2015+ тоже за Сэмпсон, с независимой критикой её шубертиады). Трек-рецензий нет — включение по правилу состава при достойном (не пиарном) кандидате. Видео: 41x92f-6rC8 (Carolyn Sampson - Topic).

## Ключевые решения и отклонённые кандидаты

- **Christine Schäfer / Johnson (Hyperion т. 27 «Schubert & the Schlegels», зап. III.1995)** — почти равный конкурент Лотт: профильный том (Шлегели), хорошая пресса (BBC Music Magazine: «Another jewel in the Schubert Edition crown»), 30 лет — начало пика, первая редакция. Уступила по силе прессы и по правилу более ранней записи при сходном уровне. Первый резерв.
- **Christine Schäfer / Gage (Orfeo, изд. 1997, год сессии не установлен)** — дубль певицы; рецензий нет, год под вопросом; правило дублей отдаёт место Hyperion-версии 1995.
- **Lucia Popp — зальцбургский лайв 10.08.1983 (Orfeo, изд. 2016)** — дубль певицы; студийная EMI-версия того же года документирована и канонизирована антологией. Резерв на случай смерти студийного ролика.
- **Matthias Goerne / Deutsch (harmonia mundi, т. 8, сессии 2011–12, корпусный год 2014)** — ЕДИНСТВЕННАЯ мужская запись фонда; свод отмечен Diapason d'Or, но похвала относится к своду, не к треку (правило скепсиса). В слоте 1990–2014 уступил Лотт (у той — тематически центральный том с прямой прессой). Резерв.
- **Mitsuko Shirai / Höll (Capriccio, 1988?)** — год сессии не документирован, рецензий нет, самое медленное прочтение фонда; ниже тройки старых мастеров по совокупности свидетельств.
- **Julia Borchert / Eisenlohr (Naxos DSLE т. 24, 2007)** — ценность только принадлежностью к полному изданию; певица вне фонда дайджеста.
- **Elly Ameling / Baldwin (Etcetera, ℗ 1983)** и **Edith Mathis / Engel (DG, ~1988)** — сильные по существу кандидаты, но на YouTube отсутствуют (отрицательный результат по Topic-каналам и фан-загрузкам) — непубликуемы.
- **Elisabeth Speiser / Gage** — альбом и год не установлены, певица вне приоритетов — по правилам непубликуема.
- **Приоритеты 1–3**: Квастхоф, Фишер-Дискау (женские песни исключал из свода), Шварцкопф, а также Хоттер, Андерс, Э. Шуман — песню не записывали (верифицировано MusicBrainz + yt-dlp, см. досье).

## Соответствие правилам состава

3 записи ранее 1990 (1973, 1977, 1983) ✓; 2 записи 1990+ (1992, 2024) ✓; из них 1 запись 2015+ (2024) ✓. Обе редакции представлены: D 745a — Людвиг; D 745b — Яновиц, Лотт. Порядок — по иерархии: группа §4 (Попп → Людвиг → Яновиц, по качеству), затем современные (Лотт → Сэмпсон, по качеству).
