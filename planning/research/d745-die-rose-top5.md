# Die Rose (D 745) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: `docs/rules/youtube-performances.md`. Досье: `planning/youtube/data/d745-die-rose.dossier.json` (14 значительных записей; глубина «famous»). Все итоговые и резервные видео проверены через oEmbed — живы, официальные Topic-каналы.

Особенность фонда: песня в дисковой практике — женский рецитальный номер (единственная мужская запись — Гёрне). **Ни один исполнитель пунктов 1–3 иерархии приоритетов песню не записывал**: Квастхоф, Фишер-Дискау (в его своде DG «женские» песни сознательно исключены), Шварцкопф — отрицательный результат по MusicBrainz и yt-dlp; Хоттер, Андерс, Э. Шуман — тоже не записывали. Пятёрка начинается с пункта 4 (звёзды прошлого). Сравнительных обзоров именно D 745 не существует (klassik-prisma страницы не имеет); единственный найденный «сравнительный вердикт» — отбор записи Попп в историческую антологию EMI «Schubert — Lieder on Record 1898–2012».

Песня существует в двух редакциях (D 745a / D 745b); пятёрка представляет обе.

## Итоговый топ-5

1. **Lucia Popp / Irwin Gage** — студийный рецитал EMI, сессии 1–6.11.1983, Abbey Road, прод. John Mordler; изд. 1984 (на YouTube — «Icon: Lucia Popp», Warner). Ей 44 — внутри пика (~1970–1988; позднего спада у Попп практически нет). Сильнейший объективный маркер фонда: именно эта запись отобрана в антологию EMI «Schubert — Lieder on Record 1898–2012» (Discogs 23802614; MusicBrainz) — де-факто признание её референсной для песни; также в «The Collector's Edition». Приоритетная певица правил (§4); прецедент Попп/Gretchen (отсев за слабость) здесь не действует — по D 745 картина обратная: канонический статус. Из двух её версий 1983 года студийная предпочтена зальцбургскому лайву (документированность, общее правило проекта). Видео: 0DO-kK4OLFg (Lucia Popp - Topic; 193 с ↔ MB 192,7 с — студийная, не лайв).
2. **Christa Ludwig / Irwin Gage** — зап. 21–24.06.1973, Вена, Tonstudio Rosenhügel (дискография Грея); DG 2530 404 «Schubert-Lieder» (℗ 1974), прод. Cord Garben. Ей 45 — верхняя граница пика (~1957–1975): голос ещё полный и ровный. Приоритетная певица правил (§4). Поёт первую редакцию (D 745a). Год 1973 — сквозная конвенция корпуса для этого альбома (d553, d686, d191). Осторожность из досье (риск «слишком крупного» голоса в миниатюре — по аналогии с критикой её D 828 того же круга) не перевешивает статус и состояние голоса. Видео: pZqoP77wJKg (Christa Ludwig - Topic).
3. **Gundula Janowitz / Irwin Gage** — 4-LP свод DG «Schubert: Lieder» (2713 012 / 2530 858), сессии 1976–77, Studio Lankwitz, Берлин, прод. Cord Garben; корпусный год свода — 1977. Ей 40 — сердцевина пика (~1965–1980): инструментальная ровность, «серебряный» тон. Серия дважды удостоена Deutscher Schallplattenpreis. Поёт вторую редакцию (D 745b) — вместе с Людвиг пятёрка закрывает обе редакции уже в «старом» ярусе. Видео: KEE2SbLNHkE (Gundula Janowitz - Topic).
4. **Felicity Lott / Graham Johnson** — Hyperion Schubert Edition, т. 19 «Songs about flowers & nature» (CDJ33019), зап. июль 1992, Rosslyn Hill Unitarian Chapel; изд. XI.1993. Ей 45 — рецитальная зрелость. Тематически центральная запись песни (том целиком о цветах и природе), редкая для фонда прямая пресса о томе: In Tune — «Rarely can one find a recording where every single aspect — repertoire, performance and production — is perfect. This is»; Répertoire — «art vocal propre, parfait», «prononciation impeccable». Вторая редакция. Слот 1990-х: предпочтена Шефер/Джонсон-1995 как более ранняя из двух сходных по уровню Hyperion-записей и как носитель более сильных персональных цитат прессы. Видео: NJDF0t1moR8 (Graham Johnson - Topic — официальная загрузка UMG Hyperion-свода).
5. **Carolyn Sampson / Joseph Middleton** — «Schubert's Four Seasons» (BIS-2703), зап. 25–28.02.2024 (буклет, Discogs 34201693; релиз 04.04.2025 — в плеере год сессии 2024). Ей 50 — зрелый пик (~2010–наст.), третий шубертовский диск устоявшегося дуэта с Мидлтоном; аннотация — Susan Youens. Единственный кандидат яруса «не ранее 2015» с официальной загрузкой; дуэт уже подтверждён в корпусе (Gretchen-топ5). Пресса о треке отсутствует — включение по правилу состава при достойном (не пиарном) базовом уровне. Видео: 41x92f-6rC8 (Carolyn Sampson - Topic).

## Ключевые решения и отклонённые кандидаты

- **Порядок внутри группы «звёзды прошлого»**: у Попп — единственный внешний сравнительный вердикт по песне (антология EMI), поэтому она выше Людвиг и Яновиц, несмотря на более поздний год; Людвиг выше Яновиц как именной приоритет §4 при сопоставимом состоянии голоса.
- **Popp / Gage, лайв Зальцбург 10.08.1983 (Orfeo, ℗ 2016; 9M_mpVbg1qY)** — то же лето, тот же дуэт; дубль певицы. По правилу проекта студийная документированная запись предпочтительнее без прямых свидетельств превосходства лайва. Первый резерв.
- **Christine Schäfer / Johnson (Hyperion т. 27 «Schubert & the Schlegels», зап. III.1995)** — профильный шлегелевский том, сильная пресса (BBC Music Magazine: «Another jewel in the Schubert Edition crown»), певица в пике. Уступила Лотт слот 1990-х: записи сходного уровня → более ранняя (1992), плюс у тома Лотт цитаты категоричнее. Резерв.
- **Christine Schäfer / Gage (Orfeo, изд. 1997; год сессии не установлен)** — дубль певицы, рецензий нет; отпадает вслед за её же Hyperion-версией.
- **Matthias Goerne / Deutsch (HM, т. 8 свода, сессии 2011–12, изд. 2014)** — единственная мужская запись фонда; похвалы (Diapason d'Or) относятся к своду, не к треку (правило скепсиса). Уступил Лотт (прямая пресса тома) и Сэмпсон (слот 2015+). Резерв.
- **Mitsuko Shirai / Höll (Capriccio, 1988?)** — год сессии не документирован, рецензий нет, самое медленное прочтение фонда; вне пятёрки.
- **Julia Borchert / Eisenlohr (Naxos DSLE т. 24, 2007)** — ценность только принадлежностью к полному изданию; певица вне фонда дайджеста; вне пятёрки.
- **Elly Ameling / Baldwin (Etcetera, 1983)** и **Edith Mathis / Engel (DG, ~1988)** — сильные по существу кандидаты, но на YouTube отсутствуют (проверено yt-dlp по Topic-каналам и фан-загрузкам) — непубликуемы.
- **Elisabeth Speiser / Gage** — альбом и год не установлены, певица вне приоритетов — по правилам непубликуема.

## Соответствие правилам состава

3 записи ранее 1990 (1973, 1977, 1983) ✓; 2 записи 1990+ (1992, 2024) ✓; из них 1 запись 2015+ (2024) ✓. Обе редакции представлены: D 745a — Людвиг; D 745b — Яновиц, Лотт (редакция записи Попп в источниках не размечена). Возрастная структура выполнена без ущерба качеству: пятёрка = все три «звезды прошлого» фонда с живыми видео + сильнейшая запись 1990-х + единственный официальный кандидат 2015+.
