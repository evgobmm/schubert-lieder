# D 554 «Uraniens Flucht» — топ-3

Большая баллада на Майрхофера (1817), ~18–21 мин — одна из самых протяжённых песен Шуберта. Приоритетных исполнителей нет вовсе: Квастхоф, Шварцкопф — нет; **Фишер-Дискау D 554 не записывал** (точный поиск по YouTube и MB даёт только три записи ниже). Порядок — группа 5 (современные), между собой по качеству. Источники: реестр, MusicBrainz, Discogs (Tudor 764); oEmbed — все ID живы (2026-08-17).

**Снят вопрос досье о «странной длительности»**: 18–21 мин — нормальная длина этой песни, а не сборный трек. Подтверждение: трек-лист Discogs 9020369 (Tudor 764) даёт «Uraniens Flucht — 20:58».
