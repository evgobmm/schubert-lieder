## Найденная проблема: порядок нарушает строгую иерархию приоритетов

Правило («Порядок записей в топ-5 — строгая иерархия приоритетов»): Квастхоф → Фишер-Дискау → Шварцкопф → прочие звёзды прошлого (между собой по качеству) → современные (между собой по качеству); «возрастная структура влияет на состав пятёрки, не на порядок».

Фактический порядок в `performances.json` (одинаковый для всех 24 песен цикла): **Квастхоф → Маттеи → Фишер-Дискау → Андерс → Хоттер**. Это ставит современного исполнителя (группа 5) на второе место — выше Фишера-Дискау (группа 2, приоритет №2 всегда) и выше обоих старых мастеров (группа 4). Хронологический порядок годов записи (1997/98, 2018, 1962, 1945, 1942) здесь, по-видимому, случайно совпал с фактическим расположением — похоже на то, что список был отсортирован не по иерархии, а по другому принципу (например, «сначала недавно найденные / приоритетные-и-современные»).

**Рекомендуемый порядок**: Квасхоф → Фишер-Дискау → Андерс → Хоттер → Маттеи (Шварцкопф пятёрку не заполняет — Winterreise написан для низкого мужского голоса, в дайджесте фонда певцов (`planning/research/singers-digest.md`) записи цикла у неё не значится). Взаимный порядок Андерс/Хоттер внутри группы «старые мастера» не пересматривался (недостаточно сравнительных данных, чтобы предпочесть один другому по качеству; сохранена прежняя относительная позиция).

Правку `performances.json` не вносил (запрет задания на этот прогон); правку нужно применить отдельным коммитом **сразу ко всем 24 песням цикла** (это один и тот же массив на все 24 slug'а) — заодно с исправлением года Квасхофа (1997→1998).
