# Heidenröslein (D 257) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Ярус: famous. Основа — досье `planning/youtube/data/d257-heidenroslein.dossier.json` (дискография Майкла Грея, MusicBrainz work 43118055, реестры альбомов проекта, ℗-строки официальных Topic-загрузок — только как год издания). Особенность фонда: у klassik-prisma сравнительной страницы по D 257 НЕТ (проверено по полному указателю Шуберта), слепых тестов не найдено — ранжирование опирается на документированное состояние голоса, репутацию изданий в реестре проекта и иерархию приоритетов. Все 5 итоговых видео перепроверены через oEmbed 2026-08-17 — живы, официальные Topic-каналы.

## Итоговый топ-5

1. **Thomas Quasthoff / Justus Zeyen** — зап. ноябрь 2003, Bavaria Musikstudios, Мюнхен; DG «Widmung – Romantische Lieder» (℗ 2004; переизд. «A Romantic Songbook»). Ему 44 — внутри пика (~1993–2007 по дайджесту), до ухода из классического пения (2012). Единственная его запись песни; альбом уже верифицирован в реестре по D 799 и D 853. Приоритет №1 правил — при достойной записи всегда первая строка; запись достойная: голос в полной форме, каноническая DG-студия. Видео: JUzOCewcxuU (Quasthoff Topic).
2. **Dietrich Fischer-Dieskau / Gerald Moore** — сессии 16–17.12.1966 и 2–10.01.1967, Berlin UFA Studio (дискография Грея; LP DG 2530 229 «Goethe-Lieder», свод DG «Sämtliche Lieder»); в плеере — 1969 по конвенции сквозного года свода (complete-editions.md). Ему 41 — внутри пика ~1951–1972. Базовая точка отсчёта для любой мужской песни Шуберта. Из двух его версий выбрана DG: EMI-версия (℗ 1965) дискографически не датирована (у Грея сессии нет) — по note досье публикуется DG. Видео: 07VkE7E0D-U (F.-Dieskau Topic, самая просматриваемая официальная загрузка песни).
3. **Elisabeth Schwarzkopf / Gerald Moore** — студийная EMI/Columbia, продюсер Walter Legge; ℗ 1966 Parlophone («The Elisabeth Schwarzkopf Song Book, Vol. 1» и др.). Точная сессия не установлена (у Грея записи нет; верхняя граница ~1964 — год ухода Legge из EMI), т. е. внутри пика 1948–1964. По правилу «хорошая запись приоритетного певца не блокируется неустановленным годом» публикуется с year в формате `"1966?"` — строкой, со знаком вопроса (год издания ℗; кандидат на целевое доисследование даты). Самая протяжённая трактовка пула (130–132 с) — детально «рассказанная» строфика. Предпочтена её же зальцбургскому лайву (Orfeo): качество сходно, датировка студии строже. Видео: PoWk5MEX1H0 (Schwarzkopf Topic).
4. **Fritz Wunderlich / Hubert Giesen** — сессии 2–5 июля 1966, Akademie der Wissenschaften, Мюнхен; DG 139 220 «Die schöne Müllerin + Lieder» (дата двойно подтверждена: Грей + карточка реестра по D 800). Ему 35, «только пик» (дайджест) — последние студийные записи певца, за два месяца до гибели. Сильнейшая по качеству заявка группы «прочие старые мастера»: эталонные мюнхенские сессии, голос в абсолютной форме. Видео: 5XI3ATTa4vI (Wunderlich Topic).
5. **Florian Boesch / Malcolm Martineau** — зап./изд. 2016, Onyx ONYX 4149 «Schubert: Lieder Recital» (альбом верифицирован в реестре по D 805, D 806). Ему 45 — внутри пика ~2010–наст.; «рассказчик венской школы» (дайджест) — манера, органичная народно-строфической миниатюре. Единственный достойный кандидат слота «не ранее 2015»: против Appl-2023 и Sampson-2025 — устоявшееся положение в реестре проекта и зрелая репутация в шубертовском репертуаре. Видео: QzoZ4w2PLVI (Boesch Topic).

## Ключевые решения и отклонённые кандидаты

- **Alexander Kipnis / Moore (20.10.1936, Columbia LX 665, матрица 7868)** — самый тяжёлый отказ: дискографически безупречная запись, редкий настоящий бас в этой миниатюре, пик формы. Проиграл единственный оставшийся слот старых мастеров Вундерлиху: у того эталонные последние сессии в современном звуке DG против 78-оборотной стороны. Резерв №1 на слот до 1990.
- **Elisabeth Schumann / Alwin (℗ 1928)** — именной приоритет (п. 4 правил), но привязка к сессии не доказана (у Грея записи нет; известная сессия 14.11.1927 её не содержит), звук конца 1920-х уступает; при одном свободном слоте группы уступила Вундерлиху и Кипнису по качеству записи. Кандидат на переоценку после матричного поиска.
- **Fischer-Dieskau / Moore, EMI-версия (℗ 1965)** — та же пара исполнителей, сессия у Грея не индексирована; по note досье публикуется документированная DG-версия. Возможный пересмотр после доисследования даты (более ранняя = голос свежее).
- **Irmgard Seefried (Columbia 1947, von Nordberg)** — прекрасно документирована (матрица 978, зал Брамса), но на Topic-канале четыре разных Heidenröslein (103/108/109/134 с) и привязка videoId к изданию предварительная — публиковать рискованно; уступает Вундерлиху/Кипнису по весу.
- **Julia Culp (1914)** — старейшая значительная запись (матрица 14536), ценность историко-документальная; акустический звук проигрывает всему пулу.
- **Hermann Prey** — версия 1952 с Раухайзеном на YouTube отсутствует; версия с Энгелем (℗ 1965) не датирована по сессии и с расхождением лейбла в реестре; версия 1971 (Хокансон) — только фан-загрузка.
- **Ameling / Baldwin (20–21.06.1972)** и **Baker / Moore (1970)** — сильные, полностью документированные женские записи; не поместились: слоты до 1990 заняты приоритетниками (Ф.-Дискау, Шварцкопф) и Вундерлихом. Ближайшие резервы.
- **Peter Schreier / Olbertz** — самая просматриваемая версия песни на YouTube (583 тыс.), но канал неофициальный, год записи не документирован — по правилам непригодна.
- **Современные 1990-х (Bonney 1994, Terfel 1994, von Otter 1996, Bostridge 1996, Goerne 1997)** — слот «не ранее 1990» занят Квастхофом (2003), который выше всех их по иерархии; второй современный слот отдан 2015+ (Boesch). Лучший резерв группы — Bostridge 1996 (дебютный рецитал с Дрейком, «сильнейшая студийная работа раннего периода» по реестру).
- **Appl (2023), Sampson (2025)** — альтернативы слоту 2015+; у обоих нет самостоятельной критической репутации в этой песне (правило скепсиса к пиару), сессии не датированы. Резерв слота — Appl (линия ученика Фишера-Дискау).
- **Приоритетники без записи (негативы досье)**: Хоттер, Андерс, Попп — записи D 257 нет (MusicBrainz + Грей + Topic-каналы); Людвиг — след без даты и пианиста, к публикации непригодно. Ложный след: ролик Андерса «Sah ein Knab’…» — оперетта Легара «Фридерика», не Шуберт.
