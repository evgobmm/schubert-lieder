## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — сессия 7–8 мая 1962, Берлин-Целендорф, Evangelisches Gemeindehaus; Electrola E/STE 91 204, «VII. Folge: Gedichte von Heine, Rückert und Schlegel» (Michael Gray id 59118; треклист Discogs 14368009). Ему 37 — абсолютный пик (по дайджесту ~1951–1972), Мур на своём пике. Из двух его студийных версий правила выбирают раннюю: DG-версия 1969 (Ufa-Ton-Studio, буклет DG 437 225-2) — часть сводного 21-CD собрания, тон плотнее, интерпретация «сессионная»; версия 1962 — из именной шубертовской серии Electrola, к которой отсылают все переиздания EMI/Warner. Видео: vfTfh8WzO7w (Fischer-Dieskau Topic, Warner «Schubert: 21 Lieder»).
2. **Hans Hotter / Gerald Moore** — сессия 3–4 октября 1957, Abbey Road, продюсер Walter Legge; Columbia 33CX1626 (℗1959), переизд. EMI References / «Icon» (буклет Warner, зафиксирован в реестре альбомов). Ему 48 — сразу за пиком (~1942–1955): голос ещё крупный и тёмный. Единственная версия D 741 в антологии Diapason «Les Indispensables de Diapason — Schubert: Lieder» (2023) — внешний редакционный маркер канона по этой песне. Радиоверсия с Раухайзеном (1942–45?) отклонена: год не установлен, загрузка через серого агрегатора, звук с износом. Видео: v9ARbO7UyMo (Hotter Topic, Warner-релиз).
3. **Heinrich Schlusnus / Michael Raucheisen** — сессия: ноябрь 1924, Polydor 66611, матрица as 2069 (Michael Gray id 209915); переизд. Preiser «Lebendige Vergangenheit». Ему 36 — пик (1920-е–1930-е). Эталон немецкого лирического баритона своего поколения с легендарным legato — прямое попадание в характер этой кантиленной песни; записывал её четырежды (1924, 1927, 1938, 1948) — сама по себе мера его связи с ней; берётся самая ранняя, по правилу и по свежести голоса. Официальная загрузка Preiser. Видео: iOE0fscnZ_M (Raucheisen Topic).
4. **Ian Bostridge / Julius Drake** — сессия: ноябрь 2000, St George's Brandon Hill, Бристоль; EMI «Schubert Lieder, Volume II» (буклет по Discogs 11474396, ℗2001). Ему 35 — пик (~1995–2010), до поздней манерности. Сильнейший современный кандидат с документированным годом сессии; тенор даёт и тембровый контраст двум баритонам и Шлуснусу. Wigmore-лайв ~2015 того же дуэта отклонён: после пика, дата концерта не установлена, дубль по певцу. Видео: Qt8nzJhcESI (Bostridge Topic, Warner).
5. **Bernarda Fink / Gerold Huber** — запись 2007 (по дайджесту фонда; издание harmonia mundi, релиз 02.09.2008 — буклетное подтверждение даты сессии осталось хвостом). Ей ~52 — внутри пика (~1995–2015); ровное тёмное меццо, стилистически строгий дуэт с Хубером (со-победитель слепого теста 2020 по Gretchen — оценка другой песни, но показатель уровня дуэта). Единственный женский голос пятёрки и сильнейшая современная женская версия пула. Видео: jMu7uRDbOyk (Fink Topic, harmonia mundi).

## Ключевые решения и отклонённые кандидаты

- **Fischer-Dieskau / Moore, DG 1969** — та же пара на пике, но на 4 года позже и «сводная» по духу; правило «сходные по уровню → более ранняя» отдаёт слот версии 1962. Первый резерв.
- **Lotte Lehmann / Gurlitt (Odéon, 6.12.1927)** — одна из самых известных исторических версий, пик певицы; не взята в пятёрку из-за отсутствия официальной загрузки (только фан-каналы; osN1E4z0roo не прошёл oEmbed) при наличии равновеликого старого мастера (Шлуснус) с официальным Preiser-треком. Резерв.
- **Ernst Haefliger / Klust (DG, 10+12.11.1956)** — редкий теноровый голос старой школы, документированная сессия (Gray id 4251); уступил Шлуснусу по масштабу фигуры и по значимости версии. Резерв.
- **Elly Ameling / Baldwin (Philips, ℗1983)** — крупная шубертианка, но поздняя часть пика (ей ~50), год сессии не установлен, заметно беглый темп (3:20 — самая короткая версия пула).
- **Hans Hotter / Raucheisen (1942–45?)** — документ пика, но год не установлен и загрузка неофициальная; студийная версия 1957 с Легге предпочтительнее по всем формальным признакам.
- **Julia Hamari / Werba (DG, ℗1969)** — свежий ранний голос, но фигура вне исследованного фонда, год сессии не установлен.
- **Koningsberger / Johnson (Hyperion т. 28, 1996)** — научно-контекстная ценность («шубертиада 1822 года»), вокально не первый ряд.
- **Bostridge / Drake, Wigmore Hall Live (~2015)** — после пика, дата не установлена, дубль по певцу.
- **Felicity Lott / Johnson (IMP, год «?»)** и **Ian Partridge / Lush (SOMM 2023 — радиоархив 1960–70-х)** — неустановленные даты, вне ядра фонда.
- **M. Schäfer / Eisenlohr (Naxos DSLE т. 25)** — справочная полнота, не конкурент.
- **Dorliak / Richter (Мелодия 1953/56)** — исполнение на русском языке, для проекта непригодно. **Schreier** — единственная находка неатрибутируема (издание не установлено).
- Ловушки выдачи (в отбор не идут): Таубер «Sei mir gegrüßt» — композитор Franz Grothe, не Шуберт; «Release - Topic» nTgAYab8Ro4 — Pollitzer/Ujaldón; ролики Гёрне и др. под этим заголовком — «Alfonso und Estrella» либо оперетта Штрауса; инструментальные транскрипции (Ибрагимова, Солтани, Лист S. 558/1).
