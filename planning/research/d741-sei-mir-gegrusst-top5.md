# Sei mir gegrüßt (D 741) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Ярус — famous (не менее 14 коммерческих версий до 1950 по дискографии Грея). Досье кандидатов: planning/youtube/data/d741-sei-mir-gegrusst.dossier.json; даты сессий — по дискографии Майкла Грея (classical-discography.org) и буклетам изданий (Discogs API), не по метаданным загрузок. Все 5 итоговых видео проверены через oEmbed (живы, встраиваемы).

Особенность фонда: из восьми приоритетных певцов правил песню записали только Фишер-Дискау (дважды) и Хоттер (дважды) — Квастхоф, Шварцкопф, Андерс, Э. Шуман, Людвиг и Попп проверены с отрицательным результатом (MusicBrainz + дискография Грея + целевой YouTube-поиск; по Квастхофу — закрытая дискография из 6 шубертовских альбомов без D 741). Сравнительной страницы klassik-prisma по песне нет — привычного пятибалльного ориентира нет, опора на дискографический канон, состояние голоса и правила предпочтения ранних версий.

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — зап. 7–8.05.1962, Берлин-Целендорф, Evangelisches Gemeindehaus; Electrola E/STE 91 204, «VII. Folge: Gedichte von Heine, Rückert und Schlegel» (Michael Gray id 59118; треклист Discogs 14368009). Ему 37 — абсолютный пик (~1951–1972), Мур на своём пике. Более ранняя из двух его студийных версий: DG-версия 1969 года (полное собрание, Ufa-Ton-Studio) — «сводная», сессионная, на четыре года позже; по правилам «сходные по уровню → более ранняя» и о состоянии голоса выбрана EMI-1962. Высший из записавших песню приоритетов правил → № 1. Видео: vfTfh8WzO7w (Fischer-Dieskau Topic, Warner «Schubert: 21 Lieder»).
2. **Hans Hotter / Gerald Moore** — зап. 3–4.10.1957, Abbey Road, прод. Walter Legge; Columbia 33CX1626 (℗1959), переизд. EMI References / «Icon» (буклет Warner в реестре альбомов). Ему 48 — сразу за пиком (~1942–1955): голос ещё крупный и тёмный. Единственная версия D 741, отобранная в редакционную антологию Diapason «Les Indispensables de Diapason — Schubert: Lieder» (2023) — фактический маркер канона по этой песне. Радиоверсия с Раухайзеном (1942–45, голос свежее) отклонена: год не установлен, загрузка — серый агрегатор. Видео: v9ARbO7UyMo (Hotter Topic, Warner-релиз — предпочтён «Icon» и Diapason-обёрткам).
3. **Heinrich Schlusnus / Michael Raucheisen** — зап. ноябрь 1924, Polydor 66611, матрица as 2069 (Michael Gray id 209915); переизд. Preiser «Lebendige Vergangenheit». Ему 36 — пик (1920-е–1930-е): эталон немецкого лирического баритона, легендарное legato. Песня — его фирменная: четыре версии за карьеру (1924 Раухайзен, 1927 Rupp, 1938 Peschko, 1948 Decca/Peschko); по правилу ранней версии взята первая, пиковая. Исторический слот пятёрки — граммофонный «шлягер» в исполнении главного его носителя. Видео: iOE0fscnZ_M (Raucheisen Topic, Preiser — официальная загрузка, в отличие от фан-переносов).
4. **Ian Bostridge / Julius Drake** — зап. XI.2000, St George's Brandon Hill, Бристоль; EMI «Schubert Lieder, Volume II» (буклет по Discogs 11474396, ℗2001, прод. John Fraser). Ему 35 — пик (~1995–2010), до поздней манерности. Единственный сильный кандидат «не ранее 1990» с документированным годом сессии; теноровый голос разбавляет баритоновый верх списка. Его же концертная версия Wigmore (~2015) отклонена: после пика, дата концерта не установлена, дубль по певцу. Видео: Qt8nzJhcESI (Bostridge Topic, Warner).
5. **Bernarda Fink / Gerold Huber** — зап. 2007 (по дайджесту фонда; изд. harmonia mundi 02.09.2008). Ей ~52 — внутри пика (~1995–2015): ровное тёмное меццо, стилистически строгое. Дуэт Финк/Хубер — со-победитель слепого теста 2020 по Gretchen (оценка другой песни, но показатель уровня). Сильнейшая современная женская версия пула; замыкает пятёрку как второй слот «1990+». Видео: jMu7uRDbOyk (Fink Topic, harmonia mundi).

## Ключевые решения и отклонённые кандидаты

- **Fischer-Dieskau / Moore, DG 1969** (Ufa-Ton-Studio, буклет DG 437 225-2) — та же пара, песня в полном своде; самая слушаемая версия на YouTube, но на 7 лет позже эталонной EMI и «справочная» по характеру. Дубль по певцу — в пятёрку одновременно не идёт. Первый резерв.
- **Hotter / Raucheisen (1942–45?)** — документ самой свежей формы Хоттера, но год не установлен, звук с износом, канал — Topic серого агрегатора (Believe SAS). При двух версиях певца выбрана студийная 1957 с Легге и Муром — та, что канонизирована Diapason.
- **Lotte Lehmann / Gurlitt (Odéon, 06.12.1927, Gray id 111191)** — одна из самых известных исторических версий; отклонена по технической гигиене: официальной загрузки нет, только фан-каналы (один из двух роликов не прошёл oEmbed). Исторический слот отдан Шлуснусу (официальный Preiser-Topic, пиковая форма, «его» песня). Резерв.
- **Ernst Haefliger / Klust (DG, 10+12.11.1956, Gray id 4251)** — редкий теноровый голос старой школы, пик, официальная загрузка; уступил Шлуснусу и Хоттеру по масштабу фигуры именно в Lied и остался за пределами трёх «старых» слотов. Резерв.
- **Elly Ameling / Baldwin (Philips, ℗1983)** — поздняя часть пика (~50 лет), тембр без юношеской свежести; самая быстрая версия пула (3:20). Ниже трёх выбранных «старых» записей.
- **Julia Hamari / Werba (DG, ℗1969)** — свежий ранний голос, но фигура вне исследованного фонда, дата сессии не установлена, критического следа нет.
- **Koningsberger / Johnson (Hyperion т. 28, зап. III.1996)** — научный эталон контекста («шубертиада 1822 года»), но вокально не первый ряд (оценка досье); в современные слоты выбраны Бостридж и Финк.
- **Felicity Lott / Johnson (IMP, год не установлен)** и **Ian Partridge / Lush (SOMM 2023, радиоархив без даты)** — неустановленные годы и фигуры вне ядра фонда.
- **Markus Schäfer / Eisenlohr (Naxos DSLE т. 25)** — опорная точка полноты издания, не конкурент.
- **Дорлиак / Рихтер (Мелодия, 1953/1956)** — исполнение на русском языке, для проекта непригодно. **Peter Schreier** — единственная находка не атрибутирована к изданию. **Ловушки выдачи**: Tauber «Sei mir gegrüßt» — композитор Franz Grothe, не Шуберт; ролик «Release - Topic» nTgAYab8Ro4 — Pollitzer/Ujaldón; «Sei mir gegrüsst» у Гёрне — ария из «Alfonso und Estrella» D 732; инструментальные транскрипции (Ибрагимова, Солтани, Лист) не в счёт.

## Соответствие возрастной структуре

3 записи ранее 1990 (1924, 1957, 1962) ✓; 2 записи 1990+ (2000, 2007) ✓; слот 2015+ — **пуст, достойного кандидата нет**: единственная версия периода — концертный Бостридж Wigmore (~2015, после пика, дата не установлена, дубль по певцу); по правилу «никогда в ущерб качеству» слот отдан лучшей доступной записи (Финк 2007). Порядок — по строгой иерархии приоритетов: Фишер-Дискау (№ 2 списка приоритетов) → звёзды прошлого по качеству (Хоттер — канон Diapason, затем Шлуснус) → современные по качеству (Бостридж 2000 — пик и документированная студия, затем Финк).
