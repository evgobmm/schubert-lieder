# Die Sterne (D 939) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: `docs/rules/youtube-performances.md`. Ярус — famous (песня заменила Der Wanderer an den Mond в программе единственного авторского концерта Шуберта 26.03.1828, пел Фогль — аннотация Грэма Джонсона к Hyperion CDJ33037). Досье: `planning/youtube/data/d939-die-sterne.dossier.json`. Все 5 итоговых видео + 3 резервных проверены через oEmbed 2026-08-17 (ok:true, все — официальные Topic-каналы).

Особенность фонда: из приоритетных исполнителей песню записывали только Фишер-Дискау (минимум 5 раз) и Попп (запись на YouTube отсутствует). Квастхоф, Шварцкопф, Хоттер, Андерс, Э. Шуман, Людвиг песню не записывали (проверено по MusicBrainz-работе — 23 записи, по Topic-каналам и поиску; см. досье). Сравнительных критических обзоров песни нет: у klassik-prisma страницы по D 939 не существует, WebSearch в сессии досье был исчерпан — ранжирование опирается на дискографическую документированность, состояние голоса и устоявшуюся репутацию исполнителей/альбомов.

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — студийный свод DG «Sämtliche Lieder» (сессии 1966–72, Ufa-Ton-Studio, Берлин; конвенция корпуса для свода — 1969; точная сессия D 939 у Грея не документирована). Певцу 41–47 — конец большого пика (~1951–1972), техника на максимуме. Базовая точка отсчёта всего корпуса; официальная Topic-загрузка (187 с). Выбран из пяти его версий: зальцбургский лайв с Муром моложе голосом, но год не установлен вовсе (диапазон в десятилетие, звук — концертный ORF); версия с Рихтером (1977) — за пиком («с сер. 1970-х тон суше»); EMI-версия 1950-х дискографически не идентифицирована и без официальной загрузки; версия с Хёллем (1987) — глубоко поздняя. Видео: tqEzYKKw5Co (Fischer-Dieskau Topic).
2. **Hermann Prey / Leonard Hokanson** — зап. 27–30.10.1971, Мюнхен; Philips «Lied-Edition» (бокс 6747 059; на Topic — «Lieder von Franz Schubert – Lied-Edition Vol. 2», ℗1974). Дата и пианист — дискография Майкла Грея (id 176422). Певцу 42 — середина пика (~1960–1980), один из двух главных баритонов-шубертианцев поколения. **Конфликт пианиста решён в пользу Грея**: Topic-кредиты называют Karl Engel, но это боксовый кредит без по-трековой разбивки (Discogs 6573 010 подтверждает смешение Engel/Hokanson по трекам), а метаданные загрузок по правилам верификации не источник; Грей документирует именно сессию D 939 с Хокансоном. Идентификация фонограммы надёжна: Topic-альбом — то самое издание Lied-Edition. Видео: cOpcDVeDS8Q (Prey Topic).
3. **Elly Ameling / Dalton Baldwin** — зап. 21–26.08.1973; Philips 6500 704 (LP 1974). Дата — дискография Грея (id 179179). Певице 40 — центр пика (~1965–1985), «самая записываемая шубертианка поколения»; классическая серия Ameling/Baldwin. Единственная доступная на YouTube записи женская версия яруса старых мастеров (Попп недоступна). Самая просматриваемая официальная загрузка песни (13,8 тыс.). Порядок Prey → Ameling внутри группы: критических оценок нет у обоих, уровень сходный → по правилу берёт верх более ранняя (1971 < 1973). Год в плеере — 1973 (сессия), не ℗1974. Видео: Yz2CPh6YFeY (Ameling Topic).
4. **Christoph Prégardien / Michael Gees** — «Lieder von Abschied und Reise» (EMI → Warner; 1992 по klassik-prisma, ℗1996). Певцу 36–40 — начало пика (~1990–2012), светлый теноровый звук в лучшем состоянии. Сильнейший кандидат 1990-х: альбом — единственная современная запись корпуса с 5 баллами klassik-prisma (оценка по Erlkönig с этого же диска) — независимая репутация, не пиар. Год 1992 — действующая корпусная конвенция этого альбома («Prégardien — Gees | 1992» уже опубликован в performances.json). Видео: o0yslEh71lg (Prégardien Topic).
5. **Carolyn Sampson / Joseph Middleton** — зап. 21–23.09.2020, «Elysium — A Schubert Recital» (BIS, изд. 2023). Сессия документирована по-трековой разбивкой MusicBrainz (сессия 2020 — только D 762, D 939, D 343; карточка реестра альбомов). Ведущая современная английская шубертианка в пике (~2010–наст.); третий шубертовский альбом линии Sampson/Middleton. Единственный по-настоящему достойный кандидат 2015+ (остальные — периферийные концепт-записи без карточек в дайджесте). Год в плеере — 2020 (сессия), не 2023. Видео: FIn8fGTJYxE (Sampson Topic).

## Ключевые решения и отклонённые кандидаты

- **Lucia Popp / Gage (EMI; 1983/1984, расхождение не разрешено)** — единственная женская запись приоритетного уровня; номер вышел только в боксе «The Collector's Edition» (CD 45). **На YouTube отсутствует** (проверены поиск и Topic-канал) — для плеера недоступна; при появлении официальной загрузки — немедленный кандидат в пятёрку по иерархии.
- **Fischer-Dieskau / Richter (Тур, 2+4.07.1977, DG 2530 988)** — легендарный документ: единственный совместный шубертовский вечер дуэта. Отклонён из пятёрки как второй FD-слот: голос за пиком, а место старого мастера ценнее отдать Праю/Амелинг (диверсность против дубля певца). Первый резерв слота старых мастеров.
- **Fischer-Dieskau / Moore (Зальцбург, бокс Orfeo «Die Salzburger Liederabende 1956–1965»)** — голос в центре пика, но год конкретного вечера не документирован (в плеер пришлось бы ставить «1956–65?»), звук — концертный ORF. Уступил студийному своду; кандидат на переоценку после целевого доисследования даты (том C 140 101 B документирован как 5.08.1957, но вхождение D 939 не подтверждено). Видео zHxarkda_9k (Topic) живо.
- **Fischer-Dieskau / Moore (EMI/Electrola, ~1957?)** — дискографически не идентифицирован (том серии не установлен), официальной загрузки нет, дата — только с фан-подписи. Не включён.
- **Fischer-Dieskau / Höll (1987)** — 62 года, «тон суше»; только фан-загрузка. Отклонён по возрасту голоса и техгигиене.
- **Pears / Britten («The Aldeburgh Recital»)** — великий дуэт, но дата концерта не документирована ни в одном издании: без даты не оценить состояние голоса Пирса (пик 1950–60-х, позже суше), а в плеер пришлось бы ставить диапазон шириной в десятилетия. Уступил полностью документированным Праю и Амелинг.
- **Padmore / Lewis (harmonia mundi, ℗2011)** — самый титулованный современный теноровый свод (трилогия; Gramophone Award 2010 за Winterreise). Уступил Прегардьену слот 1990-х/2000-х: у Прегардьена независимая оценка klassik-prisma против премиальной прессы (правило скепсиса к пиару), голос в начале пика, запись раньше. Резерв современного слота.
- **Banse / Johnson (Hyperion т. 36, зап. I.1999)** — научный эталон издания, свежий голос (30 лет), том с ключевой аннотацией Джонсона о лейтнеровском блоке. Уступила Прегардьену (независимая оценка) и Сэмпсон (слот 2015+). Резерв.
- **Rolfe Johnson / Johnson (Hyperion т. 6, зап. IX.1989)** — достойная запись научного эталона, но формально до-1990 слот, где конкуренция с Праем/Амелинг/FD безнадёжна.
- **Walker / Vignoles (CRD, 1989)** — зрелое английское меццо, документирована; тот же проигрыш в до-1990 конкуренции.
- **Haefliger / Dähler (Claves, 1986, хаммерклавир)** — 67 лет, «голос уже сухой»; ценность периодная, не вокальная. Отклонён.
- **Bostridge / Drake (Wigmore Hall Live, ℗2014)** — ~50 лет, после пика («манернее/суше»), дата концерта не установлена; его более ранняя студийная версия с Андснесом (EMI 2002) на YouTube не найдена. Отклонён.
- **Keenlyside / Martineau** — только фан-загрузки, происхождение фонограмм не подтверждено. Отклонён по техгигиене.
- **Периферия 2015+** (M. Schäfer 2017, Edelmann 2018, Johannsen 2019, Nigl 2020, Jaroussky 2020, Hughes 2016) — без карточек в дайджесте фонда и без независимых оценок; слот 2015+ уверенно закрывает Сэмпсон.

## Открытые вопросы

- Сравнительный критический слой (Gramophone, MusicWeb, слепые тесты) по D 939 не добран из-за исчерпанного лимита WebSearch в сессии досье — при доступном поиске отдельный проход может изменить порядок Prey ↔ Ameling и судьбу Padmore/Banse.
- Расхождение года Popp/Gage (1983 дайджест / 1984 Discogs) — разрешить по буклету EMI, если запись появится на YouTube.
- Корпусная примечание: в других песнях бокса Philips Lied-Edition встречается запись «Prey — Engel» с годом 1974 (℗) — для D 939 Грей документирует сессию 1971 с Хокансоном по-трековой записью; расхождения по другим песням бокса решать их собственными дискографическими проверками.
