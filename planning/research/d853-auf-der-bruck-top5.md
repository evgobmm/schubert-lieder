# Auf der Bruck (D 853) — отбор топ-5 исполнений

Дата: 2026-08-16. Правила: `docs/rules/youtube-performances.md`. Ярус — famous (Джонсон: «one of the most famous warhorses in the Schubert canon») → полное обоснование. База: досье `planning/youtube/data/d853-auf-der-bruck.dossier.json`; в этой сессии дополнительно закрыты по CHARM две дискографические дыры досье (Пирс—Бриттен и лайв с Рихтером — см. «Дискографические находки»). Все 5 итоговых видео + резервы проверены через yt-check (oEmbed): живы; весь топ-5 — официальные Topic-каналы.

## Итоговый топ-5

1. **Thomas Quasthoff / Justus Zeyen** — зап. ноябрь 2003, Bavaria Musikstudios, Мюнхен; DG «Widmung – Romantische Lieder» (изд. 01.04.2004; переизд. «A Romantic Songbook», 2012). Источники: реестр `planning/youtube/albums.md`; MusicBrainz recording dc0a2a5a…. Ему 44 — внутри пика (~1993–2007 по дайджесту), до ухода из классического пения (2012). Высший приоритет правил — всегда № 1 при достойной записи; запись студийная, в пике формы, умеренный (не гнатый) темп 3:27. Видео: `fHes5B6YNa4` (Quasthoff Topic, DG).
2. **Dietrich Fischer-Dieskau / Gerald Moore** — DG, публикуемый год 1969 — **редакционная конвенция, не верифицированный факт**: «эдиция внутри свода „Sämtliche Lieder“ (сессии 1966–1972, Ufa-Ton-Studio Берлин)», уже применённая в этом потоке к D 799, D 800, D 851, D 852, D 862; трек входит в «Lieder, Volume II» (DG 437 225-2 — MB d42b89e6…, 212 с). Точная сессионная дата D 853 внутри свода не установлена ни по буклету, ни по вторичному источнику; при этом для тома «Lieder Volume 1» того же бокса уже зафиксировано расхождение — Discogs release 3366698 датирован **1970**, не 1969 (`d862-um-mitternacht-top5.md`, «Примечания по верификации дат»). Решение project-wide: единоразовая сверка всего бокса по буклету/Discogs (и возможная унификация на 1970) — до итоговой публикации всех песен бокса, не по одной песне. Ему ~44 — внутри пика (~1951–1972), до сухости середины 1970-х. Приоритет № 2 правил; свод с Муром — базовая точка отсчёта для любой мужской песни Шуберта. Из его версий с установимой датировкой — лучшая по состоянию голоса (см. «Версии Фишера-Дискау»). Видео: `kqUykhqkcuQ` (Fischer-Dieskau Topic; на канале дубли `xxOKy6tV7AQ`, `4j-VfLE02xc` — резервные ID).
3. **Peter Pears / Benjamin Britten** — зап. **15.11.1950**, HMV, матрица 2EA 15068-2, изд. HMV DB 21423 — дата закрыта по CHARM (каталог Lehl); CHARM — правильный по правилам источник для 78-х, но вторичной независимой перепроверки (Britten–Pears Foundation, Boosey & Hawkes, книжные дискографии HMV/EMI) дата пока не имеет — CHARM и Discogs из контейнера при повторной сверке недоступны (bot-protection/403); досверить при появлении доступа; переизд. Heritage «Britten & Pears: The Early HMV Recordings», EMI-антология «Lieder on Record 1898–2012» (Warner, 2012). Пирсу 40 — вокально его лучшая пора (пик 1950-е–1960-е). Одна из великих шубертовских связок; включение именно этого трека в кураторскую антологию EMI — знак канонического статуса. Единственная довоенно-послевоенная «историческая» запись песни вообще (78-х других мастеров по этой работе не существует — негативы досье). Видео: `Q1iufova6ms` (Benjamin Britten Topic; дубль `bamVKQX-Uis` на Pears Topic — резервный ID).
4. **Peter Schreier / Graham Johnson** — зап. август 1992, St George's, Brandon Hill; изд. июнь 1993, Hyperion CDJ33018, том 18 «Schubert & the Strophic Song» (даты — страница издания hyperion-records.co.uk). Старый мастер (р. 1935, пик ~1965–1990) на самой границе пика, 57 лет. Пресса альбома — редкий для этой песни прямой критический след: Gramophone «Superlative», BBC Music Magazine «An outstanding disc in a distinguished series», Fanfare «One of the glories of the series». Том — реконструированный Джонсоном «цикл» песен на стихи Шульце как ступень к Winterreise, D 853 его открывает; научный эталон издания. Честные оговорки: транспозиция в A (оригинал G) и самый долгий темп пула (3:49). Видео: `S_FUAwQb9W8` (Schreier Topic).
5. **Samuel Hasselhorn / Ammiel Bushakevitz** — harmonia mundi HMM902747 «Licht und Schatten» (изд. 28.02.2025), том 2 проекта «Schubert 200» — программа целиком из песен 1824–1826, ровно раздел пилота. **Публикуемый год — 2025 (год издания)**, как в `d799-im-abendrot-top5.md` для этого же альбома: дата сессии «март 2024, студия b-sharp, Берлин» из отчёта по D 800 восходит к странице harmoniamundi.com, недоступной для перепроверки (403), а jpc.de даёт лишь «Aufnahmejahr ca. 2024» (метадата ритейлера) — собственное досье D 853 год записи честно помечает «не установлен». Независимо подтверждено в этой сессии по скану задника CD (Cover Art Archive, MB release f87a3c47…): D 853 в трек-листе, ℗ 2025. Слот «не ранее 2015»: единственный кандидат 2015+ с независимым непиаровым подтверждением — Diapason d'or de l'année 2025 и Bestenliste 2/2025 Preis der deutschen Schallplattenkritik за сам альбом. Видео: `OgQjx_iTOtQ` (Hasselhorn Topic; официальный ролик harmonia mundi `H-K6SP1JmaI` — резервный ID).

## Версии Фишера-Дискау (ключевое решение)

В фонде не менее пяти его версий; выбор между тремя реальными:

- **EMI с Муром (1950-е)** — вокально самая свежая («1957» — только из фан-метаданных двух загрузок; по правилам верификации не публикуется). CHARM (каталоги Lehl и Gray) этой записи не содержит; Presto/Discogs/поисковики из контейнера недоступны (403), WebSearch-бюджет исчерпан. Дата остаётся незакрытой → по конвейеру «сначала факт» версия в топ-5 не допущена. Первый кандидат на пересмотр слота № 2 после сверки по буклету Warner («The Great EMI Recordings», 2010).
- **DG-свод с Муром (℗ 1969)** — взят: пик голоса, официальный Topic, датировка по принятой конвенции потока.
- **Лайв со Святославом Рихтером** — дата закрыта в этой сессии по CHARM (каталог Gray): **02.07.1977, Тур, Grange de Meslay** (фестиваль Рихтера; LP DG 2530 988, CD DG 445 717-2) — фан-описание «1978» опровергнуто. Ему 52 — после пика, тон суше; уникальность — пианист первого ряда в песне, где, по Джонсону, движущая сила — именно левая рука пианиста. Не взят в топ: голос хуже версии 1969, загрузка только фанатская (`JMHq0twKY9o`). Первый резерв.

Зальцбургский лайв (Orfeo, 1956–65, вечер не установлен, загрузки нет) и поздняя версия с Хёллем (изд. 1999, вокально слабейшая) отпали без борьбы; неидентифицированный лайв с Заваллишем (`f-bNWu1Epjc`) — вне дискографий, не рассматривался.

## Отклонённые кандидаты

- **Florian Boesch / Roger Vignoles** (зап. XI.2012, Hyperion CDA68010) — сильнейший из отклонённых: единственный кандидат с прямыми цитатами крупной прессы по альбому, включая похвалу пианисту именно в этих труднейших аккомпанементах (The Guardian). Уступил современные слоты: Квастхофу и Шрайеру — по иерархии приоритетов и статусу, Хассельхорну — по квоте 2015+ (Бёш в неё не попадает: 2012). **Второй резерв.**
- **Christian Gerhaher / Huber** (зап. IX.2005, «Abendbilder», PdSK 2006) — достойный альбом, но песенно-специфичного критического следа нет; по времени конкурирует с Квастхофом-2003 — слот занят приоритетом № 1. **Третий резерв.**
- **Bryn Terfel / Martineau** (зап. II.1994, DG) — бестселлер, но «не циклист-шубертианец»; правило скепсиса к пиару; уступает Шрайеру-1992 (раньше и с несравненно более сильным критическим следом).
- **Matthias Goerne / Haefliger** (изд. 2013, HM Vol. 7) — крупнейший свод поколения, но самое быстрое прочтение пула (3:05, аргумент «гонки» из досье) и нет персональной критики трека.
- **Ian Bostridge / Andsnes** (изд. 2003, EMI) — попадание в антологию «Lieder on Record» — сильный маркер, но год записи не установлен (фактовый гейт) и по дайджесту поздний Бостридж манернее.
- **Christoph Prégardien** — неразрешённое противоречие досье (два разных издания/пианиста: Gees 219 с vs Drake 200 с) — по досье «до разрешения не публиковать».
- **Andrè Schuen / Heide** — альбом и год не верифицированы (тег Topic «2016» — не источник); в MusicBrainz записи нет.
- **Nathalie Stutzmann** (контральто) — единственная женская запись; необычная краска для мужской «песни-скачки», кандидат второго ряда без критического следа.
- **Paul Armin Edelmann** — без критической репутации, самое медленное прочтение; периферия.
- **Приоритеты правил, не записавшие песню**: Шварцкопф, Хоттер, Андерс, Э. Шуман, Людвиг, Попп — отрицательные проверки задокументированы в досье (`priority_singers_checked`); текст Шульце — мужская «песня-скачки» из круга, ведущего к Winterreise.

## Соответствие возрастной структуре

2 записи ранее 1990 (1950, 1969) + 3 записи 1990+ (1992, 2003, 2025), из них 1 — 2015+ (2025) ✓. Желательные «3 записи ранее 1990» невыполнимы без ущерба: весь довоенно-послевоенный слой песни — это один Пирс—Бриттен (78-х других старых мастеров не существует — негативы досье), а третий до-1990 слот означал бы второго Фишера-Дискау в пятёрке (Рихтер-1977) ценой достойного современного — правило прямо запрещает структуру в ущерб качеству и составу.
