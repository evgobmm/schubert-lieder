# Факты: «Mailied» (D 503)

Немецкий текст песни в проекте (4 строфы, старая орфография сохранена): `app/src/data/songs/d503-mailied.json` (текст, как приведён в бандле):

> Grüner wird die Au, / Und der Himmel blau; / Schwalben kehren wieder, / Und die Erstlingslieder / Kleiner Vögelein / Zwitschern durch den Hain. — [строфа 1]
> Aus dem Blütenstrauch / Weht der Liebe Hauch: / Seit der Lenz erschienen, / Waltet sie im Grünen, / Malt die Blumen bunt, / Roth des Mädchens Mund. — [строфа 2]
> Brüder, Küsset ihn! / Denn die Jahre fliehn! / Einen Kuß in Ehren / Kann euch niemand wehren! / Küßt ihn, Brüder, küßt, / Weil er kußlich ist! — [строфа 3]
> Seht, der Tauber girrt. / Seht, der Tauber schwirrt / Um sein liebes Täubchen! / Nehmt euch auch ein Weibchen, / Wie der Tauber thut, / Und seid wohlgemut! — [строфа 4]

Поэт — Людвиг Кристоф Генрих Хёльти (в фоссовской редакции, как и остальные 22 песни Шуберта на его тексты в проекте). Досье поэта: `planning/research/poets/hoelty.md` (факты оттуда переиспользуются со ссылкой «досье hoelty, Ф№», заново не проверялись). История записей: топ-3 в приложенном к бандлу файле рейтинга исполнений.

**Важная оговорка по источникам.** Предзагруженная для этого бандла страница schubertsong.uk (`https://www.schubertsong.uk/text/mailied/`) оказалась посвящена **другой** песне Шуберта — «Mailied (Der Schnee zerinnt)», D 130 и D 202, на другое стихотворение Хёльти («Der Schnee zerrinnt / Der Mai beginnt…», написано 17.2.1773). Это не тот текст, что положен на музыку в D 503 («Grüner wird die Au…»): у Хёльти два разных стихотворения с близким названием «Mailied»/«Maylied», и Шуберт обращался к ним в разных песнях (D 130/D 202 — к одному, D 503 — к другому). Контент этой страницы **не использован** ни для одного факта ниже — совпадение заголовков не означает совпадения текста. Специальной страницы schubertsong.uk именно для D 503 в бандле нет; попытки найти её и текст на schubertlied.de/LiederNet через поиск (DuckDuckGo, 3 запроса) результата не дали — либо индексация отсутствует, либо сеть в среде агента ограничена. Буклет Hyperion CDJ33023 предзагружен, но, по манифесту, строка про D 503 в нём не найдена.

Из-за этого фактическая база по самой песне D 503 (дата, тональность, форма, автограф, публикация) в бандле почти не представлена — заполнить её проверенными фактами из данного бандла не удалось; см. раздел «Не подтвердилось / не найдено».

## 1. Датировка и возраст Шуберта

**Ф1.** D 503 «Mailied» — один из 23 текстов Хёльти, положенных Шубертом на музыку в проекте; относится ко второй, весенней волне обращений к поэту в 1816 году (наряду с D 398, 399, 400, 401, 429, 430, 431, 433, 434, 436, 468) — досье hoelty, Ф26 (источник факта — `app/src/data/index.json`, поле `poet_de`) — verified (внутренний источник проекта). Точная дата сочинения (день и месяц) внутри 1816 года в бандле не приведена.

**Ф2.** Возраст Шуберта в 1816 году: родился 31 января 1797 года (дата приведена по образцу формата файла фактов — досье использует её для песен 1815 года; для 1816-го арифметика та же: Шуберту в течение всего 1816 года было либо 18, либо (с 31 января) 19 лет) — арифметика по дате рождения Шуберта, уже верифицированной в проекте для других песен (см. образец, Ф2 к D 198) — uncertain для точного возраста на момент сочинения именно D 503, поскольку точный день/месяц сочинения не подтверждён в этом бандле.

## 3. Текст и источник

**Ф3.** Текст стихотворения в нотах Шуберта, воспроизведённый в проекте, содержит орфографию эпохи, не изменённую в проекте: «Roth» (совр. «rot»), «Küsset», «Küßt», «kußlich», «thut» (совр. «tut») — прямое наблюдение по тексту песни, как он приведён в бандле — verified (внутренний источник — текст проекта).

**Ф4.** Общий для всего корпуса Хёльти–Шуберт факт (не проверен специально для D 503, но применим по методу издания): Шуберт пользовался не прижизненными публикациями Хёльти, а посмертными изданиями в редакции Иоганна Генриха Фосса, который «внёс многочисленные метрические и текстовые изменения, почти всегда во вред стихотворениям» — досье hoelty, Ф18 (NDB) — verified как общий факт о корпусе; применение конкретно к D 503 — uncertain, так как постраничная сверка Растля (schubertsong.uk) для этой песни в бандле отсутствует.

**Ф5.** Конкретное издание, которым, по данным, установленным Петером Растлем, пользовался Шуберт для текстов Хёльти в целом, — венское переиздание 1815 года: «Gedichte von L. H. Ch. Hölty. Neu besorgt und vermehrt von Johann Heinrich Voß. Wien, 1815. Bey Chr. Kaulfuß und C. Armbruster» — досье hoelty, Ф21 (Schubert Song Texts) — verified как общий факт; для D 503 конкретно (страница, разночтения с оригиналом Хёльти) в бандле подтверждения нет — uncertain.

Оригинал Хёльти «Grüner wird die Au» (дата написания, первая публикация, разночтения с фоссовской версией построчно) — не найден в бандле; сравнить по schubertsong.uk/LiederNet не удалось (см. вводный раздел).
