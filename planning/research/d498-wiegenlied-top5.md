# Wiegenlied «Schlafe, schlafe, holder süßer Knabe» (D 498) — отбор топ-5 исполнений

Дата: 2026-08-17; в тот же день — правка по замечаниям верификатора (закрыт конфликт названия Testament SBT 2172; год Людвиг/Парсонс переустановлен «1961–66?» → «1961–62?» по доисследованию; добавлено независимое подтверждение Discogs для Э. Шуман). Правила: docs/rules/youtube-performances.md. Ярус: famous (planning/youtube/triage.json). Досье: planning/youtube/data/d498-wiegenlied.dossier.json. Все 5 итоговых видео и 3 резерва проверены yt-check (oEmbed): живы, официальные Topic-каналы.

Особенность фонда: у klassik-prisma НЕТ сравнительного обзора D 498 (раздел Шуберта — только 9 позиций, песни среди них нет), поэтому привычной шкалы баллов не существует; ранжирование — по устоявшейся репутации певцов, состоянию голоса на момент записи, документированности и правилам приоритетов. Вторая особенность: из именных приоритетов песню записали только женщины — Квастхоф, Фишер-Дискау, Хоттер и Андерс её не записывали (проверено по MB-работе 439b6eca — 38 записей, по реестрам и по Грею; у Ф.-Д. в каталогах значится только колыбельная Брамса op. 49/4 — ловушка одноимённости). Мужских записей во всём фонде две, обе второго ряда (Lorenz; Schreier с гитарой — живого видео нет).

## Итоговый топ-5

1. **Elisabeth Schwarzkopf / Gerald Moore** — студийная EMI-запись, не изданная в своё время; впервые — Testament SBT 2172 «The Unpublished EMI Recordings 1946–1952» (1999), CD 2. Год сессии не установлен (буклет Testament недоступен); по Грею неизданные шубертовские сессии Шварцкопф/Мура — 21.05.1948, 02.12.1951, 11.09 и 21.09.1952, отсюда диапазон **«1948–52?»** по правилу о неустановленном годе приоритетного певца. Ей 31–37 — начало и середина пика (1948–1964), голос свежий, до поздней манерности далеко. Топ-1 среди женщин по правилам проекта; косвенный маркер класса связки тех же лет — эталонный рецитал 1952 и Gretchen-1952 (со-победитель слепого теста 2020). Конфликт названия релиза, вскрытый верификацией (Discogs release 31144637 называет ТОТ ЖЕ SBT 2172 — тот же barcode 749677217228, тот же трек-лист с Wiegenlied на CD 2 — «The Unpublished EMI Recordings 1955-1958»), закрыт третьим источником — каталогом самого лейбла: страница продукта SBT2172 на testament.co.uk даёт название «The Unpublished EMI Recordings 1946-1952», пианист Gerald Moore. Титул Discogs — ошибка ввода; диапазон «1948–52?» и возраст 31–37 остаются в силе. Видео: 3-CWQnNim_U (Schwarzkopf Topic, 190 с — совпадает с MB-длительностью студийной фонограммы 195 с; концертный вариант 176 с — отдельный ролик, см. резервы).
2. **Elisabeth Schumann / George Reeves** — HMV DB 3426, сессия 29.11.1937, London, Abbey Road Studio 3, матрица 2EA 6022 (дискография Грея, id 40198 — дата по матрице, не по метаданным архивов). Ей 49 — сразу за пиком, голос ещё в форме (в отличие от сессий 1945–49); тот же круг, что её знаменитая Gretchen-1936. Именной приоритет (п. 4) и естественнейший голос для этой песни: канон венской лёгкой лирики, колыбельный тон — её стихия. Внутри группы «звёзд прошлого» поставлена первой по совокупности: идеальное попадание в жанр + точная документация + official Topic. Независимое подтверждение помимо Грея: Discogs release 37384332 (HMV D.B.3426 «The Brook's Lullaby») — сторона A: Des Baches Wiegenlied D 795/20, B1: «Wiegenlied (Cradle Song) Op. 98 No. 2» (= D 498), B2: Der Schmetterling; матрицы 2EA.6021/6022 — состав пластинки и матрицы совпадают с Греем полностью. Видео: 43LrTqhfAkQ (Schumann Topic, 155 с = MB 154 с).
3. **Christa Ludwig / Geoffrey Parsons** — запись, вовсе не изданная в LP-эру. Верификация показала, что ни один известный альбом связки её не содержит: полные трек-листы SAX 5272 «A Schubert Recital» (Discogs 5430638, 12 треков) и SAX 5274 (Discogs 7538601 — там Брамс «Geistliches Wiegenlied» op. 91/2, не D 498) песни не включают; прежняя формулировка «окно 1961–1966 по двум LP» была экстраполяцией и снята. Доисследование восстановило происхождение: в Warner-боксе «The Complete Recitals» (2018) CD 4 — это SAX 5272 (треки 1–12, сессии 28–30.11.1961 + 20.02.1962, Abbey Road Studio 1) плюс пять треков «previously unpublished», среди них Wiegenlied D 498 (трек 4-14) — Discogs release 34671325, notes «CD 4: (1-12) [SAX 5272]; (13-17) previously unpublished». Два из пяти бонус-треков Грей документирует как unissued Columbia из сессий того же рецитала: Nacht und Träume — 29.11.1961 (id 55247), Im Abendrot — 20.02.1962 (id 55245); у всех 17 треков CD 4 общие продюсер и инженер (Suvi Raj Grubb / Robert Gooch — Discogs, MB). Итого фонограмма — неизданный остаток сессий рецитала SAX 5272; точный день Грей не индексирует → публикуется как **«1961–62?»**. Ей 33 — ядро пика (~1957–1975), тёмное ровное меццо; из тех же сессий — её 5-звёздная Gretchen. Самое протяжённое прочтение пула (216 с) — осознанно медленная, «убаюкивающая» колыбельная. Именной приоритет. Видео: SsYJY8arSBU (Ludwig Topic, 216 с = MB точно).
4. **Lotte Lehmann / Ernő Balogh** — Victor set M-419 / HMV DA 1603, сессия 16.03.1937, матрица BS 6665 take 1 (Грей, id 62832); пианист — по реестру и дайджесту (соседняя матрица 6664 той же сессии — её Gretchen с Балогом). Ей 49 — ещё внутри пика (сер. 1910-х — кон. 1930-х). Не именной приоритет, но безусловная звезда прошлого: эталон выразительной «рассказывающей» немецкой школы, первая женщина, записавшая Winterreise. Внутри группы уступает Шуман (менее прямое попадание тембра в жанр) и Людвиг (именной приоритет). Видео: IF0eNsc0czw (Lehmann Topic, 208 с).
5. **Arleen Augér / Lambert Orkis (хаммерклавир)** — Virgin Classics 5614572 (диск разделён с Thomas Allen), издание апрель 1991; год сессии не установлен → по правилу ставится год издания **1991**. Ей ~51 — излёт пика (1980-е–1991), голос цел; признанная шубертианка позднего периода (Hyperion т. 9, 1989). Единственный достойный кандидат «не ранее 1990»; бонус — периодный звук хаммерклавира, редкий для этой песни. Привязка фонограммы однозначна: MB-длительность версии с Оркисом 150,4 с = Topic-ролик 151 с (версий с Olbertz/Baldwin под D 498 в MB нет). Видео: zMEEMsQ71jw (Augér Topic).

## Ключевые решения и отклонённые кандидаты

- **Слот 2015+ остаётся пустым**: единственный кандидат — Anna Lucia Richter / Bushakevitz (видео ARTE, 208 тыс. просмотров), но без года записи, без идентифицированного издания, на неофициальном канале и без критической репутации — классический случай правила о скепсисе к пиару современных; качество — квалификационный фильтр, возрастная структура никогда не в ущерб ему. **Kirchschlager (When Night Falls, 1999)** — трек из концептуального сборника, не шубертовского проекта; сольного студийного Шуберта у певицы нет — отклонена.
- **Sarah Walker / Johnson (Hyperion т. 8)** — единственная запись песни с цитируемой критикой (Telegraph, CDReview — о диске; Джонсон в аннотации: D 498 — «пожалуй, самая знаменитая из всех вещей этого жанра, за какие Шуберт брался»), но запись сделана в мае 1989 — слот «не ранее 1990» она формально не закрывает, а в конкуренции старых слотов уступает звёздам прошлого (певица не звёздного ряда). Первый резерв научного профиля.
- **Irmgard Seefried / Nordberg (04.12.1947, Columbia LB 78)** — точнейшая документация (Грей, id 19926; уточнена ошибка реестра: Wiegenlied записан отдельной сессией 4.12, а не 21.11), 28 лет, светлый молодой голос — идеален для колыбельной, но пятёрка уже заполнена двумя именными приоритетами той же эпохи + Леманн; сильный резерв. Внимание: на её Topic минимум две разные фонограммы (≈177 с и ≈150 с — вероятно DG/Werba 1958); резервный ID — именно 1947 года (177 с).
- **Gundula Janowitz / Gage (1976–77, DG)** — единственный полностью документированный год LP-эры, серия дважды Deutscher Schallplattenpreis, самая просматриваемая версия песни на YouTube; уступила по качеству вокальной конкретики (фонетическая проработка традиционно слабее, чем у Людвиг/Бейкер) и по правилу приоритетов. Главный резерв.
- **Janet Baker / Moore (1970, HMV SLS 812)** — классический двойник-LP, но принадлежность именно этого трека альбому SLS 812 не доказана трек-листом (Грей по D 498 после 1965 слеп) — до подтверждения не публикуется.
- **Elly Ameling** — минимум три разные фонограммы D 498 (Baldwin ×2, Jansen), четыре Topic-загрузки, развести их по альбомам не удалось — включение нарушило бы сквозную унификацию года по альбому.
- **Rita Streich** (ориентир DG 1960) и **Elisabeth Rethberg** (год не установлен вовсе) — без документированного года; **Marian Anderson** — трек на Topic есть, но в 22 шубертовских позициях Грея и в MB-работе отсутствует, год недокументирован; **Ria Ginster** — вероятная путаница MB между D 498 и D 867. **Mathis (Novalis 1988)** и **Schreier/Ragossnig (гитара)** — живого видео нет. **Schwarzkopf live (Orfeo ℗ 2019)** — вторая версия той же певицы; правило велит студийную, лайв в резерв не нужен при трёх других.

## Соответствие возрастной структуре

3+ записи до 1990: 1937, 1937, «1948–52?», «1961–62?» ✓ (4 шт.); записи 1990+: одна (Augér, 1991) — второй достойной нет; запись 2015+: отсутствует — достойных кандидатов нет (см. выше). Отступление от желательного состава — осознанное, по правилу «никогда в ущерб качеству»: места незакрытых современных слотов заняли лучшие старые записи.
