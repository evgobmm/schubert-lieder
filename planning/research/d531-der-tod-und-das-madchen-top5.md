# Der Tod und das Mädchen (D 531) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Досье: planning/youtube/data/d531-der-tod-und-das-madchen.dossier.json (ярус famous; 25 кандидатов, 28 позиций по базе Майкла Грея). Даты — только по дискографиям (Gray/classical-discography.org, буклеты Hyperion, реестры альбомов проекта); метаданные загрузок датой не считались. Все 5 итоговых видео проверены yt-check.js (oEmbed 200, официальные Topic-каналы).

Особенность фонда: из восьми приоритетных певцов правил песню записывали только двое — Фишер-Дискау и Людвиг. Квастхоф, Шварцкопф, Хоттер, Андерс, Э. Шуман и Попп её не записывали (проверено по Грею, MusicBrainz и yt-dlp — см. priority_singers_checked досье). Сравнительной страницы klassik-prisma для D 531 нет (только для квартета D 810) — опорного рейтингового обзора у песни нет, ранжирование опирается на дискографическую репутацию записей и состояние голоса.

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — DG «Sämtliche Lieder», сессии 1966–1972, Ufa-Ton-Studio Berlin; год по сквозной конвенции проекта — 1969. Ему 44 — внутри пика ~1951–1972, вершина студийной работы с Муром до «сухого» тона середины 1970-х. Базовая референсная запись всего мужского корпуса Шуберта. №1 — по строгой иерархии: Квастхоф песню не записывал, Фишер-Дискау — высший из представленных приоритетов. Ранняя EMI/Electrola-версия того же дуэта («1965?» по метаданным загрузки) отклонена: год дискографически не подтверждён, происхождение не разведено — «при прочих равных более ранняя» неприменимо, когда равенство не установлено. Видео: 4HqvO74m3sQ (FD Topic, альбом «Schubert: Lieder (Vol. 1)» = DG-интеграл).
2. **Christa Ludwig / Geoffrey Parsons** — зап. 28.11.1961, Abbey Road Studio No. 1; Columbia SAX 5272 / Angel S 36462 (база Грея, точная сессия). Ей 33 — внутри пика ~1957–1975; та же серия сессий, что дала её пятизвёздную Gretchen (klassik-prisma) — в проекте корпус Ludwig/Parsons 1961–62 проходит как эталонный. Ремейк DG с Гейджем (сессии 21–24.06.1973, Вена) отклонён по правилу ранней версии: в D 118 ремейк с Гейджем последовательно оценивался ниже EMI-оригинала. Видео: HC7TURBMleA (Ludwig Topic; 168 с = версия Parsons по длительностям MB).
3. **Marian Anderson / Franz Rupp** — зап. 10.05.1946, New York, Victor Studio No. 2; Victor LM-98, матрица D5-RB 203 (Грей). Ей 49 — внутри пика 1930-х–40-х, контральто полное и ровное. По дайджесту фонда эта песня — её фирменный шубертовский номер (одна из считанных названных записей); огромный резонанс на YouTube. Контральтовая тесситура прямо отвечает реплике Смерти. Ранняя парижская версия с Веханеном (13.11.1936, HMV DA 1550) осталась резервом: голос свежее, но критического следа меньше, а Topic-загрузка (канал пианиста) не прошла проверку oEmbed в досье. Видео: FbH1w_c_rxo (Anderson Topic, прямо озаглавлено «Recorded 1946» — совпадает с Греем).
4. **Kathleen Ferrier / Bruno Walter** — живой рецитал Эдинбургского фестиваля, 1949 (Decca «Centenary Edition»; студийной D 531 у Ferrier по Грею нет — происхождение концертное). Ей 37, спада не было вовсе (умерла в 41). Один из самых чтимых документов Ferrier, уникальная связка: за роялем — дирижёр Бруно Вальтер; в проекте рецитал уже отобран в топ-5 D 828 («Die junge Nonne»). Порядок с Anderson: записи сходного легендарного уровня, обе — контральто в пике; по правилу «сходные → более ранняя» Anderson (1946) стоит выше Ferrier (1949). Видео: GXXsFdgtJY4 (Ferrier Topic, Centenary Edition).
5. **Brigitte Fassbaender / Graham Johnson** — зап. VI.1990, Hyperion Schubert Edition, т. 11 «Schubert & Death» (CDJ33011, изд. V.1991). Ей 51 — внутри пика ~1975–1992, через два года после её знаменитой Winterreise (1988). Сильнейший кандидат зоны «не ранее 1990»: научный эталон издания Джонсона, тематический том, в котором D 531 — смысловой центр (аннотация Джонсона: «дева тщетно сопротивляется домогательствам тирана»); Classic CD о томе: «19 tracks devoted to some of the greatest songs ever written». Видео: w1DKeFcbk-g (Fassbaender Topic; 160 с = MB 159 с).

## Ключевые решения и отклонённые кандидаты

- **Слот «не ранее 2015» оставлен незанятым — сознательно.** Единственный технически пригодный кандидат 2015+ — **Florian Boesch / Martineau** (Onyx «Lieder Recital», изд. 20.05.2016; год сессии не установлен): ни одной независимой критической оценки именно его D 531 не найдено, а правило скепсиса к прессе о современных требует документированного достоинства (прецедент Gretchen: Сэмпсон вошла с опорой на MusicWeb/Limelight). Второй сильный кандидат 2015+, **Alice Coote / Drake** (Hyperion CDA68169, зап. XII.2017; Gramophone «doesn't sugar-coat anything», BBC Music «white-hot sincerity»), дисквалифицирован технически: на диске и на YouTube песня разбита на два отдельных трека/ролика (56 и 114 с) — цельного исполнения одним ID нет. По правилу «если достойных современных нет — их места занимают лучшие старые записи» пятый слот отдан Ferrier/Anderson (в пятёрке обе); Boesch — резерв №1.
- **Kurt Moll / Garben** (Orfeo «Lieder für Baß», изд. 1982) — самый трудный отказ среди старых: «new standard» для басового Шуберта (Wikipedia через реестр), чёрный бас идеально ложится на реплику Смерти. Уступил четырём позициям выше по совокупной репутации (интеграл DG, эталонный корпус Ludwig/Parsons, два легендарных контральто) и Фассбендер — по квоте 1990+. Первый резерв старой зоны; внимание: вторая Topic-загрузка Молля (LEJsUXphiuY) — оркестровая аранжировка Мотля, не годится.
- **Jessye Norman / Moll** (Philips, зап. IV.1984) — пик голоса, но манера крупная, оперная — для миниатюры Клаудиуса спорная; отдельных оценок D 531 нет. Живая версия с Parsons (Шубертиада 1987) дублирует певицу и уступает студийной.
- **Janet Baker / Parsons** (EMI, год сессии НЕ установлен; гипотеза 1979–80 по LP 1981) — классик жанра, но запись без установленной даты и без критического следа именно по D 531; резерв с year «1980?» при необходимости.
- **Terfel / Martineau** (DG «An die Musik», зап. II.1994) — бестселлер, драматические миниатюры ему удаются (klassik-prisma 4–5 за Erlkönig с диска), но зона 1990+ уже закрыта более сильной Фассбендер; второй современный слот без кандидата 2015+ не заполнялся в ущерб старым. Резерв.
- **Goerne / Deutsch** (HM, зап. 2011), **Stutzmann / Södergren** (Calliope, 2005), **Gerhaher / Huber** (Arte Nova, 2001?), **Bostridge / Andsnes** (EMI, 2002–05?), **Fleming / Eschenbach** (Decca, 1996) — достойный современный пул, но никто не предъявил критического превосходства над Фассбендер в своей зоне; у Bostridge и Gerhaher годы сессий не установлены, у Fleming Lieder вторичны (дайджест).
- **Lehmann (Odéon 1927, орк. Гурлитта)** и **Chaliapin (HMV 1928, орк. Гуссенса)** — исторически ценные, но с оркестром, а не фортепиано: стилистический отход от оригинала при живой фортепианной конкуренции того же уровня.
- **Ludwig/Gage 1973, Anderson/Vehanen 1936, FD «1965?»** — вторые версии певцов пятёрки, см. пункты 1–3.
- **Greindl/Klust (1957), Gerhardt (1923), Schumann-Heink (1923), Culp (1926), Holzmair (Naxos 2005), de los Ángeles (год не установлен)** — либо нет отдельной официальной YouTube-загрузки, либо только фан-перенос 78-х; в топ-5 войти не могут.

## Соответствие возрастной структуре

4 записи ранее 1990 (1969, 1961, 1946, 1949) — «как минимум 3 очень хорошие» перекрыто ✓; 1 запись 1990+ (Fassbaender, VI.1990) ✓; запись 2015+ отсутствует — допустимое отступление: единственный пригодный кандидат (Boesch) не имеет документированного качества, а достойная Coote технически неиграбельна; квота никогда не заполняется в ущерб качеству ✗→обосновано. Возрастная структура влияла только на состав (Фассбендер вместо пятой старой записи), не на порядок.
