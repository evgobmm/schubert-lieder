# Wohin? (D 795/2) — отбор топ-5 исполнений

Дата: 2026-09-06. Ярус: famous, цикльный метод + пер-песенная перепроверка приоритетных исполнителей (правило «Масштабирование», п. 2 и п. 3.4 приоритетных певцов) — «Wohin?» имеет самостоятельную концертную жизнь внутри Die schöne Müllerin, поэтому проверена отдельно от цикльной пятёрки. Источник отбора: `planning/research/cycle-muellerin-top5.md` (раздел «Топ-5 для D 795/2», по цикльному досье `planning/youtube/data/cycle-muellerin.dossier.json`); пятёрка уже опубликована в `app/src/data/performances.json` («795/2») — этот файл документирует и перепроверяет её задним числом.

Проверка для настоящего файла: даты и издания — Discogs API (`api.discogs.com`, без ключа); живость и точное соответствие видео песне — YouTube oEmbed по всем пяти videoId из `performances.json` (все пять — код 200, канал совпадает с исполнителем, заголовок дословно называет «Wohin?»/«No. 2»). Пятёрка **подтверждена без изменений** — заменять нечего.

## Итоговый топ-5

1. **Thomas Quasthoff / Justus Zeyen** — зап. июль 2005, Teldex Studio, Берлин; Deutsche Grammophon 00289 474 2182. Discogs: «Recording: Berlin, Teldex Studio, 7/2005» (https://www.discogs.com/release/4640997). Ему 46 — внутри вокального пика (~1993–2007), последний из шести шубертовских альбомов певца перед уходом из классики в январе 2012. Приоритет №1 правил — при достойной записи всегда открывает пятёрку. На том же Topic-канале рядом лежит параллельный лайв-комплект Вербье-2023 с Эмануэлем Аксом с пометкой «(Live)» — в отборе он не участвует, взят только альбомный трек. Видео: nMN9Bw8Tnus (Thomas Quasthoff - Topic, oEmbed 200, заголовок «…No. 2, Wohin?»).
2. **Dietrich Fischer-Dieskau / Gerald Moore** — зап. 2–4.12.1961, Evangelisches Gemeindehaus, Berlin-Zehlendorf; Electrola/EMI STE 91187/8, ныне каталог Warner. Discogs (переизд. EMI «Great Recordings of the Century»): «Recorded 2-4.XII.1961, Gemeindehaus, Berlin-Zehlendorf» (https://www.discogs.com/release/3325573). Ему 36 — середина пика (~1951–1972), стерео; самая тиражируемая EMI-версия цикла. По правилу «при прочих равных — более ранняя» первой должна была бы идти сессия 3.10.1951 (HMV DB 21388) — она вокально самая свежая (26 лет), но официальной потрековой загрузки нет: на YouTube только «серые» агрегаторы (Heritage/The Orchard, MVE, Believe SAS, BNF и др.), чьи кредиты правилами запрещены как источник. Гейт не пройден → слот занимает следующая по рангу версия того же певца, 1961 года. Видео: 7q1CDLZ7SYE (Dietrich Fischer-Dieskau - Topic, Warner, oEmbed 200).
3. **Gerhard Hüsch / Hanns Udo Müller** — зап. 1935, Abbey Road, студия №3 (сессии Das Wandern — 31.01, Am Feierabend — 31.01, Trockne Blumen — 02.02, Der Müller und der Bach — 22.03, по дискографии Майкла Грея); HMV DB 2429–2436. Discogs (переизд. Angel/Toshiba «Great Recordings of the Century»): «Recorded in 1935» (https://www.discogs.com/release/11098709). Ему 34 — пик; тот же дуэт, что записал эталонную Winterreise 1933. Исторический эталон цикла (klassik-prisma — 5 баллов, первая строка мужской таблицы в фонде проекта); статус канона подтверждён включением в серию «Great Recordings of the Century». Сильнейшая запись группы «звёзды прошлого» → №3. Видео: s06zo8Zswac (Gerhard Hüsch - Topic, ℗ 2000 hänssler/Naxos-ряд, oEmbed 200).
4. **Fritz Wunderlich / Hubert Giesen** — зап. июль 1966, Мюнхен, Plenarsaal der Akademie der Wissenschaften; Deutsche Grammophon 139 220. Discogs (переизд. «The Originals»): «Recordings: Munich, Residenz, Plenarsaal der Akadamie der Wissenschaften, 7/1966» (https://www.discogs.com/release/6628286). Ему 36 — только пик; погиб 17.09.1966, это последние студийные сессии певца. Эталон тенорового цикла, одна из самых почитаемых записей Lieder вообще. Второе место старой группы по качеству → №4. Видео: SK3qfa_f9uE (Fritz Wunderlich - Topic, DG-ряд, oEmbed 200) — на канале рядом лежат чужие комплекты (Sony/BMG-ряд, SWR-радио, сборник «Fritz Wunderlich sings»), при подборе взят только альбомный DG-ряд 1966 года.
5. **Samuel Hasselhorn / Ammiel Bushakevitz** — зап. 2023; harmonia mundi HMM 902720, т. 1 серии «Schubert 200» (Discogs 36696394, изд. 22.09.2023). Ему 33 — ранний пик. Альбом вошёл в подборку месяца лейбла «Diapason d'or»: в сборнике «Les Plus Beaux CD Du Mois — Octobre 2023» трек №2 — Schubert, «Die Schone Mullerin (Tranenregen)», Samuel Hasselhorn (Baritone Vocals) / Ammiel Bushakevitz (Piano) (https://www.discogs.com/release/30700150) — премия объективна (отбор лейбла Diapason, не пресс-релиз артиста), фильтр скепсиса к пиару пройден. Лучший кандидат слота «не ранее 2015» → №5. Видео: 5XE7Jq3Na1I (Samuel Hasselhorn - Topic, harmonia mundi, oEmbed 200).

## Ключевые решения и отклонённые кандидаты

- **Fischer-Dieskau / Moore, 1951 (HMV DB 21388, Грей id 69628)** — вокально самая свежая версия певца (26 лет), но на YouTube нет ни одной официальной потрековой загрузки: только агрегаторы Heritage/The Orchard, MVE, Believe SAS, BNF Collection, «Diapason»-компиляция, MusiKazoo, Golden Legacy — их атрибуция сессии не подтверждена и правилами запрещена как источник дат/состава. Отклонена по гейту доступности, не по качеству; при обнаружении официальной загрузки — кандидат на пересмотр слота №2.
- **Elisabeth Schwarzkopf** — «Wohin?» не записывала: в перечне из 51 позиции дискографии Грея песни нет; на официальном Topic-канале певицы из цикла присутствует только «Ungeduld». Отрицательный результат, женский приоритет правил на эту песню не закрывается.
- **Hans Hotter / Michael Raucheisen** — запись существует (Columbia, 1952, матрица 972), но помечена в дискографии Грея «unissued» (id 19917, не издана) — фонограммы в обороте нет, публиковать нечего.
- **Elisabeth Schumann / Karl Alwin, 1927** — историческая ценность, но уступает Хюшу-1935 по значительности и репутации в фонде именно этой песни; официальный Topic-трек жив (aEFGvQwv-Ro). Первый резерв старой группы.
- **Peter Anders / Michael Raucheisen (Mende), «1950–54?»** — приоритетный тенор правил, но год дискографически не закреплён, а качество уступает трём отобранным старым записям. Второй резерв.
- **Heinrich Schlusnus / Sebastian Peschko, 1939** и **Aksel Schiøtz / Gerald Moore, 1945** — сильные исторические версии, но третий слот «до 1990» в пятёрке уже закрыт Вундерлихом по правилу состава (у Хюша и Вундерлиха качество и значительность выше). Резервы.
- **Christa Ludwig, Lucia Popp** — «Wohin?» не найдено ни в дискографии Грея, ни на официальных Topic-каналах, ни через yt-dlp по цикльным изданиям. Отрицательный результат.
- **Ian Bostridge, Christian Gerhaher, Matthias Goerne, Barbara Hendricks, Brigitte Fassbaender, Benjamin Appl** — современные версии из общей выдачи по названию песни; ни одна не подтверждена как заслуживающая вытеснить Хассельхорна из единственного слота «2015+» или добавить второй современный слот сверх состава пятёрки (правило состава — «желательно», не «обязательно» сверх пяти мест).

## Соответствие возрастной структуре

3 записи ранее 1990 (1935, 1961, 1966) ✓; 2 записи 1990+ (2005, 2023) ✓; из них 1 запись 2015+ (2023) ✓. Порядок — строгая иерархия приоритетов: Квасхоф (№1) → Фишер-Дискау (№2 при отсутствии живого Квасхофа-конкурента) → звёзды прошлого по качеству (Хюш → Вундерлих) → современный (Хассельхорн).
