# Grenzen der Menschheit (D 716) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Досье кандидатов: planning/youtube/data/d716-grenzen-der-menschheit.dossier.json (17 кандидатов, все обязательные пункты данных). Все 5 итоговых видео проверены yt-check (oEmbed): живы, встраиваемы, официальные Topic-каналы.

Особенность фонда: гимн Гёте от лица человека перед богами — песня для низкого мужского голоса; женских записей в найденном фонде нет вовсе (12 карточек MusicBrainz и все живые загрузки — баритоны и басы). Из приоритетного списка правил песню записали только Квастхоф, Фишер-Дискау и Хоттер; Шварцкопф, Андерс, Э. Шуман, Людвиг, Попп — проверенные отрицательные результаты (репертуарно чужая песня).

## Итоговый топ-5

1. **Thomas Quasthoff / Charles Spencer** — сессии 25–26 и 28–29 мая 1993, Historischer Reitstadel, Ноймаркт; RCA Victor Red Seal 09026 618642 «Schubert: Goethe-Lieder» (изд. 1995). Квастхофу 33–34 — самое начало пика (~1993–2007), голос свежий, крупного бас-баритонового формата — по тесситуре и весу песня «его». Первый из шести шубертовских альбомов певца, опорное издание гётевских песен в реестре проекта; известное замечание klassik-prisma о шершавом нижнем регистре относится к Erlkönig того же диска и оценки альбома в целом не отменяет. Высший приоритет правил; оснований для исключения по качеству исследование не дало. Видео: VBbpZjeBYh4 (Thomas Quasthoff - Topic).
2. **Dietrich Fischer-Dieskau / Gerald Moore** — свод DG «Sämtliche Lieder», сессии Ufa-Ton-Studio, Берлин, декабрь 1966 – март 1969 (гётевский блок), ℗ 1969. ФД 43–44 — середина пика (~1951–1972): полный, гибкий баритон, декламация на высоте — идеально для гимнической декламации Гёте. Каноническая версия песни (в MusicBrainz по work единственный дуэт с двумя карточками — остальные единичные); свод DG — общепризнанный эталон мужского шубертовского репертуара. Из четырёх официальных Topic-контейнеров выбран альбомный «Schubert: Goethe Lieder» (486 с). Видео: OcaLa2yvgwU (Dietrich Fischer-Dieskau - Topic).
3. **Kurt Moll / Cord Garben** — Orfeo S 021821 A «Schubert: Lieder für Bass», изд. 1982 (год сессии не документирован; в плеере год издания по правилу). Моллу ≈43–44 — зрелый пик знаменитого «чёрного» баса с полноценным низом, который эта песня требует буквально. Редчайший специализированный басовый шубертовский рецитал (Prometheus, Gruppe aus dem Tartarus, Fahrt zum Hades…), по зафиксированной в реестре оценке «set a new standard for these songs» — сильнейший басовый кандидат фонда. В группе «прочие звёзды прошлого» поставлен выше Хоттера по качеству: студийная запись на вокальном пике против концертной записи певца за пиком. Видео: zD23R5S0aDA (Kurt Moll - Topic).
4. **Hans Hotter / Walter Martin** — концерт NDR 18 февраля 1961, Beethovensaal der Stadthalle Hannover; изд. Orfeo d'Or C 507 991 B «Lieder Abend» (1999), песня открывает программу. Хоттеру 51 — за пиком (~1942–1955), голос тяжелее и менее гибок, но в медленной, низко лежащей гимнической декламации D 716 эта тяжесть скорее актив; исторически ценный документ поздней большой эпохи легендарного бас-баритона, чей типаж (тёмный «философский» Гёте) — сердцевина именно этого репертуара. Пианист — Walter Martin по буклету Orfeo (фан-загрузка, приписывающая Мура, отвергнута как враньё метаданных). Видео: 3aOLUjh-oqs (Hans Hotter - Topic).
5. **Matthias Goerne / Elisabeth Leonskaja** — harmonia mundi HMC 901988 «Sehnsucht» (Matthias Goerne Schubert Edition, т. 1), релиз 14.03.2008 (год сессии не установлен; в плеере год издания). Гёрне ≈40 — середина пика (~1997–2015): тёмный «замшевый» баритон, крупная медленная фразировка (455 с) песне органична; объективный плюс — Леонская, пианистка первого ряда, редкая в песенном репертуаре. Сильнейший современный кандидат; титул «первый Schubert-баритон поколения» учтён с поправкой на пиар, но выбор подтверждается сравнением с альтернативами (см. Бёш ниже). Видео: SB7ida5mmrI (Elisabeth Leonskaja - Topic).

## Ключевые решения и отклонённые кандидаты

- **Florian Boesch / Martineau (Onyx, 2014)** — главный конкурент Гёрне на современный слот: пик формы, признанный рассказчик. Против: самый быстрый темп фонда (396 с против 455–491 с у лидеров) — риск потери гимнической весомости, отмеченный в досье; репутация трилогии Onyx во многом держится на пианисте. Первый резерв.
- **Gottlob Frick (SWR Archive / загрузка Общества Фрика)** — идеальный голосовой типаж «чернейшего баса», но год записи НЕ установлен (атрибуция «1949, Martin Görgen» — из описания загрузки, по правилам не источник; загрузки 551/572/536 с — минимум две разные записи). По правилу о неустановленном годе требуется целевое доисследование даты до публикации; в пятёрку не включён, отмечен как кандидат на переоценку.
- **Neal Davies / Graham Johnson (Hyperion т. 34, сессии I.1999)** — научный эталон издания, точнейшая документация, но вокально не первый ряд; ценность прежде всего аккомпаниаторская и текстологическая. Резерв.
- **Franz-Josef Selig / Huber (CAvi)** и **Robert Holl / Lutz** — концептуально релевантные басовые программы, но год записи не установлен (Discogs троттлил) и критических оценок нет; публикация возможна только после доисследования.
- **Кандидаты «не ранее 2015»**: Shenyang / Zeger (Delos, 2018) — немецкая песня не главная линия певца, критического резонанса нет (по правилу скепсиса к современным — только при явном качестве, которого источники не подтверждают); Zeppenfeld / Springer (Вена, 20.11.2022) — значимый лайв, но неофициальная фан-загрузка без издания. Достойного кандидата 2015+ нет — слот по правилу занимает лучшая старая запись.
- **Kränzle / Dumno (Challenge, 2013)**, **Bästlein / Laux (Naxos DSLE, 1999)**, **Hauptmann**, **Alsen**, **Lemalu** — второй ряд по качеству/данным. Lorenz/Shetler и Félix/Badura-Skoda на YouTube отсутствуют.
- **Ловушка одноимённых сочинений**: под этим названием на YouTube висят песни Вольфа (Kipnis Gk7B4ckk1Jg; ФД dk_m0hGPaLI) и ещё одна чужая композиция 1902 г. (hTLRuwRmpYs, ФД/Reimann) — все НЕ D 716, отсеяны. Загрузка ФД 5wDBRh5G2Ko (433 с) расходится со сводом DG — не публикуется до выяснения.

## Соответствие правилам состава

3 записи ранее 1990 (1969, 1982, 1961) ✓; 2 записи 1990+ (1993, 2008) ✓; запись 2015+ отсутствует — допустимое отступление: оба кандидата 2015+ не прошли квалификацию по качеству/официальности (см. выше), их место занимает лучшая старая запись. Порядок — строгая иерархия приоритетов: Квастхоф № 1, Фишер-Дискау № 2, далее звёзды прошлого по качеству (Молл > Хоттер), затем современный Гёрне.
