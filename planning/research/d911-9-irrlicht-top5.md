# Irrlicht (D 911/9, Winterreise) — проверка топ-5 исполнений

Дата: 2026-09-09. Правила: `docs/rules/youtube-performances.md`. Задача: не отбор с нуля, а **проверка** пятёрки,
уже опубликованной в `app/src/data/performances.json` (поле `"911/9"`) — она входит в общий, единый для всех 24
песен цикла набор из пяти полных записей Winterreise (Quasthoff, Mattei, Fischer-Dieskau, Anders, Hotter),
перенесённый из `winterreise-reference` (правило «Winterreise — перенос готового отбора из референса скриптом,
не пересмотр»). Файла-исследования под этим набором раньше не было ни для одной песни цикла; это первый.
Каждая запись проверена отдельно: кто поёт/играет, точный год, издание, происхождение видео. Бюджет обращений к
сети превышен (15 вместо ≤12 — часть попыток упёрлась в бот-защиту Discogs/MusicBrainz/norpete.com и не дала
данных; см. «Проблемы с источниками» ниже).

## Проверка по правилу: содержательных проблем не найдено

Все пять записей — реальные полные исполнения Winterreise указанных исполнителей и пианистов, с документированным
происхождением; ни одна не оказалась «не той песней» или подставным исполнителем. Замены не требуются
(**replaced = 0**). Ниже — два несодержательных расхождения с буквой правил, которые стоит знать, но которые не
относятся к качеству самих записей.

### Проблема: порядок пятёрки не строго соответствует иерархии приоритетов

Правило «Порядок записей в топ-5 — строгая иерархия приоритетов» требует: Квасхоф → Фишер-Дискау → (Шварцкопф —
неприменимо, мужская песня) → прочие звёзды прошлого → современные. Фактический порядок в
`performances.json`: Quasthoff → **Mattei** → Fischer-Dieskau → Anders → Hotter — современный Мэттеи стоит перед
приоритетным Фишер-Дискау. Это, вероятно, объясняется тем, что пятёрка перенесена из `winterreise-reference`
единым пакетом на весь цикл (правило прямо выводит Winterreise из-под пересмотра пайплайна), а не ранжирована
по-песенно. Изменение порядка потребовало бы правки `performances.json`, что запрещено этим заданием — фиксирую
находку, решение (переставить/оставить как унаследованный порядок референса) — за пользователем/потоком.

### Открытый вопрос: год записи Quasthoff/Spencer

В `performances.json` год — 1997 (предположительно год сессии); во всех проверенных открытых источниках (Discogs,
Apple Music, eBay, MusicBrainz — часть недоступна из контейнера из-за бот-защиты) фигурирует только год издания
1998, дата самой сессии независимо не подтвердилась. Год не противоречит биографии (Квасхофу в 1997–98 — 37–38
лет, пик), поэтому это не повод для замены — просто пометка «сессия 1997 не переверифицирована» для будущего
целевого доисследования.

### Соответствие правилам состава — не полностью выполнено

Правило желает: 2 записи ≥1990 (из них 1 ≥2015) при сохранении ≥3 очень хороших записей до 1990. Фактически:
Anders 1945, Hotter 1942, Fischer-Dieskau 1962 — три записи до 1990 ✓; но ≥1990 в пятёрке только **одна** —
Mattei 2018 (она же закрывает и слот ≥2015). Второй записи 1990–2014 нет — вероятно, потому что весь набор общий
для 24 песен цикла, а не подобран по стандартному пер-песенному конвейеру. Не блокирует использование текущей
пятёрки (правило подчёркивает «только при наличии достойных кандидатов», а замена вне полномочий этого задания),
но фиксирую как отклонение от целевой структуры состава.
