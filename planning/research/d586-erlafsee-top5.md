# Erlafsee (D 586) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Ярус песни: medium (досье: planning/youtube/data/d586-erlafsee.dossier.json). Фонд — не «звёздный» рецитальный, а полные своды (DG Фишер-Дискау, Hyperion, Naxos DSLE), мейрхоферовские программы и «водные» концепт-альбомы. Историческая особенность песни: первая напечатанная песня Шуберта (альманах на 1818 г.; эссе Грэма Джонсона к Hyperion CDJ33021). Все итоговые видео проверены через oEmbed (живы, встраиваемы).

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Karl Engel** — зап. не позже декабря 1959 (Electrola E 91 024 / WALP 552, «VI. Folge: Gedichte von Johann Mayrhofer»; Discogs 32319945, промо-штамп «22.Dez.1959»; UK: HMV ALP 1850, 1961). Ему 34 — абсолютный вокальный пик (дайджест: ~1951–1972). Единственный приоритетный певец из правил, записавший песню вообще; целиком мейрхоферовская программа — Erlafsee в контексте «водных» песен (Am Strome, Auf der Donau, Wie Ulfru fischt). Каталог держит запись в обороте 65+ лет (EMI 5 65670 2, 1995; бокс Warner 2025). Из двух его версий правила выбирают раннюю: голос на 10 лет свежее, чем в DG-своде. Оговорка по носителю: YouTube-загрузка — Topic-канал певца, но через агрегатор Believe/«BNF Collection»; его выходные данные (℗1961) не источник года. Видео: ccN0F1CDrek (Stereo Version).
2. **Elly Ameling / Irwin Gage** — зап. 7–13.10.1971, Берлин (дискография Грея; HMV HQS 1261 / Electrola «Folge II»; кредит Erlafsee → Gage подтверждён Warner). Ей 38 — пик (дайджест: ~1965–1985, «самая записываемая шубертианка поколения»); светлое, ровное лирическое сопрано без следов износа. Сильнейшая женская студийная версия фонда; альбом десятилетиями в переизданиях (Warner «Icon»). Из двух её версий ранняя (1971) предпочтена концертной Tanglewood-1987 — техника безупречнее, правило «при прочих равных — более ранняя». Видео: 1OgSXt05YoM (Warner, «Icon: Elly Ameling»).
3. **Robert Holl / David Lutz** — зап. июль 1986, Casino Baumgarten, Вена (описание официального канала певца с разрешения Preiser; Preiser SPR 3373 «Ausgewählte Lieder»). Ему 39 — пик (дайджест: ~1980–2005). Патриарх Шубертиады Хоэнемс, специалист по редким песням; «гранитная» широкая манера — 5'03", самый медленный из «клавирных» кандидатов (у Ф.-Д. ~4'04"). Лучший низкий голос фонда после Фишера-Дискау; редкий случай точно документированной сессии прямо от правообладателя. Видео: b7IaukcA5ME (официальный канал певца, лицензия Preiser).
4. **Edith Mathis / Graham Johnson** — зап. октябрь 1992, Rosslyn Hill Unitarian Chapel, Лондон (Hyperion Schubert Edition, т. 21 «Schubert in 1817 & 1818», CDJ33021, изд. 1994). Ей 54 — поздний пик (дайджест: 1970-е–1980-е); голос лёгкий, стилистически безупречный. «Документальный» эталон: том целиком о песнях 1817–18, эссе Джонсона — главный аналитический источник по песне (именно там Erlafsee названа первой напечатанной песней Шуберта). Предпочтена Хольцмайру-1992 в слоте 1990+: певица крупнее по статусу (карточка дайджеста), связка с научным изданием ценнее для страницы песни. Видео: hThx_apPAio (Hyperion/UMG official audio).
5. **Georg Nigl / Olga Pashchenko (хаммерклавир)** — релиз 13.11.2020, Alpha Classics «Vanitas» (Schubert–Beethoven–Rihm; Erlafsee — бонус-трек; дата сессии не документирована → год издания). Густо-декламационная манера, самая протяжная версия фонда (5'04"); историческое фортепиано даёт «другую оптику». Единственный кандидат «не ранее 2015» с официальным носителем — занимает современный слот структуры; сравнительной критики по треку нет (учтён скепсис к пиару: альбом взят не по прессе, а как единственный достойный представитель поколения — Нигль в резерве дайджеста, Alpha — серьёзный лейбл). Видео: AJVvDYTb7bc (Alpha/Outhere).

## Ключевые решения и отклонённые кандидаты

- **Fischer-Dieskau / Moore (DG «Sämtliche Lieder», ℗1969)** — дубль певца; по правилу «при прочих равных — более ранняя» уступил версии 1959/Engel (голос свежее, редкая цельная мейрхоферовская программа). Единственное преимущество DG — официальный носитель UMG; это делает его первым резервом на случай смерти BNF-загрузки.
- **Ameling / Jansen (Tanglewood, 2.07.1987)** — дубль певицы; живой рецитал конца пика, техника уже не так безупречна, как в 1971.
- **Holzmair / Wyss (Tudor 764, 1992)** — целиком мейрхоферовская программа, начало пика; уступил Матис слот 1990+ (статус и научная ценность издания Hyperion). Сильный резерв.
- **Raskin / Schick (Epic, 1967)** — добротный американский рецитал 1960-х (переиздан Sony), но без критического следа и карточки в дайджесте; уступила Холлу третий «старый» слот.
- **Elsner / Höll (Capriccio, ℗1997), Ainsley / Lubin (Decca, 1993), Iven / Kehring (Naxos DSLE, 2003), Neven / Eijsackers (Onyx «The Sea», 2012)** — ровный «второй ряд» 1990–2010-х без критической репутации; ни один не вытесняет выбранных.
- **Schweppe / Fukuda (2021)** — маргинал: лейбл и репутация не установлены.
- **Gruberová (Orfeo live 1980), Glaz (Entré, 1950-е)** — наличие песни потреково не подтверждено, YouTube-загрузок нет; по досье в топ не брать.
- **Приоритетные певцы**: из восьми по правилам песню записал только Фишер-Дискау (дважды). Квастхоф (дискография закрыта, мейрхоферовских песен нет), Шварцкопф, Хоттер, Андерс, Э. Шуман, Людвиг, Попп — записей нет (проверено по MusicBrainz и полной Discogs-выдаче «Erlafsee», 63 релиза).
