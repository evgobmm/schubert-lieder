# Ständchen «Horch, horch, die Lerch'» (D 889) — отбор топ-5 исполнений

Дата: 2026-08-17. Правила: docs/rules/youtube-performances.md. Ярус famous, полный конвейер. Досье кандидатов: planning/youtube/data/d889-standchen.dossier.json (даты — по дискографии Майкла Грея, каталогам Hyperion/Naxos, Discogs API и ℗-строкам официальных загрузок; метаданные фан-загрузок и archive.org источником дат не служили). Все итоговые и резервные videoId проверены yt-check.js (oEmbed 200, официальные Topic-каналы).

Особенность фонда: generic-выдача YouTube и часть привязок MusicBrainz по слову «Ständchen» массово относятся к D 957/4 (Рельштаб) и D 920 — каждый кандидат в досье верифицирован по явному указанию D 889. Сравнительной страницы klassik-prisma по D 889 нет; единственный найденный «кураторский» сигнал канона — антология EMI «Schubert — Lieder on Record 1898–2012», где D 889 представлена Вундерлихом (Discogs 23802614).

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — EMI/Electrola, ℗1965 (сессия дискографиями не установлена; Warner-переиздание, прод. Christfried Bickenbach). Ему 40 — середина пика (~1951–1972). Из двух его студийных версий с Муром выбрана ранняя EMI: голос полнее, трактовка развёрнутая — все три строфы (3:57) против одной строфы с повтором в стремительной DG-версии ℗1969 (1:38); правило «при прочих равных — более ранняя» действует в ту же сторону. Приоритет №2 по правилам (Квастхоф песню не записывал — его дискография закрыта в 2012 без D 889; проверено по Discogs/MusicBrainz и дайджесту). Видео: LH605UI_8G4 (Fischer-Dieskau Topic, ремастер 1990).
2. **Elisabeth Schumann / Gerald Moore** — зап. 7.09.1936, EMI Studio No. 3, Abbey Road; HMV DA1526 (Gray id 62858; переизд. Naxos Historical 8.110731, трек 10). Ей 48 — конец пика, голос ещё светлый и ровный. Именной приоритет; канонический голос для «светлых» песен Шуберта — прямое попадание в утреннюю серенаду жаворонка. Внимание: цифровые кредиты Topic ошибочно называют пианистом George Reeves — каталог Naxos на сам альбом и MusicBrainz дают Gerald Moore. Имя в плеере — «Schumann — Moore» без инициала: во всём корпусе performances.json Элизабет Шуман записана просто «Schumann» (Moore/Coleman/Reeves/Alwin/Rosenek), а инициал по правилу нужен лишь при конфликте фамилий среди певцов — единственный «N. Schumann» в корпусе это пианист (запись Breedt), конфликта нет. Видео: YJs7uAt9-vY (Elisabeth Schumann — Topic, Naxos).
3. **Peter Anders / Michael Raucheisen** — зап. май 1944, Eterna 520221 (Gray id 211228; позиция Грея «1959, Eterna 720069» — переиздание: Андерс погиб в 1954; переизд. MYTO ℗1997). Ему 36 — пик (спада у Андерса не было). Именной приоритет; берлинский корпус Андерс/Раухайзен 1940-х — признанный документ немецкой Lied-школы военных лет (переиздания DG/Tahra/Myto). Внутри группы старых мастеров поставлен после Шуман: уровень сходный, её запись раньше и репертуарно точнее. Видео: aABu3j3ppxw (Anders Topic).
4. **Christine Schäfer / Graham Johnson** — зап. февраль 1996, Rosslyn Hill Chapel, Лондон; Hyperion Schubert Edition т. 26 «An 1826 Schubertiad» (CDJ33026, прод. Brown/Compton). Ей 30–31 — ранний пик, светлое точное сопрано. Единственный кандидат фонда с редакционным текстом, прямо выделяющим её D 889 (аннотация Грэма Джонсона: «Christine Schäfer 'Hark, hark, the lark'»); программа тома — реконструкция шубертиады 1826 года, года сочинения песни; издание в целом — «This is an archive of glorious Lieder singing…» (The Guardian, цит. Hyperion). Сильнейший документированный кандидат слота 1990-х. Видео: GOiZhcnHWR4 (Graham Johnson Topic; певица указана в кредитах трека).
5. **Carolyn Sampson / Joseph Middleton** — «Sounds and Sweet Airs — A Shakespeare Songbook», BIS, ℗2023 (прод. Robert Suff; год сессии буклетом не документирован — в плеере год релиза). Ей ~48 — зрелый пик. Один из самых уважаемых современных песенных дуэтов (в реестре проекта уже несколько их альбомов, дуэт подтверждён и в топ-5 Gretchen); шекспировская программа альбома — прямой контекст для песни из «Цимбелина». Сильнейший кандидат слота 2015+. Видео: Sl9Zr1E2ca0 (Sampson Topic, BIS).

## Ключевые решения и отклонённые кандидаты

- **Fritz Wunderlich / Reinhardt (2.11.1962, Electrola; Gray id 251581)** — самый трудный отказ: единственный «кураторский» сигнал канона (выбор антологии EMI «Lieder on Record») и пиковый Вундерлих. Но антология составлялась из каталога EMI, где Eterna-записи Андерса быть не могло, — сигнал не является сравнительным по всему фонду; при сходном уровне двух пиковых теноров место в тройке до-1990 отдано именным приоритетам (Шуман, Андерс) при обязательном Фишере-Дискау. **Первый резерв**; при переоценке кластер Topic-загрузок ~252–257 с не брать (не верифицирован) — только кластер ~234 с (sVHQeSSMDZk).
- **Arleen Augér / Orkis, хаммерклавир (Virgin ℗1991)** — очень ценимая лидер-сопрано, редкий периодный баланс; уступила слот 1990-х Шефер (у той — единственный трек-специфичный редакционный сигнал по D 889 и программный контекст 1826). Резерв.
- **Barbara Bonney / Parsons (апр. 1994, Teldec; Discogs 16032161)** — сильный современный диск (уже в топ-5 Gretchen), но по этой песне трек-специфичных оценок нет; в слоте 1990-х уступила Шефер по тем же основаниям, Augér — по общему весу репутации. Резерв не ставлю: слот закрыт двумя более сильными кандидатами.
- **Samuel Hasselhorn / Bushakevitz («Schubert: Hoffnung», harmonia mundi, релиз 17.04.2026)** — серия «Schubert 200» с премиями за прошлые тома, но по правилу скепсиса к современникам свежий релиз без критического следа именно этой записи не вытесняет устоявшийся дуэт Sampson/Middleton из слота 2015+. Резерв.
- **Fischer-Dieskau / Moore, DG «Sämtliche Lieder» ℗1969 (lwWYOBHmcAQ)** — вторая версия того же певца в пятёрку не берётся; EMI-версия раньше, полнее и в лучшем вокальном состоянии.
- **Gerhard Hüsch / H. U. Müller (апр. 1939, Electrola; Gray id 54374)** — эталонный дуэт 1930-х, достойная запись; не хватило мест в тройке до-1990 при трёх приоритетных именах выше. Кандидат на переоценку наравне с Вундерлихом.
- **Richard Tauber (28.09.1934, Parlophone)** — эталон венского тенорового лиризма, но край пика и звук 78-й; уступает Андерсу и Вундерлиху.
- **Hermann Prey** — обе версии вне пятёрки: 1952 (Columbia, Раухайзен) — 23 года, документальная ценность; 1974 (DG, Hokanson) — пиковая, но без трек-специфичной репутации и позади конкурентов группы.
- **Kathleen Battle / Levine (DG ℗1988)** — красивый тембр, но устойчивые упрёки критики в декоративности и слабом немецком слове; 4:43 — самая медленная версия пула (риск затянутости).
- **Kasarova (1999), Boog (Naxos DSLE, 2003), Bostridge/Andsnes (2008)** — соответственно манерность по прессе, референсность без выдающегося уровня, спорная манера; все ниже выбранных.
- **Hempel (1922), Ivogün (1924)** — исторические документы; у Хемпель атрибуция пластинки не верифицирована (расхождение DA 382 / DA4436), у Ивогюн нет кредитов пианиста; вне пятёрки.
- **Schock (1968), Goerne (2018), Keenlyside** — официальных загрузок именно D 889 нет (Шок, Гёрне) или происхождение записи не установлено (Кинлисайд).
- **Приоритетные без записей D 889**: Квастхоф, Шварцкопф, Хоттер, Людвиг, Попп — отсутствие проверено по Грею (45 позиций по D 889), MusicBrainz (work 352cdb51) и Discogs; популярные ролики «Ständchen» этих певцов — D 957/4. Karl Erb (1934) и Wittrisch (1935) — стороны UNISSUED, фонограмм не существует.

## Соответствие правилам состава

3 записи ранее 1990 (1936, 1944, 1965) ✓; 2 записи 1990+ (1996, 2023) ✓; из них 1 запись 2015+ (2023) ✓. Порядок — по строгой иерархии приоритетов: Квастхофа нет → №1 Фишер-Дискау; Шварцкопф не записывала → далее именные старые мастера (Шуман, Андерс — между собой по качеству/репертуарному попаданию и правилу ранней записи), затем современные по качеству (Шефер, Сэмпсон).
