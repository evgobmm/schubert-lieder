## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — DG «Sämtliche Lieder», сессия 1969 (klassik-prisma). Ему 44 — конец пикового периода (~1951–1972), голос ещё полнокровный, интерпретация зрелая. klassik-prisma — 4–5 баллов (верхняя группа обзора). Из пяти его версий выбрана эта: у EMI-версии с Энгелем (1959) нет ни одной критической оценки, а дата сессии подтверждена только YouTube-описанием; версии с Бренделем (изд. 1990) и Парсонсом — поздний голос; Бриттен-1972 и Демус на YouTube отсутствуют. Видео: DGESX_k33Bk (FiDi Topic, 198 с).
2. **Hans Hotter / Hans Altmann** — Preiser, «1959?» (год по klassik-prisma; дискографического подтверждения нет — по правилу «хорошая запись приоритетного исполнителя не блокируется неустановленным годом» публикуется со строкой-диапазоном). Лучшая из четырёх версий Хоттера по klassik-prisma — 4–5 баллов, одна из шести записей верхней группы; ≈50 лет — по досье ещё до заметного спада. Предпочтена версии с Муром 1949 (4 балла): единственный сравнительный обзор ставит её на полбалла выше при сохранном голосе. Видео: CLir_GvXr40 (Hans Altmann - Topic — официальная Preiser-загрузка, канал заведён на пианиста).
3. **Kurt Moll / Cord Garben** — Orfeo «Schubert: Lieder für Baß» (S 021821 A), 1982. Ему 44 — пик великого немецкого баса; редчайший специализированный басовый шубертовский рецитал («set a new standard for these songs» — Wikipedia по карточке реестра). klassik-prisma — 4–5 баллов. Для песни, где ключевой эффект — бездна нижнего регистра, настоящий бас даёт то, чего не дают баритоны. Внутри группы старых мастеров Хоттер и Молль равны по оценке (4–5) — более ранняя запись впереди. Видео: 8s0UFTvdDTY (Moll Topic; НЕ путать с регеровской оркестровой QB0XbYxI3Mw на том же канале).
4. **Christoph Prégardien / Andreas Staier** — Deutsche Harmonia Mundi «Lieder nach Gedichten von Friedrich Schiller», 1993. Ему 37 — пик (~1990–2012); Штайер на историческом инструменте. **Единственная запись песни с полными 5 баллами klassik-prisma и первая строка обзора** — при том, что обзор в целом благоволит старым мастерам; теноровое прочтение вместо привычного басового. Лучший современный кандидат по независимой оценке, а не по пиару. Видео: fGaT8eRuKYI (Prégardien Topic).
5. **Thomas Hampson / Graham Johnson** — Hyperion Schubert Edition, т. 14 «Schubert & the Classics» (CDJ33014), запись октябрь 1991 (сайт Hyperion: Rosslyn Hill Unitarian Chapel; изд. 1992). Ему 36 — пик (~1988–2005). klassik-prisma — 4–5 баллов; Gramophone о томе: «readings… constantly enlightening», Джонсон «at its probing best». Единственная запись песни из «научного эталона» — полного издания Hyperion. Видео: NY0OKtZiyM8 (Graham Johnson - Topic — официальная UMG-загрузка каталога Hyperion).

## Ключевые решения и отклонённые кандидаты

- **Alexander Kipnis (Odéon, август 1917)** — самый трудный отказ: 4–5 баллов klassik-prisma, вторая по рейтингу мужская запись после Прегардьена. Против включения три довода: акустическая запись 1917 года (26-летний Кипнис до пика); **неразрешённый вопрос аккомпанемента** (Michael Gray пианиста не указывает, goldenageofsong пишет «with piano accompaniment», Topic-загрузка кредитует оркестр Берлинской штаатсоперы — досье требует прослушивания перед публикацией); пианист не установлен — корректный name невозможен. Первый резерв.
- **Hotter / Moore (1–2.X.1949)** — 4 балла, пик формы, дата подтверждена буклетом Warner; уступил версии с Альтманном только по оценке единственного сравнительного обзора. Готовый резерв на случай претензий к записи 1959 года.
- **Hotter / Nordberg (1946)** — 4 балла, но на YouTube не найдена ни одна загрузка (целевой поиск). **Hotter / Parsons (1973)** — 3–3,5 балла, худшая мужская оценка обзора: прямая иллюстрация правила о позднем голосе.
- **Fischer-Dieskau, прочие версии**: Engel 1959 (без критического следа, дата недискографична), Зальцбург-1963 live (идентификация Topic-ролика не стопроцентная), Britten 1972 и Demus (нет на YouTube), Brendel (поздний голос).
- **Gérard Souzay / Baldwin (апрель 1954, Gray id 4234)** — 4 балла, пик, «французская лёгкость»; вытеснен из пятёрки записями с 4–5 баллами.
- **Bryn Terfel / Martineau (февраль 1994)** — 4 балла, бестселлер DG; уступил Прегардьену (5) и Хэмпсону (4–5) по прямому сравнению оценок. Современный резерв.
- **Hermann Prey** (Moore 1960; Deutsch live 1990) — ранняя версия без критического следа и с недискографичной датой; поздняя — неофициальный канал и голос за пиком.
- **Goerne / Leonskaja (изд. 2008)**, **Keenlyside (2003)** — вне обзора klassik-prisma, самостоятельной репутации именно в этой песне нет; по правилу скепсиса к прессе о современных не проходят мимо Прегардьена и Хэмпсона.
- **Слот 2015+ оставлен пустым — осознанно.** Кандидаты Boesch (Onyx 2016), Appl (Wigmore 2016), Krimmel (Alpha 2019) не имеют ни одной независимой критической оценки именно этой песни; включение любого из них означало бы выбросить из пятёрки запись с оценкой 4–5 (Хэмпсон или Молль). Правило прямое: квота 2015+ — «только при наличии достойных, никогда в ущерб качеству».
- **Оркестровые версии вне конкурса** (не фортепианная песня): von Otter / Abbado (Регер, DG 2003, Grammy — «оркестровый эталон»), Degout / Pichon (редкая оркестровка Брамса), Moll / NDR (Регер), Appl / Münchner Rundfunkorchester (2023).
- **Behr-Schnabel / A. Schnabel (17.XI.1932)** — единственная историческая женская запись, 3–3,5 балла (вокально за пиком в 56); ценность — Шнабель за роялем, для топ-5 недостаточно.
