## Итоговый топ-5

1. **Thomas Quasthoff / Chamber Orchestra of Europe, дир. Claudio Abbado** — live, Cité de la musique, Париж, 2002; альбом «Schubert: Lieder with Orchestra» (DG, изд. 2003; Grammy 2004 — дайджест). Ему 43 — середина пика (~1993–2007). Оркестровка Макса Регера, не фортепианный оригинал — по правилу о непианистическом сопровождении имя в плеере «Quasthoff — Abbado». Его фортепианная версия с Андрашем Шиффом (Wigmore Hall, 2001, обложечный CD BBC Music Magazine) на YouTube официально отсутствует — остаётся на бумаге. Приоритет №1 правил: достойная запись пика с Аббадо открывает список. Видео: F3J0JcrwYCI (Quasthoff Topic; из двух Topic-дублей того же исполнения выбран по большему охвату).
2. **Dietrich Fischer-Dieskau / Gerald Moore** — EMI/Electrola «Schubert: Lieder Vol. 2», ℗ 1958 (кредиты официальной Warner-загрузки: producer Christfried Bickenbach — тот же, что у Vol. 4, сессии 23–25.05.1958). Точный год сессии не установлен (в базе Грея записей Ф.-Д. для D 547 нет); по правилу о неустановленном годе публикуется диапазон «1957–58?» (фан-загрузка того же дубля, 152 с, заявляет 1957; ℗ 1958). Ему 32–33 — ранний вокальный пик; досье: «ранний Ф.-Д. в этой песне ценнее позднего свода». Доразведка сессии: T6fmST30N-U — Warner-кредиты, 152 с (= MB 153 с), т.е. именно EMI-версия, а не DG-свод 1966–72 (тот — wLw5hl44viw, ℗ 1969 DG, 158 с). Видео: T6fmST30N-U (F.-Dieskau Topic).
3. **Elisabeth Schwarzkopf / Edwin Fischer** — зап. 4–5.10.1952, Abbey Road Studio No. 1A, прод. Walter Legge; Columbia 33CX 1040 (Грей id 58269). Ей 37 — ядро пика. Эталонный шубертовский рецитал (дайджест; Gretchen той же сессии — со-победитель слепого теста 2020). Из её версий выбрана студийная 1952 (лайв Orfeo с Муром без установленного года — второй ряд). Видео: tf7L4IzUuTg (Schwarzkopf Topic, альбом «Schubert: Song Recital», ℗ 1953 / ремастер 2015; кредиты подтверждают Эдвина Фишера и Легге).
4. **Hans Hotter / Gerald Moore** — зап. 2.10.1949, Abbey Road, Columbia LX 1305, матрица CAX 10621 (Грей id 76165); переизд. EMI References CDH 5 65196 2. Ему 40 — центр пика (~1942–1955); связка Хоттер/Мур — «эталон тёмного низкого голоса» (дайджест). Версия 1949 предпочтена рециталу 1957 (за пиком; правило «при прочих равных — более ранняя»). Видео: WPK5C0jSWxI (Hotter Topic, альбом «Schubert: Lieder», ℗ 1994 Parlophone = переиздание EMI References 1994 с группой 1949 года; прод. Walter Legge, 169 с = MB).
5. **Bryn Terfel / Malcolm Martineau** — зап. февраль 1994, Friedrich-Ebert-Halle, Hamburg-Harburg; «An die Musik – Favourite Schubert Songs» (DG 445 294-2) — песня титульная. Ему 28 — самый свежий период голоса (пик ~1992–2005); бестселлер каталога DG (реестр; klassik-prisma 4–5 баллов за Erlkönig с этого же диска — косвенный маркер уровня). Сильнейший верифицированный современный кандидат. Видео: vFkC0Aa3nMs (Terfel Topic).

## Ключевые решения и отклонённые кандидаты

- **Fischer-Dieskau, DG «Sämtliche Lieder» (1966–72, конвенция 1969)** — уступил ранней EMI-версии по состоянию голоса (41–47 против 32–33; «суше ранних 1950-х»); ID-резерв wLw5hl44viw подтверждён кредитами DG ℗ 1969.
- **Fischer-Dieskau / Weißenborn (WDR 1954, Audite)** — самый ранний его вариант (29 лет), но официального ролика нет (174 с — маркер для будущей доразведки).
- **Fischer-Dieskau, medici.tv (bZZqZTKoFcM, 1,06 млн просмотров)** — год не установлен ни по одному дискографическому источнику, диапазона нет — по правилам не публикуется.
- **Fritz Wunderlich / Giesen (2–5.07.1966, DG 139 220; Грей id 2065)** — сильнейший тенор, только-пик, погиб через два месяца; проиграл единственный слот «старого мастера» Хоттеру: в иерархии правил Хоттер — именной приоритет группы 4, связка Хоттер/Мур в этой песне-гимне — прямой эталонный кейс. Первый резерв.
- **Christa Ludwig / Parsons (29.11.1961, Грей id 175955)** — тот же корпус сессий, что её 5-звёздная Gretchen; уступила по той же причине (один слот старых мастеров при трёх именных приоритетах выше). Резерв.
- **Elisabeth Schumann / Moore (7.09.1936, матрица 0EA 3760; Грей id 62855)** — именной приоритет, но 48 лет — на исходе пика; при одном свободном слоте уступает Хоттеру-1949 в вокальном состоянии. Резерв.
- **Ferrier (14.02.1949), Schlusnus (1928), Hüsch (3.03.1938), Lehmann (1947), Schreier (1984), Greindl (1957), Gerhardt (1924), Schmitt-Walter (1940), de los Ángeles (1957?)** — достойный второй ряд старых записей; все проиграли конкуренцию за единственный небронированный до-1990 слот.
- **Benjamin Appl / Baillieu («For Dieter», Alpha, изд. май 2025 — тизер официального канала Alpha)** и **Andrè Schuen / Heide (DG-сингл «Musical Moments», ℗ 2024)** — единственные кандидаты «не ранее 2015»; год теперь установлен по официальным каналам, но критическая репутация именно этих треков не верифицирована (веб-поиск недоступен два прогона подряд), а правило скепсиса к пиару современных запрещает включать их «в ущерб качеству» против верифицированного Терфеля. Слот 2015+ оставлен незаполненным осознанно; Appl — резерв на перепроверку прессы.
- **Fink / Huber (2007, harmonia mundi)** и **Mathis / Johnson (X.1992, Hyperion Vol. 21)**, **Goerne / Deutsch («An mein Herz», HM ℗ 2008)** — достойные современные; уступили Терфелю (титульная запись, пик 28 лет, документированный бестселлер) второй слот 1990+.
- **Anders и Popp песню не записывали** (MusicBrainz count 0; отсутствуют среди 48 записей у Грея; том Попп в Hyperion — «Schubert in 1816», песня сочинена в 1817) — отрицательные результаты досье.
- **Оркестровые/хоровые/инструментальные версии** (Mormon Tabernacle Choir, Lehmann/Гурлитт 1927, Hope, Maisky и др.) — вне жанра сольной песни; исключение сделано только для Квастхофа (именной приоритет №1, правило об ансамблевом имени прямо предусматривает такие случаи).

## Соответствие возрастной структуре

3 записи ранее 1990 («1957–58?», 1952, 1949) ✓; 2 записи 1990+ (1994, 2002) ✓; слот 2015+ пуст — достойного верифицированного кандидата нет (Appl/Schuen без критического следа), места заняты лучшими записями по качеству, как предписывают правила. Порядок — строгая иерархия приоритетов: Квастхоф → Фишер-Дискау → Шварцкопф → звезда прошлого (Хоттер) → современный (Терфель).
