# Der Einsame (D 800) — отбор топ-5 исполнений

Дата: 2026-08-16. Правила: docs/rules/youtube-performances.md. Ярус песни — famous; досье кандидатов: planning/youtube/data/d800-der-einsame.dossier.json (23 кандидата, MusicBrainz-каркас 35 записей). Все итоговые и резервные videoId проверены yt-check (oEmbed 200, живы, встраиваемы); все — официальные Topic-каналы. Даты — только по дискографическим источникам; в двух случаях (Фишер-Дискау DG, Ameling) дата до-верифицирована в этой сессии сверх досье.

## Итоговый топ-5

1. **Dietrich Fischer-Dieskau / Gerald Moore** — DG, свод «Sämtliche Lieder» (сессии 1966–72); для трека лейбл-копия DG даёт «℗ 1969 Deutsche Grammophon GmbH, Berlin» (Qobuz, альбом 0002894310852) → публикуемый год 1969. Главная запись топа: высший из представленных в пятёрке приоритетов (Квастхофф песню не записывал, Шварцкопф заблокирована датировкой — см. ниже). Ему 44 — поздний пик (сухость по дайджесту — только с середины 1970-х). Именно эта версия чаще всего цитируется как «стандарт» Der Einsame; Gramophone характеризует его прочтение как «мягко комический портрет бюргерского благодушия». Из шести его версий: EMI 1955 (дата до-верифицирована: Лондон, 12–13 мая 1955, Muziekweb) вокально свежее, но статус «точки отсчёта» и самая устойчивая официальная загрузка — у DG; правило «при прочих равных — более раннюю» не применено, поскольку уровни не равны (прецедент Gretchen: консенсус весомее ранности). Лайв с Рихтером (29.08.1977) — за пиком и без отдельного трека; Brendel-1982, Höll, «Homage to Moore» — поздний голос. Видео: 9fN5wDg0jrw (FiDi Topic, самая просматриваемая официальная загрузка песни).
2. **Fritz Wunderlich / Hubert Giesen** — зап. 2–5 июля 1966, Akademie der Wissenschaften, Мюнхен (дискография Праефке, сессия «Die schöne Müllerin a.o.»); DG. Сильнейший в группе «прочих звёзд прошлого». Ему 35 — вершина и последние студийные сессии (погиб 17.09.1966; по дайджесту «только пик»). Комплект 1966 с Гизеном — эталон тенорового Шуберта; светлый, улыбчивый тон — ближайший к бидермайерскому характеру песни (Лаппе, «сверчковая» идиллия у печи). Из трёх его версий (студия + Эдинбург 4.09.1966 + Зальцбург 19.08.1965) выбрана студийная: тот же пик голоса без концертного шума и акустики Usher Hall. Видео: Z8dBmI9QHdU (Wunderlich Topic, альбом «Ich liebe dich»).
3. **Lucia Popp / Irwin Gage** — зап. 1–6 ноября 1983, Abbey Road, прод. John Mordler; EMI LP 1984 (данные издания на Discogs). Ей 44 — середина пика (позднего спада у Попп практически нет). Именной приоритет проекта; один из самых любимых женских шубертовских рециталов 1980-х; её Der Einsame — светлое, улыбчивое прочтение, песне идёт (в отличие от D 118, где исследование было против неё). Из трёх загрузок дуэта выбрана надёжно идентифицированная студийная (два лайва 1983/84 не атрибутируются по видео). Видео: zhV5PpMDELw (Popp Topic, «Icon»).
4. **Elly Ameling / Dalton Baldwin** — зап. 1973 (каталожные данные Philips/Universal; альбом «Schubert: Lieder» издан 8.01.1974). Ей ~40 — центр пика; самая записываемая шубертианка поколения, филипсовская серия с Болдуином — репертуарный стандарт 1970-х. Занимает четвёртый «старый» слот вместо второго современного: достойного второго кандидата 1990+ нет (см. ниже). Более поздняя её версия с Янсеном отклонена по правилу ранней записи. Видео: ZD-P1zN9Do0 (Ameling Topic).
5. **Samuel Hasselhorn / Ammiel Bushakevitz** — зап. март 2024, студия B-Sharp, Берлин; harmonia mundi «Licht und Schatten» (релиз 2025), том 2 проекта «Schubert 200» — программа целиком из песен 1824–26. Слот «не ранее 2015»: единственный современный кандидат с независимым непиаровым подтверждением — Preis der deutschen Schallplattenkritik за сам альбом (плюс Diapason d'or года за первый том проекта). Видео: QduApCXrzEw (Hasselhorn Topic).

## Кандидаты, заблокированные датировкой (на переоценку)

Три именных приоритета записали песню, но их даты не проходят правило верификации («даты — по дискографиям, не по метаданным»); публикация с невыверенным или выдуманным годом невозможна:

- **Elisabeth Schwarzkopf / Gerald Moore** (студия EMI, прод. Legge; Topic: jLa5YQulZnA) — топ-1 среди женщин, пик. Год не установлен: трек происходит из массива «Recordings 1948–1954», сборник Naxos 8.111287 (1952–54) песню НЕ содержит; целевые поиски (Warner-боксы, tsaraslondon, Muziekweb, Apple Classical) года сессии не дали. При установлении даты — первоочередной кандидат на вход в топ (вероятно, вместо Ameling).
- **Peter Anders / Michael Raucheisen** (радио Берлина; Topic: VlY8N8YF4RU) — пик Андерса, но датировка — только диапазон издания «Vol. 10 (1943–1947)»; каталог Раухайзен-эдиции не сверен. Плюс узкий радиозвук 1940-х.
- **Elisabeth Schumann / Gerald Moore** (HMV; Topic: oFwQ53rRKLk) — «1937» только из метаданных EMI «Icon»; сверка по матрицам не сделана, а прецедент ложной даты у этой же певицы уже был (D 118: «1945» вместо 1936).

## Прочие отклонённые кандидаты

- **Pears / Britten (1954)** — великая связка, год верифицирован лейблом («1954 Version», Britten the Performer); отклонён из-за документированно спорного тембра Пирса при уже занятом теноровом слоте эталонным Вундерлихом. Первый резерв.
- **Hendricks / Lupu (сессии 25–30.11.1985)** — главный интерес записи — Лупу; голос лёгкий, стилистически не немецкий.
- **Fassbaender / Werba (1974)** — добротно, но ранний рецитал ценится ниже её поздних работ; уступает всем пяти выбранным.
- **Prey / Engel** — год сессии не установлен (только релиз 1974); тёплая манера песне идёт — кандидат на переоценку при датировке.
- **Goerne / Schneider (том 8 эдиции, 2007–12)** — крупнейшее имя современного слота, но тёмная медленная манера противопоказана этой светлой песне; точный год тома не установлен.
- **Güra / Berner (релиз 2012)** — лучший «обычный» современный кандидат (настоящая немецкая теноровая школа); без независимого подтверждения уровня именно этой записи не дотягивает до вытеснения старого мастера. Современный резерв.
- **Arcayürek / Lepper (2017)** — альбом назван по песне, рецензия Gramophone существует, но текст за пейволлом — уровень не подтверждён; дебютант.
- **Appl / Baillieu (2017)**, **Bostridge / Drake (лайв, дата не установлена)** — правило скепсиса к прессе о современных; у Бостриджа манера намеренно нервная — для бидермайерской идиллии спорна.
- **Jackson / Johnson (февраль 1996, Hyperion т. 26)** — научный эталон (заметки Джонсона — главный содержательный источник о песне), вокально не топ.
- **Haefliger / Dähler (~1987)**, **Erb / Seidler-Winkler (1930–40-е)** — далеко за вокальным пиком; документальная, не топовая ценность.
- **Wunderlich, лайвы (Зальцбург 1965, Эдинбург 4.09.1966)** — та же вершина голоса, но концертный звук; на f4opWwTvoZg версия не идентифицируется однозначно.
- **Maisky / Hovora** — виолончельная транскрипция, вне конкурса. **Sarah Walker / Vignoles** — нет загрузки, альбом не установлен. **Quasthoff, Hotter, Ludwig** — песню не записывали (проверено по дискографиям и MusicBrainz; для Хоттера и Людвиг — отрицательный результат поиска).

## Соответствие возрастной структуре

4 записи ранее 1990 (1966, 1969, 1973, 1983) + 1 запись 2015+ (2024). Желательные «2 записи 1990+» не выполнены сознательно: правило разрешает структуру «только при наличии достойных, никогда в ущерб качеству», а единственный современный кандидат с независимым критическим подтверждением именно этого материала — Hasselhorn; второй современный слот отдан Амелинг (старый мастер в центре пика) вместо Гёрне/Гюры/Арджаюрека, ни один из которых не показал песенно-специфичных свидетельств уровня выше её.

2. **Fischer-Dieskau — Moore, EMI 1955** (F714qOJ_VxE, Topic) — дата верифицирована (Muziekweb: Лондон, 12–13.05.1955); прямой резерв слота 1 при смерти DG-загрузки.
