## Ключевые решения и отклонённые кандидаты

Ниже — сводка пер-песенного разбора из `cycle-schwanengesang-top5.md` (раздел Die Taubenpost, 2026-08-17), на основе базы Майкла Грея (поиск по work = Taubenpost, 8 внецикловых сессий) и оставшихся 5 полных циклов Schwanengesang (Квастхоф/Фишер-Дискау/Хоттер/Прай/Финли).

- **Hermann Prey / Walter Klien, 1963 (Decca, «Cycle»)** — цикловый кандидат на позицию № 4, **вытеснен Андерсом**. Основания: (а) иерархия правил — Андерс назван поимённо среди приоритетных исполнителей (группа 4), Прай в списке приоритетов не значится; (б) идиоматика — «Taubenpost» светлая, подвижная «бисовая» песня в верхнем шубертовском лирическом регистре, лирический тенор Андерса на пике формы подходит ей ближе, чем нейтральное баритональное чтение Прая; (в) фонограмма Андерса официальная (Preiser Records, историческое переиздание, не агрегатор). Видео Прая `jkVHluvR9Z0` («Hermann Prey - Topic», альбом «(Cycle)», ℗ 1963 Decca) остаётся первым резервом и используется для прочих 13 песен цикла на сайте.
- **Gerhard Hüsch / Gerald Moore, 27 августа 1937** (Electrola, матрица 2RA 2185; Грей id 54118) — официальная загрузка Preiser есть (`_S83Cho4pWI`, канал «Gerald Moore - Topic»); певцу 36, запись первого ряда исторической школы. Отклонён по арифметике состава: три доцикловых слота уже заняты Фишером-Дискау, Хоттером и Андерсом. **Второй резерв.**
- **Heinrich Schlusnus / Sebastian Peschko, 24 мая 1943** (Polydor 68068, Грей id 27428) — официальная Preiser-загрузка `jFQVFoPgOhY`; уступает Андерсу того же радиовоенного времени по тембровой свежести для этой конкретной песни. Отклонён.
- **Gérard Souzay / Dalton Baldwin, дек. 1961 – янв. 1962** (Philips 835137 AY, Грей id 59970) — на YouTube только «серые» агрегаторские загрузки (Believe SAS/BNF Collection), официальной Decca/UMG-раскладки нет. Непубликуем по правилам происхождения.
- **Hans Duhan / Ferdinand Foll, 3 ноября 1928** (HMV ES471, Грей id 39084) — исторический интерес, официальных загрузок не найдено.
- **Nina Dorliak / Святослав Рихтер, 29 марта 1956** (Мелодия, Грей id 16518) — курьёз ради пианиста, певица вне приоритетов правил, официальной загрузки нет.
- **Fritz Wunderlich** — отрицательный результат: в отличие от «Ständchen» (DG 1966), «Die Taubenpost» на его студийном альбоме «Ich liebe dich» и в приватных плёнках «Wunderlich privat» не найдена.
- **Elisabeth Schwarzkopf, Elisabeth Schumann, Christa Ludwig, Lucia Popp** — «Die Taubenpost» не находится ни у одной из четырёх женщин-приоритетов правил.
- **Прочие внецикловые/современные** (Haefliger, Munteanu, A. Schmidt, Nigl, Volle, Terfel, Prégardien/Staier, Güra/Berner, Goerne, Gerhaher, Holzmair, Padmore, Fassbaender, Björling-сын, Behle/Krampe) — официальные загрузки в основном есть, но ни одна не даёт основания потеснить пятёрку; единственный современный слот по совокупной независимой критике держит Финли.
