Источники: Discogs API (каталожные номера, годы изданий, кредиты, редакционные notes), MusicBrainz API, Naxos.com, Wikipedia (биографии), дайджест фонда `planning/research/singers-digest.md` (пик/спад формы, YT-охват; там — сводка полного исследования `schubert-singers.md`). Всё, что не удалось довести до источника, помечено «?». Даты записи из метаданных YouTube не используются. Составлено: 2026-08-17.

## Сводные наблюдения для конвейера

1. **Eterna Schubert-Lieder-Edition (ГДР, ~1964–1987)** — распределённый по певцам свод: Schreier (Goethe, Rückert/Platen/Collin/Heine, Klopstock/Hölty и др., Müllerin, Schwanengesang), Lorenz (Goethe 2, Schiller, Mayrhofer, Freundeskreis, Matthisson/Claudius, автобиографические), Leib (Schulze, Rellstab, Müllerin, Winterreise), Adam (сольный рецитал, Winterreise); пианисты Olbertz/Shetler/Zechlin/Dunckel (Discogs, годы изданий). Для редких песен это главный «старый» фонд помимо Fischer-Dieskau/DG и Hyperion.
2. Довески цикловых дисков (Prey/Philips Schwanengesang + Der Fischer/Der Wanderer/Erlkönig; Lorenz/Capriccio Winterreise + 15 Lieder; Schreier/Eterna Müllerin + Rellstab-Lieder) — легальный источник несцикловых песен у цикловых записей; трек-состав сверять по изданию.
3. Специализированные ниши: Moll/Orfeo — басовые песни («новый стандарт» по Wikipedia); Hüsch/Erb/Kipnis/Janssen — исторические одиночные стороны, входящие в антологии EMI «Schubert Lieder on Record» (маркер канона); Hotter вне Winterreise — три слоя (Raucheisen 1942–45, EMI/Moore 1949–57, поздний Decca/Parsons 1974?).
