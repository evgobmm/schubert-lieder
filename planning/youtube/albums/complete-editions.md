Источники обозначены в скобках: (Hyperion) — страницы hyperion-records.co.uk по каталожному номеру; (Naxos) — naxos.com/CatalogueDetail; (Discogs) — api.discogs.com; (MB) — MusicBrainz; (Gray) — дискография Майкла Грея classical-discography.org (сессии); (пилот) — `../albums.md`; (дайджест) — `planning/research/singers-digest.md`. Хвосты с «?» — не подтверждены источником. Даты Naxos/Discogs — даты **издания**; даты «зап.» — только по дискографическим источникам.

## Примечания для конвейера

1. Годы в плеере: для изданий с документированными сессиями — год сессии (Hyperion, Goerne, циклы FD/Prey/Souzay по Грэю); для Naxos DSLE — год издания, пока сессия не установлена (правило `youtube-performances.md`).
2. Один альбом = один год во всех песнях (сквозная унификация); конвенция FD DG «Sämtliche Lieder» — 1969.
3. Кредиты сборных томов Hyperion (20, 22, 24, 26, 28, 32–37) при публикации конкретной песни сверять по трек-листу тома (страница Hyperion показывает состав только суммарно).
