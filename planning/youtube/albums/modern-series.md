# Мега-реестр альбомов: современные серии (певцы ~1990–наст.)

Часть опорного реестра альбомов (`docs/rules/youtube-performances.md`, «Масштабирование», п. 4). Не дублирует построчно пилотный `planning/youtube/albums.md` — там же лежат детали по песням пилота; здесь — сквозные карточки по певцам для наследования фактов любой песней корпуса.

Источники (обозначения в карточках): MB = MusicBrainz API (release-group, дата первого издания); Discogs = Discogs API (кат. номера, notes с датами сессий); digest = `planning/research/singers-digest.md`; albums.md = пилотный реестр; en.wiki = английская Википедия (страница артиста). Метаданные YouTube источником дат не являются. Хвосты и неподтверждённое — со знаком «?».
