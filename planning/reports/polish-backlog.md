# Бэклог полировки (не-блокеры сверки)

Сюда складываются пункты «ШЛИФОВКА:» из сверок волн — вкусовые формулировки, однокоренные повторы, оттенки дублей «сноска/раздел». Закрываются батчами (Fable по 3–5 песен) отдельным заходом, публикации не блокируют.

- [ ] **Атрибуция цикла D 688 по номерам** (найдено сверкой 03.09): в каталоге у всех четырёх номеров стоит пара «Pietro Metastasio, Jacopo Vittorelli», тогда как файл фактов D 688/3 подтверждает по изданию Метастазио (Флоренция, 1832) только Метастазио, а Витторелли относится к №№ 1–2. Разнести атрибуцию по номерам в каталоге (planning/catalog), затем перегенерировать index.json; поля poet_de/poet_ru в файлах песен привести к тому же.
