## План ночи (утверждённый порядок запуска, translation-scale-plan.md §5)

1. **Словарная волна топ-500** — очередь `planning/dictionary/top-500-queue.json` (500 форм), партиями по ~20 форм на агента, два последовательных воркфлоу (13 + 12 агентов). Агенты пишут батчи в scratchpad, слияние в `entries/` — скриптом с валидацией, коммит после каждого воркфлоу.
2. **Досье поэтов пилотной волны** — `planning/research/poets/` (один агент на поэта).
3. **Пилотная волна-замер** — 5–8 песен разных типов, полный конвейер (prepare-song → дорожка непокрытых → перевод+аннотации → «О песне» из файла фактов → двухагентная приёмка → правка→сверка → check-corpus → публикация), партиями по ~3 песни на воркфлоу.
4. **Замер и отчёт** — субтокены на песню, прогноз на корпус; итоговое сообщение пользователю (в т.ч. о переписанном правиле в project.md: заморозка перевода → утверждён к запуску).
