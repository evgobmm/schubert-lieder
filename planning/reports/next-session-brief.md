### A. Fable-бандл — компактный рендер вместо JSON (`build-bundle.js fable`), одна часть ≤42k знаков
Формат рендера (текст, без JSON):
```
# «Title_de» (D n) — «title_ru», poet_ru, year
[T] титульная сноска: текст            (если есть)
== Строфа 1
1.1 DE: Ohne sie ist Alles todt,
1.1 RU: Без [Ohne] | неё [sie] | всё [Alles] | — [ist] | мертво, [todt,]
1.1 #0 meaning [0-4]: текст сноски
== О песне
[S0] «Заголовок»: текст (абзацы через \n)
```
Сегмент = `ru [de]`; пустой de → `ru []`, пустой ru → `[de]`. Дальше в бандле как сейчас: бриф, компактные факты (700 зн.), досье «Кратко», карточки (lemma/recommendation/caveats ≤160, без evidence).

### B. Fable возвращает СПИСОК ПРАВОК, применяет скрипт `apply-edits.js`
Fable пишет ОДНИМ Write файл `work/edits-<slug>.json`:
```
{"d":"429","edits":[
 {"type":"segments","line":"3.1","segments":[{"de":"Ohne","ru":"Без"},{"de":"sie","ru":"неё"},{"de":"ist","ru":"—"},{"de":"Alles","ru":"всё"},{"de":"todt,","ru":"мертво,"}]},
 {"type":"ann","line":"3.1","index":0,"text":"новый текст","segment_range":[0,4]},
 {"type":"ann_delete","line":"1.2","index":1},
 {"type":"ann_add","line":"2.3","ann":{"type":"lang","segment_range":[1,1],"text":"..."}},
 {"type":"section","index":2,"title":"Музыка","text":"..."},
 {"type":"section_delete","index":7},
 {"type":"title_ann","text":"..."}, {"type":"title_ru","text":"..."}
],"removed":[{"what":"...","why":"..."}],"flags":["..."]}
```
Затем ОДИН Bash: `node planning/scripts/apply-edits.js <d> <W>` — применяет правки к `work/candidate-<slug>.json` (индексы — по текущему кандидату; удаления применять по убыванию индексов; правка `segments` обязана сохранить множество немецких слов строки — иначе отклонить с сообщением), вызывает `finish-page.js --final` (валидатор, линт, сборка delta-бандла) и печатает отчёт; при ошибке Fable правит edits-файл и повторяет (≤1 раз). Схема ответа Fable: d, ok, n_changes, removed, flags, tool_calls (removed берётся из файла). Итог: Fable = Read (1 часть) + Write + Bash ≈ 3 хода, цель ≤0,35M/песня. Мандат прежний: полное чтение вслух, язык+смысл+перевод, без новых фактов.
