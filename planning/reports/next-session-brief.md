# Бриф для новой сессии: волна №4 (после приёмки пользователем)

Контекст: `planning/reports/translation-run-state.md` (последние записи — итоги волны №3), правила `docs/rules/*.md`, закон агентов `planning/catalog/one-shot-brief.md`. Главный цикл — Opus (`.claude/settings.json`), Fable — только агент финальной редактуры.

Состояние на 2026-08-23: **волна №3 завершена полностью, переведённых страниц 105** (Хёльти, Козегартен, Клаудиус закрыты целиком; Майрхофер — 12 самых коротких). Валидатор 0 ERROR, линт 0, сборка проходит, реестр источников полон. Новая волна — только после приёмки пользователем опубликованных страниц и по его «поехали».

Конвейер после волны №3 вылечен от четырёх причин холостых кругов ремонта (пустые `de`, усечённые компактные факты, счёт сегментов с единицы, качели «сноска ↔ раздел») — все правила уже стоят в CONV трёх воркфлоу. Ожидание: ремонт должен сходиться за 1–2 круга, а не за девять.

Порядок работы (дисциплина ≤ ~6 ходов на партию):
1. `bash planning/scripts/wave-prep.sh <W> <d>...` — в фоне, ~1 мин сети на песню.
2. `Workflow({scriptPath: 'planning/catalog/wave-v2-workflow.js', args: <содержимое W/args.json>})` — вся волна одним запуском, 6 цепочек.
3. `node planning/scripts/wave-report.js <runId> <W>` — статус «БЕЗ FABLE — не публиковать» означает, что редактуры у кандидата нет; публиковать только «ЧИСТО». Состояние надёжнее считать по сырому результату воркфлоу (`results[].fable.ok` + последняя сверка), журнал при возобновлении смешивает прогоны.
4. `publish-candidates.js`, коммит+пуш, `usage-delta.js` + строка в журнал.
5. Нечистые — `repair-args.js` + `wave-repair-workflow.js`. Файл `<W>/repair-args.json` читают сами агенты: НЕ перезаписывать его, пока круг в работе.

Планирование объёма: **волна режется по остатку недельного пула Fable** (≈0,4M токенов Fable на песню), а не только по числу песен; при исчерпании пула — пауза до сброса (Fable другой моделью не заменять, кредиты не докупать). Возобновление прогона (`resumeFromRunId`) не бесплатно: часть завершённых цепочек гонится заново — дешевле новый прогон только на недоделанные песни, а для песен с готовой страницей — `wave-fable-workflow.js` (только Fable + сверка).
