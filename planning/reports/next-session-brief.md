# Бриф для новой сессии: волна v2 (после приёмки пользователем)

Контекст: `planning/reports/translation-run-state.md` (последние записи — v2-калибровка и замер), правила `docs/rules/*.md`, закон агентов `planning/catalog/one-shot-brief.md`.
Состояние: v2-конвейер откалиброван (D 429, D 436, D 457 опубликованы; 2,15M биллинговых на песню по агентам). Волна — только после приёмки пользователем опубликованных страниц и по его «поехали».
Запуск волны (главный цикл — коротко, без зондов):
1. `node planning/scripts/pilot-prep.js <W> <d>...` → `node planning/scripts/prefetch-sources.js <W>/prefetch <d>...` (сеть, ~1 мин/песня) → для каждой песни `build-bundle.js dict|facts <d> <W>`.
2. `node planning/scripts/wave-args.js <W> <d>...` → JSON в `args`; `Workflow({scriptPath: 'planning/catalog/wave-v2-workflow.js', args})`. Скрипт гонит цепочки партиями по 3; модели sonnet/sonnet/opus/fable/opus; ремонт при нечистой сверке — один раунд.
3. По итогам: чистые — `node planning/scripts/publish-candidates.js <W> <d>...`; нечистые — ремонт по списку (конвенция сегментов — в CONV скрипта); коммит+пуш после каждой партии.
4. Замер: `node planning/scripts/usage-delta.js <ISO-старта>`; сверить с ccusage пользователя.
Кандидаты (с досье, топ-5, записями): Хёльти 13, Козегартен 13, Клаудиус 12, Майрхофер 45 (короткие), Шобер 11, Коллин 3; без досье (Шиллер 42, Маттисон 29 …) — сначала досье поэта.
Неприкосновенно: 24 песни Winterreise. Мониторов с событиями не ставить; в главном контексте большие файлы не читать.
