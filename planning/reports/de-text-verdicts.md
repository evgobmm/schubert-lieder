# Вердикты аудита немецких текстов

Дата: 2026-08-31. Источник списка: `planning/reports/de-text-audit.md` (скрипт `check-de-texts.js`).
Вердикты выносили 12 агентов (sonnet) по предзагруженным источникам — критический текст Петера Растля (schubertsong.uk), немецкий справочник schubertlied.de, файлы фактов песен. Немецкий текст ни в одной песне не менялся: это список для решения.

**Итог: 287 пунктов** — artifact 85 (мнимые), schubert 60 (текст проекта верен, расходится со стихами поэта), **defect 73** (вероятная ошибка проекта), uncertain 69 (источников не хватает).
Из категории «schubert» 25 пунктов помечены как не оговорённые на странице — их стоит объяснить в разделе «Стихотворение».
