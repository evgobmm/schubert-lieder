# Schubert Lieder / Песни Шуберта

Сайт: **https://evgobmm.github.io/schubert-lieder/**

Все сольные песни Франца Шуберта (618 по каталогу Дойча) с немецким текстом «как поётся», пословным
русским подстрочником и пояснениями к языку и смыслу. У каждой песни — раздел «О песне» (дата, стихи,
музыка, издания, судьба) и до пяти избранных записей с YouTube; под записью подсвечивается пропеваемое
слово, клик по слову перематывает исполнение. Есть поиск по названиям, номерам Дойча и тексту, мобильная
раскладка, тёмная тема и печать.

Образец и отправная точка — [evgobmm/Winterreise](https://github.com/evgobmm/Winterreise): его переводы
24 песен цикла вошли сюда без изменений, стиль и модель данных повторены.

Сайт сделан с помощью ИИ и предназначен для общего знакомства с песнями; как источник знаний он пока
рассматриваться не может. Источники и благодарности — в окне «Источники» на сайте.

## Устройство репозитория

- `app/` — приложение (Vue 3 + Vite); данные песен в `app/src/data/`. Сборка и публикация — GitHub Actions
  при каждом пуше в `main`.
- `docs/rules/` — правила проекта: перевод, стиль, отбор записей, проверка фактов, пословные тайминги.
- `planning/` — исследования, каталог, конвейеры и отчёты.
