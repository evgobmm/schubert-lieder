# Цель проекта и рамки

Обновлено: 2026-08-14. Источник — указания пользователя (чат).

## Цель

Сайт со **всеми песнями Шуберта** (~600+) с пословным русским переводом. Образец — https://github.com/evgobmm/Winterreise (собственный проект пользователя, CC0): его стиль и вся интерактивность воспроизводятся.

## Требования к сайту

- Найти все песни Шуберта и их немецкие тексты.
- Песни сгруппировать; удобное расположение на сайте; **поиск по песням**.
- **Мобильная версия** обязательна.
- На каждую песню — **топ-5 (максимум) роликов YouTube** со значительными исполнениями (правила: `youtube-performances.md`).
- Пословный перевод в духе референса: отдельное значение каждому слову; объединение слов — только когда строгая буквальность искажает смысл или грамматику; сохранение немецкого порядка слов, где это грамматично; пояснения по наведению (правила: `translation.md`).
- **Целевое требование (не пилот)**: синхронизация текста с записью — поющееся слово подсвечивается (слева и справа; тайминги выверяются вручную по звуку; тянущееся слово подсвечено, пока звучит).

## Этапность

Работа многоэтапная. На одном из первых (но не первом) этапов — **одна пилотная песня** на просмотр пользователю, затем масштабирование.

## Группировка песен (указания 2026-08-14)

- **Циклы — точно отдельными группами.**
- Ориентироваться на **авторитетные разбиения** корпуса: изучить, как группируют авторитетные издания/справочники, и взять их схему за основу.
- Вкус пользователя: **поэтная группировка не нравится; нравятся периоды и тематическая**. Если среди авторитетных схем есть периодная/тематическая — предпочесть её; если авторитетное разбиение только другое (и альтернатив нет) — **брать как у авторитетов**.
- Плоский список всех песен с поиском остаётся в любом случае (см. «Требования к сайту»).
- **Рабочее решение по итогам исследования** (`planning/research/authoritative-groupings.md`): главное оглавление = 3 цикла + **хронологические периоды** (у периодов сильнейшая авторитетная опора: Дойч, AGA, NSA, бокс Hyperion, Уигмор и др.); **темы — только вторичный слой тегов/подборок**, не партиция (тематической партиции нет ни у одного авторитета — только теги schubertsong.uk и реситальные тома Hyperion); **поэт — индекс/фильтр**, не группировка (прецедент — регистр NSA IV/15).
- **Размер раздела (указание пользователя 2026-08-14): сильно больше 50 песен в разделе — не вариант.** Ориентир ~25–50 песен на раздел; перегруженные годы (1815 ≈ 144, 1816 ≈ 103, 1817 ≈ 61) делить на части по месяцам/полугодиям (прецеденты дробления года: Hyperion — четыре диска 1815 года; AGA — 1815 на два тома), малые годы объединять (прецеденты: Hyperion «Schubert in 1817 & 1818», «1819 & 1820», «1822–1825»).
- Предложенная сетка (~15 разделов, ждёт утверждения пользователем): 1810–1814 (~46) · 1815 в трёх частях (~48×3) · 1816 в двух частях (~51×2) · 1817 в двух частях (~30×2) · 1818–1819 (~40) · 1820–1822 (~52) · 1823–1825 (~49, Мельничиха отдельно) · 1826–1828 (~49, Зимний путь и Лебединая песня отдельно) + 3 цикла (20/24/14). Точные границы внутри 1815–1817 провести по датам (месячная точность schubert-digital.at) при сборке каталога.
