# Цель проекта и рамки

Обновлено: 2026-09-09. Источник — указания пользователя (чат).

## Цель

Сайт со **всеми песнями Шуберта** (~600+) с пословным русским переводом. Образец — https://github.com/evgobmm/Winterreise (собственный проект пользователя, CC0): его стиль и вся интерактивность воспроизводятся.

## Требования к сайту

- Найти все песни Шуберта и их немецкие тексты.
- Песни сгруппировать; удобное расположение на сайте; **поиск по песням**.
- **Мобильная версия** обязательна. Её правила:
  - **Выбор песни** — не системный список из всех песен, а панель во весь экран с тем же списком разделов, что в сайдбаре на компьютере (разделы раскрываются, поиск, «Свернуть все», текущая песня видна); в шапке — кнопка с названием текущей песни и двойным шевроном, стрелки «‹ ›» остаются. Строка поиска в шапке тоже остаётся.
  - **Горизонтальной прокрутки нет**: страница двигается только по вертикали (горизонтальные жесты отключены).
  - **Плей/пауза** — плавающая круглая кнопка внизу справа, пока в плеере загружена запись; значок по текущему состоянию (пауза во время игры, плей на паузе и после конца).
  - **Ведение по тексту** при исполнении — см. `word-sync.md` (только на мобильной раскладке).
- На каждую песню — **топ-5 (максимум) роликов YouTube** со значительными исполнениями (правила: `youtube-performances.md`).
- Пословный перевод в духе референса: отдельное значение каждому слову; объединение слов — только когда строгая буквальность искажает смысл или грамматику; сохранение немецкого порядка слов, где это грамматично; пояснения по наведению (правила: `translation.md`).
- **Целевое требование (не пилот)**: синхронизация текста с записью — поющееся слово подсвечивается (слева и справа; тайминги выверяются вручную по звуку; тянущееся слово подсвечено, пока звучит).

## Этапность

Работа многоэтапная. На одном из первых (но не первом) этапов — **одна пилотная песня** на просмотр пользователю, затем масштабирование. Пилот («Гретхен за прялкой») принят пользователем — идёт фаза «все песни».

## Фаза «все песни» (активна)

- **Отложенные задачи (зафиксированы, сейчас НЕ делаем, ждут отдельной команды):** русские названия песен и имена поэтов для всего каталога; русские вступления к разделам.
- **Перевод утверждён к запуску пользователем 2026-08-17** («поехали»): последовательность — словарная волна топ-500 → досье поэтов → пилотная волна-замер 5–8 песен → отчёт о цене песни → калибровка → серийные волны (план: `planning/translation-scale-plan.md`; ход: `planning/reports/translation-run-state.md`). Немецкие тексты корпуса готовы (618/618). Уже опубликованное: Гретхен (пилот) и 24 песни Winterreise (импорт собственных переводов пользователя, CC0) — остаются. Заготовки (дистиллят правил, генератор конвейера) лежат в репозитории без движения. Немецкий текст «как поётся» — у каждой из 628 песен; верность обеспечивается обязательным конвейером проверки (извлечение → механический контроль неизменности слов → проверка связности независимыми агентами → починка только перечисленных дефектов → повторная проверка). Непроверенный текст на сайт не попадает (карантин).
- Добавление всех песен идёт **в текущем чате**: сначала только немецкие тексты, без перевода.
- Если работают параллельные сессии: обе пушат в `main` — перед push всегда `git pull --rebase`; мелкие частые коммиты; изменения приложения (`app/`) согласовывать между потоками (модель данных менять только с фиксацией в CLAUDE.md).
- Источники: сводка и матрица — `planning/research/song-sources.md`; данные каталога — `planning/catalog/` (D-номера — канонические ID; slug `d<номер>-<кебаб-название>`; компиляции LiederNet/schubertsong.uk без разрешения не копировать).
- **По возможности брать все тексты и даты написания из одного авторитетного источника.**
- Рабочие решения фазы (до иных указаний): корпус = сольные Lieder по NSA (genre=Lied, ~630, одна страница на D-номер; фрагменты и ариетты из зингшпилей — точечно позже); тексты начинаем с OpenScore (CC0, «как поётся»); вопрос писем Растлю/Врену/Эзуст открыт — работаем с безусловно свободными источниками.
- **Типографская конвенция строк: каждая строка немецкого текста начинается с заглавной буквы** — как в референсе Winterreise пользователя (выдержано там во всех строках без исключений). Нормализация механическая (первая буква строки → заглавная), применена ко всему корпусу; новые тексты публиковать сразу по конвенции. Перенос строки (`\n`) внутри одной строки массива — дефект данных, чинить разбиением.
- **Массовый источник текстов — сканы AGA Serie XX в оцифровке MDZ** (10 томов, bsb00044995…bsb00045005; IIIF-манифесты дают карту «песня → страницы», изображения читаемы при ширине 1800px; сами тексты 1820-х — PD, атрибуция сканов: Bayerische Staatsbibliothek). IMSLP для массового скачивания не использовать (ботозащита с капчей — не обходить). Конвейер транскрипции: страницы → две независимые транскрипции зрением → сверка/арбитраж → проверка связности → публикация.

## Группировка песен
- **Две песни переставлены между разделами по датам (2026-09-10)**: D 751 «Die Liebe hat gelogen» из 1820–1821 в 1822–1823 (NSA 1822, проверенная проза «1822 год», датировка «после сентября 1821 до 17.04.1822»); D 639 «Widerschein» из 1818–1819 в 1820–1821 (NSA 1820, проза «около 1819–1820»). Основание: раздел и год под заголовком не должны спорить с текстом самой страницы.
- **Год под заголовком не противоречит разделу** (2026-09-09): год — первый год датировки schubert-digital (`date_sd`), иначе год NSA; если он вне раздела, в котором стоит песня (широкая датировка вроде «1819 bis 1823» или «vor November 1821»), показывается год NSA, когда он в разделе (D 550 — 1817, D 514/515 — 1817, D 516 — 1816, D 362 — 1816), иначе весь диапазон датировки («1816–21» у D 300, «1819–23» у D 633/634). Логика — `displayYear(c, sec)` в `build-app-data.js`; поле `year` в файлах песен синхронизируется с индексом.

- **Циклы — точно отдельными группами.** Названия циклов в навигации/заголовках — **на немецком** (Die schöne Müllerin, Winterreise, Schwanengesang).
- Ориентироваться на **авторитетные разбиения** корпуса; вкус пользователя: поэтная группировка не нравится, нравятся периоды и темы; если авторитетное разбиение только другое — брать как у авторитетов. Итог исследования (`planning/research/authoritative-groupings.md`): главное оглавление = 3 цикла + **хронологические периоды**; **темы — вторичный слой тегов**, не партиция; **поэт — индекс/фильтр**, не группировка.
- **Размер раздела: сильно больше 50 песен — не вариант** (ориентир ~25–50); перегруженные годы делить по месяцам, малые годы объединять (прецеденты: Hyperion, AGA).
- **Утверждённая сетка** (реализация — `planning/catalog/sections.json`; 16 хронологических разделов + 3 цикла, 619 песен (после удаления утраченных и бессловесных, включая две с утраченной музыкой при сохранившемся тексте, и склейки двойных строк NSA — D 442 и D 443 числятся и в хоровой серии III/3a, и в песенной IV/10; оставляем по одной строке, предпочитая IV)): 1810–1814 (43) · 1815: янв–май (37), июнь–июль (34), август (27), сент–дек (39) · 1816: янв–апр (38), май–июль (37), авг–дек (44) · 1817: янв–апр (31), май–нояб (29) · 1818–1819 (41) · 1820–1821 (38) · 1822–1823 (39) · 1824–1825 (30) · 1826–1827 (41) · 1828 (13) · Die schöne Müllerin (20) · Winterreise (24) · Schwanengesang (13 + Taubenpost D 965A = 14, примечание о посмертном сборнике). **Порядок внутри раздела — хронологический по современным датировкам** (schubert-digital/NSA); песни с диапазоном дат сортируются по СЕРЕДИНЕ диапазона — это воспроизводит порядок хронологического бокса Hyperion (проверено на самых ранних: Lebenstraum D 39 → Hagars Klage D 5 → …, Des Mädchens Klage D 6 — позже, к 1812). Заголовки годовых разделов — просто годы, без подписей («1810–1814», не «Начало (1810–1814)»; «1828», не «Последний год»). Исключены 14 записей: утрачены целиком (verschollen), эскизы без слов (ohne Text), «D deest» — список с причинами в sections.json. Каждому разделу — короткое русское вступление (позже).
- **Песни, у которых текста не существует** (утрачены целиком — «verschollen», или эскизы мелодии без слов — «ohne Text»; их никто не поёт и не записывает), **убираются из списка сайта**. Официальный признак — классификация NSA. Песни с сохранившимся текстом (в т.ч. фрагменты) остаются.
- **Также убираются песни с утраченной МУЗЫКОЙ** (даже если текст сохранился): раз нот нет — их не поют и записей не существует. Перед удалением проверять фактически, что записей нет (реконструкции/находки бывают).
- **Метод последней инстанции для труднодоступных текстов: через записи.** Если песня записана (например, в полном издании Hyperion), немецкий текст берётся со страницы записи/из буклета (сами стихи — PD; чужие переводы не копировать) или, в крайнем случае, распознаётся с аудио.
- **Порядковые номера в списке не показываем** — это служебная нумерация сайта, не официальная; официальные номера — D (каталог Дойча), показываются на странице песни.
- **Навигация слева: раскрывающиеся разделы**, не сплошной список. Разделы раскрываются и сворачиваются **независимо друг от друга** (открытых может быть несколько); **при загрузке раскрыт раздел текущей песни**, остальные свёрнуты, список прокручен так, чтобы текущая песня была видна. Смена песни извне списка (поиск, ссылка) раскрывает её раздел и прокручивает список к ней (если строка и так видна — список не дёргается); раскрытие по клику — с короткой анимацией высоты, программное — мгновенно. Заголовок раскрытого раздела «липнет» к верху списка при прокрутке; слово «Песни» и строка поиска не прокручиваются вместе со списком. Типографика шапки: главное слово — год (полужирный), уточнение (месяцы; у циклов — D-номер и год второй строкой) — обычным начертанием второстепенным цветом; названия песен мельче шапок, с отступом под направляющей линией. Порядковые номера не показываем; D-номер в списке — только у песен с одинаковым названием внутри раздела (для различения). В шапке раздела — число песен; свёрнутый раздел с текущей песней подсвечен. Текущая песня — светлой заливкой в цвет акцента с полосой слева, не сплошным блоком. Чуть правее слова «Песни» — квадратная кнопка со значком (две шевронные стрелки навстречу друг другу, в языке шевронов разделов), при наведении показывает подсказку «Свернуть все»; сворачивает все разделы разом.
- **Поиск**: под словом «Песни» — строка со значком лупы, всегда на виду (не прокручивается со списком). Ищет **сначала по названиям** (немецким и русским) и **по D-номеру** («118», «d 795.1», «965a»); если в названиях ничего — **по тексту песни**. **По имени поэта** (русскому и немецкому) тоже ищет — после совпадений в названиях, рангом ниже: «Шиллер» показывает все его песни (добавлено 2026-09-10). **По исполнителю и пианисту** из списка записей — последним рангом, под названием показывается совпавшая запись («запись: Quasthoff — Zeyen, 2005»); «Quasthoff» показывает 82 песни (добавлено 2026-09-10). Подсказка в пустой строке поиска перечисляет, по чему ищем, и подобрана по ширине поля: на компьютере «Название, поэт, текст…» (поле 163 px) с полным перечнем во всплывающей подсказке, на телефоне «Название, D-номер, поэт, исполнитель…». Частичное вхождение («прялк» находит «Гретхен за прялкой»); срабатывает само практически мгновенно (пауза ~80 мс лишь склеивает быстрый набор). Результаты ранжируются: название целиком → с начала названия → с начала слова → внутри слова; при равном ранге — хронологически. Совпавший фрагмент подсвечен; под названием — D-номер, год, русское название; у совпадений по тексту — найденная строка. Над результатами — счётчик («25 песен»; «В названиях нет · в тексте: 3 песни»; «Ничего не найдено»). Клавиатура: «/» или Ctrl/⌘+K ставит курсор в поиск, ↑/↓ — выбор (первый результат выбран сразу), Enter — открыть, Esc — очистить (пустое поле — снять фокус); крестик в поле очищает. **После перехода к песне из результатов** — открывается её страница, слева раскрывается раздел с этой песней и список прокручивается к ней, поиск сбрасывается, фокус переходит на строку песни. На мобильной раскладке — та же строка поиска в шапке (выпадающие результаты; движок, ранжирование и подсветка общие; Enter открывает первый результат).

## Проверка текстов и строфики (волна сверки)

- **Проверяем только то, что можно проверить по авторитетному источнику; что нельзя — не делаем** (никаких агентских «проверок на глаз» без эталона). Эталоны: слой Растля (LiederNet / schubertsong.uk — читать и сравнивать факты, компиляцию не копировать), PD-издания поэтов, сканы AGA; для Winterreise — собственный проект пользователя (github.com/evgobmm/Winterreise): тексты должны совпадать **абсолютно**.
- **Требование к тексту каждой песни: ровно тот текст, что поют** (с повторами Шуберта и его изменениями слов). Стихотворение «как в книге» — промежуточный, а не финальный формат. **Объём — тоже ровно поющийся**: если стихотворение длиннее положенного на музыку / реально поемого, песня НЕ считается неполной (так закрыты D 104, 217, 307 — в них весь текст, звучащий на записях).
- **Реестр источников и благодарностей ведём обязательно**: каждый сайт, база, издание и человек, чьими материалами/трудом пользуемся, фиксируется в `docs/rules/acknowledgements.md` (что взяли, роль, ссылка) — по ходу работы, а не задним числом. Позже на сайте будет раздел ссылок и благодарностей на его основе (отложенная задача).
- **Письмо Растлю/Врену НЕ пишем — оно не нужно** (решение пользователя 2026-08-16): их тексты не копируем; их выводы (какое издание использовал Шуберт, что поётся, отличия слов) используем как факты со ссылкой на источник, переформулируя своими словами — в том числе в будущих комментариях к песням.
- **Ошибки, всплывающие по ходу проекта (в т.ч. «не совсем нужный текст»), исправлять сразу** — и сообщать пользователю в чате о каждой.
- **Критерий завершения волны: пользователь должен быть уверен, что всё чисто, прежде чем двигаться дальше** — проверять столько раз, сколько потребуется; после исправлений — повторный прогон сверки до нуля необъяснённых расхождений (объяснённые — задокументировать).

## Решения по пилоту

- Пилотная песня — **«Gretchen am Spinnrade» (D 118)**: по ней должно быть видно, как будет выглядеть сайт.
- Синхронизация слов с записью **сделана** (`word-sync.md`) и пока включена только на странице «Гретхен за прялкой» (D 118) — для записей, у которых есть файл таймингов.
- На странице песни — раздел **«О песне»** (см. `translation.md`).
- **Страница — пять столбцов**: список песен · немецкий текст · перевод · **новая колонка** · настройки (пояснения, исполнения и т. д.). **Область текста занимает всю среднюю колонку** (предел 1600 px только для очень широких экранов; прежний предел 1120 px оставлял пустоту). Немецкая колонка — 36 % области текста, не уже 380 и не шире 460 px; перевод получает всё, что остаётся после новой колонки. **Новая колонка идёт на всю высоту текста песни, без обтекания**; колонка перевода из-за неё уже по всей длине (длинные строки переносятся). Разделы ниже текста (пояснения, «О песне») занимают ширину текста и новой колонки вместе. В шапке: немецкое название, русское название; в новой колонке на той же строке — метаданные; русское название ширину колонки не задаёт (при нужде переносится само). Первая строка колонки стоит **на уровне названий** (по базовой линии) и содержит **«1816, D 399»** (год, D-номер); **«стихи — поэт» — отдельной строкой ниже**. **Имя поэта не переносится.** Ширина колонки — **по её содержимому, не уже 220 px** (столько нужно кнопке и предупреждению); самая длинная строка каталога на момент замера — «стихи — Фридрих Леопольд граф цу Штольберг-Штольберг», 398 px (с 2026-09-09 имя пишется без «граф», запас ширины остаётся). Всё остальное место достаётся переводу. **Колонка существует только на экранах от 1700 px** (область текста 1000 px и шире); уже — ей нет места (переводу осталось бы меньше 240 px), и она уходит в поток: метаданные строкой под названиями, кнопка и предупреждение перед текстом. Несколько авторов — **каждый на своей строке** (перенос только между именами). Метаданные не стоят под названиями. На мобильной раскладке колонки нет — одна строка «1816, D 399, стихи — поэт» под названиями.
- **Та же третья колонка ниже, на линии начала перевода**: прямоугольная кнопка **«О песне»** в стиле кнопок «Исполнения»/«Печать» (рамка, скруглённые углы, надпись и **двойной шеврон вниз** справа; без значка), плавно прокручивает к разделу «О песне»; показывается только у песен с этим разделом. **Под кнопкой — текст-предупреждение** (две строки, второстепенным цветом, мелко): «Сайт предназначен для общего знакомства с песнями.» / «Он сделан с помощью ИИ и на данный момент не может рассматриваться как источник знаний.» Кнопка и текст стоят в той же новой колонке, что и метаданные (один левый край). На печать блок не идёт; на мобильной раскладке стоит перед текстом во всю ширину.
- **Меню печати**: помимо «Пояснения» (с подпунктами «Смысл», «Язык») — галочка **«О песне»** (по умолчанию включена): раздел печатается после пояснений, с новой страницы, во всю ширину листа; прозу можно рвать между страницами, заголовки от текста не отрываются. При печати страницы напрямую (Ctrl+P) раздел «О песне» по-прежнему не идёт.
- **Кнопка «Источники»** (компьютерная раскладка): круглая, со значком раскрытой книги, в ряду письма чуть левее его (промежуток 16 px), с подсказкой «Источники»; открывает окно **«Источники и благодарности»** — публичную версию реестра `acknowledgements.md`: люди, чьи работы цитируются, сайты и базы по группам, издания-первоисточники, инфраструктура сайта; у пунктов ссылки на сайты и короткая пометка, что взято. Данные — `app/src/data/acknowledgements.json`; **при пополнении реестра пополняется и он**. На мобильной раскладке кнопки нет.
- **Кнопка «Наверх»** (компьютерная раскладка): круглая, с **двойным шевроном вверх**, с подсказкой «Наверх», плавно возвращает к началу страницы. Стоит **в правой колонке, в одном ряду с кнопкой письма, слева — центром под значком принтера кнопки «Печать»**; колонка липкая, поэтому кнопка всегда на виду и ничего не перекрывает. Место в ряду занимает всегда, а видна только когда страница прокручена вниз более чем на ~400 px. **Круглые кнопки правой колонки одного размера (46 px); тема (месяц) и письмо — на одной вертикали, по положению месяца** (центр в 112 px от правого края окна). На мобильной раскладке остаются прежние плавающие кнопки.
