# Цель проекта и рамки

Обновлено: 2026-08-14. Источник — указания пользователя (чат).

## Цель

Сайт со **всеми песнями Шуберта** (~600+) с пословным русским переводом. Образец — https://github.com/evgobmm/Winterreise (собственный проект пользователя, CC0): его стиль и вся интерактивность воспроизводятся.

## Требования к сайту

- Найти все песни Шуберта и их немецкие тексты.
- Песни сгруппировать; удобное расположение на сайте; **поиск по песням**.
- **Мобильная версия** обязательна.
- На каждую песню — **топ-5 (максимум) роликов YouTube** со значительными исполнениями (правила: `youtube-performances.md`).
- Пословный перевод в духе референса: отдельное значение каждому слову; объединение слов — только когда строгая буквальность искажает смысл или грамматику; сохранение немецкого порядка слов, где это грамматично; пояснения по наведению (правила: `translation.md`).
- **Целевое требование (не пилот)**: синхронизация текста с записью — поющееся слово подсвечивается (слева и справа; тайминги выверяются вручную по звуку; тянущееся слово подсвечено, пока звучит).

## Этапность

Работа многоэтапная. На одном из первых (но не первом) этапов — **одна пилотная песня** на просмотр пользователю, затем масштабирование. Пилот («Гретхен за прялкой») принят пользователем — идёт фаза «все песни».

## Фаза «все песни» (активна)

- Добавление всех песен идёт **в текущем чате**: сначала только немецкие тексты, без перевода.
- Если работают параллельные сессии: обе пушат в `main` — перед push всегда `git pull --rebase`; мелкие частые коммиты; изменения приложения (`app/`) согласовывать между потоками (модель данных менять только с фиксацией в CLAUDE.md).
- Источники: сводка и матрица — `planning/research/song-sources.md`; данные каталога — `planning/catalog/` (D-номера — канонические ID; slug `d<номер>-<кебаб-название>`; компиляции LiederNet/schubertsong.uk без разрешения не копировать).
- **По возможности брать все тексты и даты написания из одного авторитетного источника.**
- Рабочие решения фазы (до иных указаний): корпус = сольные Lieder по NSA (genre=Lied, ~630, одна страница на D-номер; фрагменты и ариетты из зингшпилей — точечно позже); тексты начинаем с OpenScore (CC0, «как поётся»); вопрос писем Растлю/Врену/Эзуст открыт — работаем с безусловно свободными источниками.

## Группировка песен

- **Циклы — точно отдельными группами.** Названия циклов в навигации/заголовках — **на немецком** (Die schöne Müllerin, Winterreise, Schwanengesang).
- Ориентироваться на **авторитетные разбиения** корпуса; вкус пользователя: поэтная группировка не нравится, нравятся периоды и темы; если авторитетное разбиение только другое — брать как у авторитетов. Итог исследования (`planning/research/authoritative-groupings.md`): главное оглавление = 3 цикла + **хронологические периоды**; **темы — вторичный слой тегов**, не партиция; **поэт — индекс/фильтр**, не группировка.
- **Размер раздела: сильно больше 50 песен — не вариант** (ориентир ~25–50); перегруженные годы делить по месяцам, малые годы объединять (прецеденты: Hyperion, AGA).
- **Утверждённая сетка** (реализация — `planning/catalog/sections.json`; 16 хронологических разделов + 3 цикла, 628 песен): 1810–1814 (43) · 1815: янв–май (42), июнь–июль (30), август (27), сент–дек (41) · 1816: янв–апр (38), май–июль (41), авг–дек (42) · 1817: янв–апр (30), май–нояб (28) · 1818–1819 (42) · 1820–1821 (40) · 1822–1823 (39) · 1824–1825 (31) · 1826–1827 (43) · 1828 (13) · Die schöne Müllerin (20) · Winterreise (24) · Schwanengesang (13 + Taubenpost D 965A = 14, примечание о посмертном сборнике). Заголовки годовых разделов — просто годы, без подписей («1810–1814», не «Начало (1810–1814)»; «1828», не «Последний год»). Исключены 7 записей (утеряно/без текста/без даты — список в sections.json). Каждому разделу — короткое русское вступление (позже).
- **Навигация слева: раскрывающиеся разделы (аккордеон)**, не сплошной список. Одновременно раскрыт **максимум один раздел (или ни одного)**; **при загрузке все закрыты** (раздел текущей песни сам не раскрывается). Исключение — **переход из поиска**: открывается страница песни и автоматически раскрывается её раздел. В шапке раздела — число песен; раздел с текущей песней подсвечен в свёрнутом виде.
- **Поиск**: под словом «Песни» — традиционная строка со значком лупы. Ищет **сначала по названиям** (немецким и русским); если в названиях ничего — **по тексту песни**. Частичное вхождение («прялк» находит «Гретхен за прялкой»), без кнопки — срабатывает само с задержкой ~300 мс (принятый дебаунс). Несколько совпадений — выдаётся полный список; у совпадений по тексту показывается найденная строка. **После перехода к песне из результатов** — открывается её страница, слева раскрывается раздел с этой песней, поиск сбрасывается.

## Решения по пилоту

- Пилотная песня — **«Gretchen am Spinnrade» (D 118)**: по ней должно быть видно, как будет выглядеть сайт.
- Синхронизацию с YouTube на пилоте **не делаем** — только топ-5 исполнений.
- На странице песни — раздел **«О песне»** (см. `translation.md`).
- Репозиторий: **github.com/evgobmm/schubert-lieder**, публичный.
