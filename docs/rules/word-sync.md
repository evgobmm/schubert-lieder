# Подсветка слов под запись и переход по клику

Обновлено: 2026-09-07. Источник — указания пользователя (чат).

## Что делает сайт

- При проигрывании записи в панели «Исполнения» в тексте **подсвечивается пропеваемое слово**:
  в немецкой строке (слева) и соответствующий ему сегмент подстрочника (справа).
  Тянущееся слово подсвечено, пока звучит.
- **Клик по слову в любой колонке** (пока в плеере загружена запись с таймингами) — запись
  перематывается на это слово и играет дальше: по немецкому слову — на него самого, по русскому
  сегменту подстрочника — на первое из его немецких слов. Русское слово без немецкого соответствия
  (добавленное переводом, например «не») ведёт к ближайшему слову той же строки. Если строка спета
  несколько раз, берётся проход, ближайший по времени к текущей позиции записи. Клик по знаку сноски
  по-прежнему открывает пояснение, а не перематывает.
- Пауза записи — подсветка остаётся на месте; конец записи, смена записи, закрытие панели — снимается.
- Прокрутка вслед за подсветкой — только пока читатель за ней следит: если предыдущая подсвеченная
  строка была на экране, а новая ушла за край, страница подтягивает новую строку. Если читатель ушёл
  в другое место страницы (подсвеченной строки на экране нет), подсветка страницу не дёргает.
- Записи с подсветкой отмечены в списке исполнений значком; под плеером — подсказка: в этой записи
  слова подсвечиваются (и что по слову можно кликнуть) либо в какой записи песни подсветка есть.

## Где включено

Подсветка работает там, где для выбранной записи есть файл таймингов в `app/src/data/timings/`.
**Пока это только страница «Гретхен за прялкой» (D 118)** — запись Сэмпсон — Миддлтон (2018).
Остальные записи и песни — плеер как раньше, без подсветки. Расширение на другие песни и записи —
отдельное решение пользователя; производство таймингов — `audio-alignment.md`.

## Формат файла таймингов

`app/src/data/timings/d<D>-<videoId>.json` (для D с дробью — `d795-1-<videoId>.json`). Ключ — пара
(D, videoId): тайминги действительны только для той записи, по которой считались.

```json
{
  "d": "118", "videoId": "1F4CHXbX8gc", "performance": "Sampson — Middleton, 2018",
  "method": "…", "verified_by_ear": false,
  "extra_lines": [{ "id": "x1", "de": "…", "note": "…" }],
  "route": [ { "s": 0, "l": 0, "w": [[4.1, 4.52], [4.9, 6.06], …] }, …, { "x": "x1", "w": […] } ]
}
```

- `route` — проходы в порядке звучания; `s`, `l` — строфа и строка `stanzas[s].lines_de[l]`;
  `w[k]` — `[начало, конец]` в секундах k-го слова строки **по пробелам** (интервалов ровно столько,
  сколько слов в строке). Одна строка может встречаться в маршруте сколько угодно раз.
- В проходе `w[k]` может быть `null` — слово в этом проходе не спето (частичный повтор нескольких слов: композитор повторяет «die Erde, die Erde», в тексте повтора нет, подсвечиваются те же слова ещё раз). Индекс слов такие интервалы пропускает.
- `x` — ссылка на строку из `extra_lines` (слова, которых в тексте нет); такой проход ничего
  не подсвечивает.
- Маршрут ссылается на текст **в том виде, в каком он опубликован**. Пока повторы Шуберта в D 118
  вписаны в текст, проходы финальной строфы и коды ссылаются на строфы 10–11; при чистке текста
  (`audio-alignment.md`) маршрут переписывается (в файле есть `note`, что именно).
- `variants` — слова, спетые в этой записи иначе, чем в тексте: `[{s, l, k, w, heard, start}]` (`w` — слово текста,
  `heard` — как спето, по Whisper с подтверждением обоих CTC-движков). **Пока в плеере выбрана такая запись, в немецкой
  строке на месте слова текста показывается спетое** (пунктирное подчёркивание, подсказка «в тексте: …»); текст песни
  не меняется. Пример: Quasthoff в D 911/4 поёт «erfroren» вместо «erstorben».
- `verified_by_ear` — прошла ли разметка приёмку на слух; у D 118 пока `false`: приёмка — на сайте.

## Поведение подсветки (детали реализации)

- Слово подсвечено от `start` до `end`; пауза до 1,0 с до следующего слова закрывается предыдущим
  словом (внутри фразы подсветка не мигает); более долгая (вздох, интерлюдия) — без подсветки.
- Клик перематывает на `start − 0,15 с`, чтобы была слышна атака слова.
- Плеер — YouTube IFrame Player API поверх `youtube-nocookie.com`; позиция опрашивается покадрово
  с интерполяцией между сообщениями плеера. Если API не загрузился (блокировщик, нет сети) —
  обычный iframe, без подсветки.
- Код: `app/src/utils/playback.js` (общее состояние плеера и страницы), `utils/timings.js` (индекс
  слов по времени), `utils/lineTokens.js` (слова строки; слово → сегмент подстрочника),
  `components/LineDe.vue` (немецкая строка по словам), `PerformancePlayer.vue`, `SongView.vue`.
