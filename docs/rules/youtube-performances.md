# Правила отбора исполнений (YouTube, топ-5)

## Конвейер выделенного потока (сессия «YouTube-записи»)

Порядок работы по каждой песне:
1. **Дискография**: собрать значительные записи песни (сравнительные обзоры, слепые тесты, дискографии певцов, полные издания Hyperion/Naxos/DG); общий фонд исполнителей — `planning/research/schubert-singers.md`.
2. **Исследование каждой записи-кандидата** (обязательно, по разделу «Порядок работы» ниже): исполнители, точный год по дискографии, происхождение, состояние голоса, критическая репутация без пиара.
3. **Отбор топ-5** по приоритетам и составу (разделы ниже); обоснование — в `planning/research/<slug>-top5.md` (образец: `gretchen-am-spinnrade-top5.md` / `gretchen-top5.md`).
4. **Проверка видео**: ID только из реально просмотренных страниц; живость и встраиваемость — через oEmbed; предпочтение официальным каналам и «Topic».
5. **Публикация**: запись в `app/src/data/performances.json` (`{"<d>": [{videoId, name, year}, ...]}`, первая — главная; name — «Фамилия — Фамилия пианиста»), мелкий коммит, `git pull --rebase`, push.
6. Очерёдность песен: сначала знаменитые и уже опубликованные на сайте; полный список песен — `app/src/data/index.json`.

Поток не редактирует тексты песен, переводы и правила. Найденные по дороге факты о песне — в `planning/research/`, отдельным файлом, по протоколу фактов.

Действующая редакция: 2026-08-16. Список приоритетов дополняется по мере работы.

## Пилот потока

Пилотный объём — все 30 песен раздела «1824–1825» (`section: "1824-1825"` в `app/src/data/index.json`). Очерёдность внутри пилота: сначала знаменитые (полный конвейер), редкие — облегчённым конвейером после них.

## Экономия лимитов в потоке

Лимиты подписки ограничены; общие правила экономии — `workflow.md` («Экономия лимитов»). Специфика потока:

1. **Механика — скриптами, не агентами** (0 токенов): поиск по YouTube — `planning/youtube/scripts/yt-search.js` (curl + разбор `ytInitialData`: videoId, название, канал, длительность); живость/встраиваемость — oEmbed (`yt-check.js`); каркас дискографии — MusicBrainz API (`mb-discography.js`). Агенты читают только компактные JSON-результаты скриптов; скрипты коммитятся в репозиторий.
2. **Однократные дайджесты вместо повторных исследований**: сжатый дайджест фонда певцов (`planning/research/singers-digest.md`: пик формы по годам, ключевые Schubert-записи) и **реестр сквозных альбомов/изданий** (полные издания Hyperion/Naxos/DG Fischer-Dieskau, значимые рециталы: год, лейбл, критика) строятся один раз и переиспользуются всеми песнями. Альбом исследуется один раз — факты о нём наследуют все входящие в него песни; состояние голоса певца в году X не исследуется заново для каждой песни.
3. **Триаж перед конвейером**: один дешёвый проход делит 30 песен на «знаменитые» (полный конвейер) и «редкие» (фонд записей ≈ полные издания + несколько рециталов; облегчённый конвейер — одна связка «дискография + ранжирование», топ может быть меньше 5). Глубина исследования пропорциональна фонду записей песни.
4. **Волны по 5–6 песен**: один Workflow на волну, `pipeline()` без лишних барьеров; публикация (`performances.json` + top5-файлы) с коммитом и push — после каждой волны, не в конце пилота.
5. **Модельная лестница**: сбор и извлечение — дешёвая модель с низким effort; ранжирование и текст top5-файла — основная модель. Правило «отдельное исследование каждой записи-кандидата» означает отдельное изучение каждой записи (все обязательные пункты данных по каждой), а не отдельного дорогого агента на запись: кандидатов одной песни можно группировать в одном агенте.
6. **Калибровка**: после первой волны замерить фактический расход (`/usage` — на стороне пользователя; изнутри сессии лимиты не видны) и подстроить размер волн; тяжёлую волну не начинать в конце 5-часового окна.

## Порядок работы

1. На каждую песню — **не более 5 роликов**. Отбираются значительные исполнения; если качественных значительных исполнений меньше пяти — берём меньше.
2. **Топ-5 составляется только после отдельного исследования каждой записи-кандидата**: кто поёт, кто за роялем, точный год, происхождение (альбом/лейбл), состояние голоса певца на момент записи, критическая репутация записи, качество и статус загрузки на YouTube. Топ-5 не составляется «на глаз».

## Приоритетные исполнители

1. **Томас Квастхоф** (Thomas Quasthoff) — высший приоритет.
2. **Дитрих Фишер-Дискау** (Dietrich Fischer-Dieskau).
3. Среди женщин топ-1 — **Элизабет Шварцкопф** (Elisabeth Schwarzkopf).
4. Далее: **Ханс Хоттер** (Hans Hotter), **Петер Андерс** (Peter Anders), **Элизабет Шуман** (Elisabeth Schumann), **Криста Людвиг** (Christa Ludwig), **Лючия Попп** (Lucia Popp) и другие звёзды прошлого.
5. Остальные — по ситуации, на основании исследования.

## Состав топ-5 (возрастная структура)

Желательный состав — **только при наличии достойных кандидатов** (никогда не в ущерб качеству):
1. **2 записи не ранее 1990 года** — если есть достойные;
2. из них **1 запись не ранее 2015 года** — если есть достойная;
3. по умолчанию — **как минимум 3 очень хорошие записи ранее 1990 года**.

Если достойных современных кандидатов нет — их места занимают лучшие старые записи.

## Верификация данных о записях

Дата, состав и происхождение записи верифицируются по дискографиям (матричные номера, CHARM, буклеты изданий, каталоги лейблов), а **не по описаниям загрузок и метаданным архивов** — те регулярно врут (прецедент: «1945» вместо 1936 у записи Э. Шуман — опечатка метаданных archive.org, вскрытая по матрицам сессии).

## Общие принципы отбора

- **Приоритет старых мастеров**: как правило, они значительно сильнее современных исполнителей.
- **Скепсис к прессе о современных исполнителях**: похвалы часто продиктованы пиаром; на деле современные исполнения нередко значительно слабее старых мастеров. Опираться на сравнение самих записей и устоявшуюся репутацию, а не на маркетинг.
- **Несколько записей одного певца**: с возрастом голос, как правило, ухудшается (не всегда, но чаще всего) — учитывать возраст и состояние голоса на момент каждой записи; при прочих равных предпочитать более раннюю.
- **Сходные по уровню записи** (нельзя сказать, что одна точно лучше другой) — берём более раннюю.

## Техническая гигиена ссылок (предложение, пока не утверждено)

- Предпочитать официальные загрузки: каналы лейблов (DG, Warner Classics, Harmonia Mundi, Naxos…) и автоматические «— Topic»-каналы. Они реже удаляются.
- Проверять, что ролик встраиваемый (embed разрешён) и не заблокирован по регионам.
- Хранить метаданные каждого ролика (video ID, исполнители, год, лейбл, длительность) — для автоматической проверки живости ссылок в будущем.
