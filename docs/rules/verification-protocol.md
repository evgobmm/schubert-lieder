# Протокол проверки фактов (защита от галлюцинаций)

## 0. Конвейер «сначала факт» (непроверенных фактов не должно быть вообще)

Порядок работы над каждой песней — **строго факт-первый с первого шага**: никаких черновиков «в обход» с проверкой потом. Непроверенное утверждение не может попасть в текст по построению, а не вылавливается задним числом. Действует немедленно, для всех песен начиная с пилота:

1. **Сначала файл фактов** (`planning/research/<песня>-facts.md`): каждая запись — атомарное утверждение + источник (URL) + дословная цитата + статус (`verified` / `secondary` / `uncertain`). Исследовательские агенты пишут только сюда.
2. **Тексты собираются только из файла фактов.** Автору текста запрещено вносить утверждение, которого нет в файле, — включая «мостики», сравнения, обобщения. Нужен новый факт — сначала верифицируй и внеси в файл, потом используй. Записи `uncertain` в тексты не попадают; `secondary` — только с явной атрибуцией-оговоркой.
3. **Редакторская связка** между фактами не должна содержать проверяемых утверждений — только языковую и логическую связь.
4. **Гейт публикации**: песня не публикуется и не обновляется на сайте без аудита прослеживаемости (3в) с итогом «прослежено 100%». Аудит выполняет независимый агент, не автор текста. Итог (утверждений всего / прослежено / удалено) фиксируется в файле фактов.
5. **Автор ≠ проверяющий** на каждом этапе: перевод, аннотации, «О песне», стиль — всё проверяется свежим агентом.

Остаточный риск — ошибка в самом источнике; для ключевых фактов (даты, номера, атрибуции) он гасится требованием двух независимых источников (см. §3).

Действующая редакция: 2026-08-14. Применяется к каждой песне до публикации. Развитие протоколов референса (Winterreise, CLAUDE.md там же).

## 1. Немецкий текст

- Текст «как поют» устанавливается минимум по **двум независимым авторитетным источникам**; иерархия: автограф/первое издание → NSA (Bärenreiter) → критический текст Растля (schubertsong.uk / LiederNet) → оригинал поэта по научному изданию (Deutsches Textarchiv, Wikisource по печатному изданию).
- Каждое расхождение «Шуберт vs поэт» фиксируется отдельно с цитатами обоих чтений и источниками.
- Орфография модернизируется по реформе 1996 (ß/ss, Th→T); элизии-апострофы — по критическому тексту.
- Перед публикацией — программная сверка каждой строки `lines_de` с установленным текстом.
- **Инструмент сверки — `planning/scripts/check-de-texts.js`** (0 токенов): сверяет `lines_de` каждой переведённой песни с предзагруженными источниками, отсеивая мнимые расхождения (шубертовские повторы строки, орфография эпохи, диакритика, композиты). Прогонять после каждой партии и перед корпусными правками.
- **Правка немецкого текста корпуса** (указание пользователя 2026-08-31): выполняется только по вердикту `defect` из аудита, подтверждённому ДВУМЯ источниками по иерархии выше, и с явного разрешения пользователя — оно дано для списка `planning/reports/de-text-verdicts.md`. Правка меняет одновременно `lines_de` и поле `de` соответствующего сегмента (валидатор сверяет множество немецких слов строки), а расхождение «Шуберт против поэта» заносится отдельным фактом в файл фактов песни с обоими чтениями и источниками. Не подтверждённое двумя источниками не правится.


## 2. Пословный перевод

- Значение каждого знаменательного слова проверяется по словарям, **современным эпохе текста** (Adelung 1811, Campe, Grimm DWB), затем современным (DWDS, Duden) и переводным (БНРС, Multitran, PONS). Приоритет эпохи над современным значением (пример-ловушка: verrückt в 1814 ≠ современное «сумасшедший» в бытовом смысле).
- Для каждого источника — **дословная цитата ≥3–5 слов** либо явная пометка «недоступен/не найдено» с причиной. «Проверено» без цитаты запрещено.
- Слова с дрейфом регистра (высокое ↔ нейтральное за 200 лет) проверяются по Adelung, а не по современным пометам.

## 3. Факты в аннотациях и разделе «О песне»

- Каждое фактическое утверждение (дата, возраст, атрибуция, музыковедческий тезис, литературная связь) — **атомарно** и подтверждено источником: URL + дословная цитата, зафиксированные в `planning/research/<песня>-facts.md`.
- Приоритет источников: немецкоязычные научные и справочные → англоязычные научные и справочные → прочие. Википедия — допустимый вход, но ключевые факты сверяются со вторым независимым источником.
- Даты, числа, имена и номера опусов **никогда не берутся «из памяти» модели** — только из полученных в ходе исследования источников.
- Расхождение источников → либо указываем оба чтения, либо убираем утверждение.
- Оценочные традиции («считается первым великим Lied») передаются с атрибуцией («часто называют», «по традиции»), не как факт.
- Недоказуемое — вычёркивается. Пустая клетка лучше выдуманной.

## 3-цитаты. Съём цитат — только с сырого текста

Дословные цитаты снимаются с сырого источника: curl/raw-викитекст (`?action=raw`), pdftotext, постраничный скан. Пересказ WebFetch (промежуточной моделью) — навигация, не источник цитаты: он может незаметно исказить формулировку. Цитата фиксируется в файле фактов в момент верификации — публикация не зависит от дальнейшей живости ссылки; для нестабильных источников добавлять ссылку на веб-архив.

## 3а. Цитаты из OCR-сканов первоисточников

Цитаты, извлечённые из OCR старых изданий (фрактура, документы Дойча и т.п.), перед публикацией сверять с постраничным сканом; нормализацию орфографии (ſ→s, uͤ→ü) помечать в файле фактов. До сверки — использовать только пересказом, не в кавычках.

## 3б. Редактура без потерь

Любая стилистическая переработка готовых текстов (аннотаций, «О песне») обязана сохранить всё содержание. После редактуры — **проверка сохранности**: независимое сопоставление старой и новой версий по фактам (каждое утверждение, дата, имя, цитата, атрибуция старой версии должны находиться в новой — либо потеря явно обоснована и сообщена пользователю). Стилистическая правка не повод терять смысловые оттенки: если фраза несла два смысла, оба должны выжить.

Это касается **и правок, предложенных контролёрами**: применение находок редактора или факт-чекера — тоже редактура, после неё сверка сохранности обязательна так же, как после авторской переписки. Цикл «правка → сверка» повторяется, пока последняя партия правок не пройдёт сверку чистой.

**И в обратную сторону**: перефразировка не должна вводить новых фактических утверждений. Каждый «мостик» или сравнение, появившееся при правке («и до Шуберта...», «в отличие от...», «как обычно...»), — это новый факт, требующий источника; проверка сохранности проверяет и это (прецедент: «прялки крутились в музыке и до Шуберта» — неподтверждённое утверждение, внесённое стилевой правкой и пойманное пользователем).

## 3в. Аудит прослеживаемости (обязателен после КАЖДОГО содержательного изменения)

Не только при первой публикации: после любого добавления или переработки контента страница проходит пофактный аудит. Каждое утверждение текстов (включая редакторские «мостики», сравнения, обобщения) прослеживается до записи в `planning/research/<песня>-*.md` с цитатой источника. Непрослеживаемое утверждение: либо проверяется живьём и вносится в файл фактов, либо удаляется/смягчается до атрибутированного мнения. Итог аудита фиксируется (сколько утверждений, сколько прослежено, что удалено).

## 4. Контрольный проход перед публикацией

- **Адверсариальная проверка**: независимый проверяющий (агент, не писавший текст) пытается опровергнуть каждое утверждение по источникам; публикуются только выдержавшие проверку.
- Пословная сверка каждого сегмента DE↔RU.
- Типографика: ё-проверка (regex), «ёлочки», длинное тире, прописные в началах стихотворных строк, одиночные `\n` в аннотациях.
- Валидность JSON и целостность диапазонов аннотаций.

## 5. YouTube

- Video ID берутся только из реально просмотренных страниц/выдач — никогда не «по памяти».
- Перед публикацией каждый ID проверяется запросом (oEmbed / открытие страницы): ролик существует, встраиваемый.
- Метаданные ролика (исполнители, год, лейбл) сверяются с описанием ролика и внешним источником (дискография).
